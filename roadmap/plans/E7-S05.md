## Mục tiêu
Từ màn hình bố cục trang (E7-S04), người có quyền `content.edit` bấm "Sửa nội dung" một section → màn hình chia đôi:
form `SchemaForm` (E7-S03) bên trái, iframe preview draft (`<slug>.preview.<platform>`, E5-S07) bên phải, tự cuộn tới
section đang sửa. Gõ vào form → sau 800 ms tự lưu nháp (`saveDraft`) → preview làm mới tại chỗ (không tải lại trang,
giữ vị trí cuộn). Rời trang khi còn thay đổi chưa lưu (đang chờ debounce, đang lưu, dữ liệu lỗi chưa lưu được, lưu lỗi)
→ cảnh báo.

## Thiết kế

1. **Giao thức preview (web)** — `apps/web/src/components/preview/PreviewBridge.tsx` (`"use client"`), chỉ render khi
   `preview === true` trong layout `sites/[tenantId]/[siteId]/[ctx]/layout.tsx` (context đã có trong URL, không đọc
   cookie → không ảnh hưởng cache). Hằng + kiểu dùng chung đặt ở `packages/cms-ui/src/preview/protocol.ts` (thuần, không
   React) để admin và web cùng import:
   ```ts
   export const PREVIEW_MESSAGE = "solar-preview";
   export type PreviewCommand = { type: "solar-preview"; action: "refresh" | "scroll"; sectionId?: string };
   export type PreviewEvent = { type: "solar-preview"; action: "ready" | "updated"; sectionId?: string };
   export function parsePreviewMessage(data: unknown): PreviewCommand | PreviewEvent | null; // zod hoặc kiểm tay; sectionId /^[A-Za-z0-9_-]{1,64}$/
   export function adminOrigin(previewHost: string, protocol: string, port?: string): string | null; // a.preview.x → a.admin.x
   ```
   Bridge: nhận `message` chỉ khi `event.source === window.parent` **và** `event.origin === adminOrigin(...)` (cổng dev
   lấy từ `NEXT_PUBLIC_ADMIN_PORT` nếu có, xem mục 4); `refresh` → `startTransition(() => router.refresh())`, xong (effect
   khi transition hết pending) → cuộn tới `[data-section-id="<CSS.escape(id)>"]` (`scrollIntoView({ block: "start",
   behavior: reduced ? "auto" : "smooth" })`) rồi `postMessage({ action: "updated", sectionId }, adminOrigin)`;
   `scroll` → chỉ cuộn. Gửi `ready` một lần sau mount. Không chạy khi `window.parent === window`. Không đổi DOM ngoài
   cuộn (không chèn viền highlight — design pass quyết định nếu cần, dùng token).

2. **`packages/cms-ui`** (dùng lại ở wizard E13-S06):
   - `src/preview/useAutosave.ts`:
     ```ts
     export function useAutosave<T>(value: T, opts: { save(value: T): Promise<{ ok: true } | { ok: false; error: string; conflict?: boolean }>;
       valid(value: T): boolean; delay?: number /* 800 */ }): { status: "saved" | "pending" | "saving" | "invalid" | "error" | "conflict"; error?: string; dirty: boolean; flush(): Promise<void> };
     ```
     So sánh theo `JSON.stringify` với bản đã lưu gần nhất; debounce `delay`; **tuần tự** — đang lưu mà có thay đổi mới
     thì chờ xong rồi lưu bản mới nhất (không gửi song song, không để bản cũ ghi đè bản mới); `invalid` không gửi;
     `conflict` dừng hẳn (không tự lưu tiếp). `dirty = status !== "saved"`.
   - `src/preview/useLeaveGuard.ts` `useLeaveGuard(active: boolean, message = "Bạn có thay đổi chưa lưu. Rời trang?")`:
     `beforeunload` (`preventDefault` + `returnValue`) khi `active`; chặn click `<a href>` cùng origin khác trang (capture
     phase, bỏ qua `target=_blank`, phím bổ trợ, `download`, `#hash` cùng trang) bằng `window.confirm`; `popstate` không
     chặn được ở App Router — ghi chú, không làm.
   - `src/preview/PreviewFrame.tsx` `<PreviewFrame src title sectionId targetOrigin refreshKey onUpdated? />`: iframe
     `title` tiếng Việt, `sandbox` **không** đặt (draft mode cần cookie + script; nguồn đã giới hạn bằng frame-ancestors);
     nhận `ready` → gửi `scroll`; `refreshKey` đổi → gửi `refresh`; chỉ nhận message có `origin === targetOrigin`.
   - Export từ `src/index.ts`. `SectionListEditor`: thêm prop tùy chọn `editHref?(section: EditableSection): string` →
     mỗi hàng có link "Sửa nội dung" (hiện cả khi `can.reorder = false` — gói Cơ bản vẫn sửa nội dung).

3. **`apps/admin` — logic** (`src/lib/pageSections.ts`, deps tiêm vào):
   - Dep mới `content(siteId, pageId, sectionId): Promise<{ type: string; schemaVersion: number; data: unknown; draftData: unknown } | null>`
     (runtime: `forTenant(...).sectionContent.first`).
   - `loadSectionContent(pageId, sectionId, deps & { requirePermission(p: "content.edit") })`: quyền trước; page thuộc
     site của host; section có trong `draftSections ?? sections` (không → null); `sectionFormType(type, can)` (ngoài gói →
     null); dữ liệu = `def.schema.parse(migrateSectionData(def, row.schemaVersion, row.draftData ?? row.data).data)`,
     không có row → `defaults`, parse lỗi → `defaults` + cờ `recovered: true` (UI báo "Dữ liệu cũ không đọc được, đang
     hiển thị mặc định"). `row.schemaVersion < def.schemaVersion` → `readOnly: "Nội dung cần cập nhật phiên bản trước khi
     sửa"` (saveDraft không nâng `schemaVersion` — lưu dữ liệu đã migrate với version cũ sẽ bị migrate hai lần). Trả
     `{ page: { id, slug, title, revision }, section: { id, type, variant, label }, data, bilingual: can("bilingual"),
     previewPath: "/" + slug, readOnly?, recovered? }`.
   - Handler `saveContent` — `action("content.edit", saveContentSchema, …)`, `saveContentSchema = pageRevisionSchema.extend({
     sectionId: z.string().regex(/^[A-Za-z0-9_-]{1,64}$/), data: z.string().max(500_000) })`: `ownPage`; section có trong
     layout và type trong gói; `JSON.parse` + `def.schema.safeParse` lỗi → 400 "Dữ liệu không hợp lệ" (không gọi save);
     schemaVersion cũ → 409 như trên; actor null → `forbiddenActor`; `mutation(() => deps.save(tenantId, { pageId,
     expectedRevision, actor, sections: [{ sectionId, type, draftData }] }))` → `{ ok, revision }`. Không revalidate.
   - `actions.ts`: `export const saveSectionContent = action("content.edit", saveContentSchema, handlers.saveContent)`.
