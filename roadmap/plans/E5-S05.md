## Mục tiêu
`packages/cache` định nghĩa hợp đồng `cached(fn, { keyParts, tags })` + `invalidate(tags)` (bản bộ nhớ; Redis ở E10-S03).
Xuất bản ghi DB + `Outbox{topic:"invalidate"}` trong cùng transaction → worker (E11-S01) gọi `POST /api/revalidate` có HMAC →
web xóa cache theo tag và gọi `revalidateTag(tag, { expire: 0 })`. Chỉ trang liên quan được làm mới; tenant này không đụng tenant kia.

## Bối cảnh đã khảo sát

## Thiết kế
1. **packages/cache** (package mới `@solar/cache`, không dependency runtime ngoài Node):
   - `tags.ts`: `tenantTag(id)`, `siteTag(id)`, `pageTag(id, slug)`, `collectionTag(id, name)`, `isValidTag(tag)` (chỉ
     `tenant:<uuid>[:site|:page:<slug>|:collection:<name>]` hoặc `platform:settings|platform:entitlements`).
   - `cacheKey({ siteId, locale, mode, parts })` → chuỗi JSON ổn định; `mode: "draft"` → **không cache** (gọi thẳng `fn`).
   - `createMemoryCache({ maxEntries = 5000, ttlMs = 24h, now? })` → `{ cached, invalidate }`: entry lưu `tags`, `expiresAt`;
     single-flight theo key (promise đang chạy dùng chung, lỗi không được cache); `invalidate(tags)` xóa mọi entry chứa tag.
     Chống ghi bản cũ: mỗi tag có `invalidatedAt`; render bắt đầu trước `invalidatedAt` thì kết quả không được ghi vào cache.
     LRU đơn giản theo `Map` khi vượt `maxEntries`.
   - `index.ts`: singleton toàn tiến trình (`globalThis`, sống qua HMR) + `cached`, `invalidate` xuất mặc định;
     `invalidationJob(tags, { hosts? })` → `{ topic: "invalidate", payload: { tags, hosts }, idempotencyKey: "invalidate:<uuid>" }`.
   - `signature.ts`: `signRevalidate(body: string, secret)` HMAC-SHA256 hex; `verifyRevalidate(body, signature, secret)` so sánh
     `timingSafeEqual`. Dùng chung cho worker và web.
   - Test `node:test`: key A/B cùng slug khác siteId, tag A không xóa B, draft không cache, single-flight, TTL, render chậm.
2. **apps/web**:
   - `siteData.ts`: bọc bằng `cached` — `loadTenantSite` keyParts `[tenantId, siteId]`, tags `[tenant, site]`; kill switch
     keyParts `["disabled"]` tag `platform:entitlements`; `loadPublishedPage` `{ siteId, locale, mode: "published", parts: [slug] }`
     tags `[tenant, page(slug)]`; `listPublishedPages` tags `[tenant, site]`. `collections.ts`: theo collection tag.
     Giữ `react.cache` bên ngoài (dedupe trong request).
   - `app/api/revalidate/route.ts` (`runtime = "nodejs"`, `dynamic = "force-dynamic"`): đọc raw body; thiếu `REVALIDATE_SECRET`
     → 503; chữ ký `x-signature` sai → 401; body `{ tags: string[] (1–100), hosts?: string[], nonce: string, ts: number }`
     sai/tag không hợp lệ → 400; `|now - ts| > 5 phút` → 401; nonce đã dùng (Redis `SET NX PX 10m`, không có Redis → bộ nhớ) →
     409; rate-limit 120/phút theo IP (dùng `rateLimit.ts` của E11-S01) → 429. Hợp lệ → `invalidate(tags)`,
     `revalidateTag(tag, { expire: 0 })` từng tag, `invalidateHosts(hosts)` nếu có → `200 { ok: true }`.
   - `proxy.ts`: `/api/revalidate` đi thẳng (không resolve host, không gắn header tenant).
3. **apps/worker**: `handlers/invalidate.ts` — POST tới mọi URL trong `WEB_REVALIDATE_URLS` (phân tách dấu phẩy, mỗi bản
   `web` một URL vì cache bộ nhớ là theo tiến trình), mỗi lần thử nonce mới, `x-idempotency-key` = `job.idempotencyKey`, timeout
   10 s. URL nào lỗi/không 2xx → ném lỗi → retry (invalidate idempotent). Topic này `maxAgeMs: Infinity` (không bao giờ dead);
   job `pending` lâu hơn 5 phút → `console.error("[outbox] invalidate trễ > 5 phút", …)` mỗi lần thất bại.
4. **packages/db**: `enqueueInvalidate(repo, tags, hosts?)` = `repo.outbox.create(invalidationJob(...))` để admin (E7) gọi
   trong cùng `withTenantTransaction` khi xuất bản; thêm `@solar/cache` vào dependency.
5. **Tài liệu**: `packages/cache/README.md` (hợp đồng, khóa, tag, ngữ nghĩa expire 0, giới hạn cache bộ nhớ theo tiến trình →
   E10-S03), env `REVALIDATE_SECRET`, `WEB_REVALIDATE_URLS` trong `apps/web/.env.example` + `apps/worker/README.md`,
   `turbo.json` passThroughEnv.
