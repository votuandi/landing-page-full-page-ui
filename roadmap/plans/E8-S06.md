## Thiết kế
- **Storage**: `storageFor(kind, env)` (validate riêng từng driver; base `MEDIA_PUBLIC_BASE_LOCAL|_S3` → fallback
  `MEDIA_PUBLIC_BASE`); `storageFromEnv(env)` = `storageFor(env.STORAGE_DRIVER)`. Export `defaultDriver(env)`.
- **Schema**: migration thêm `Tenant.storageDriver StorageDriver?` và `Media.orphanedAt DateTime?` + index
  `[status, orphanedAt]`. Không tăng `schemaVersion` section (không đổi schema section).
- **Nơi đọc/ghi**: mọi chỗ có row dùng `storageFor(row.driver)`; reserve: `reserveUpload(db, tenantId, input, default)` đọc
  `tenant.storageDriver ?? default` trong cùng transaction. Handler admin nhận `storage(kind)`.
- **Tham chiếu**: `mediaReferenceIds(repo)` = khóa của `mediaReferences` ∪ `PageVersion.snapshot.contents[].data` ∪
  `data` trong `Page.sections/draftSections` (qua `collectRefs` theo type). `mediaReferences` (UI) không đổi hành vi.
- **Quét mồ côi** `sweepOrphanMedia(db: PlatformDb, { now, protect: Map<tenantId, Set<id>>, dryRun })`: theo từng tenant,
  transaction Serializable: tính ref; ready + không ref + `orphanedAt=null` → đặt now; có ref → null; ứng viên
  `orphanedAt < now − 30d` → (không dryRun) xóa row + `AuditLog media.orphan_deleted` (actor system) + enqueue invalidate nếu
  public. Trả `{tenantId,id,key,driver,keys[],orphanedAt}`; xóa tệp sau commit bằng `storageFor(driver)`.
  `protect` đọc từ `MEDIA_BACKUP_DIR` (mỗi `*.json` → `parseTenantBackup` → ref từ nội dung bundle); file lỗi → **dừng
  quét, không xóa**. Worker: `every(7 * 24 * 3600_000, …)`, log danh sách trước khi xóa.
- **Restore**: tệp media thiếu mà media **không** được nội dung bundle tham chiếu → bỏ row đó (đếm `skipped`), thay vì ném lỗi;
  nguồn đọc `storageFor(media.driver)`, đích `storageFromEnv()`, row ghi driver đích.
- **Migrate** `migrateTenantStorage(db, { tenantId, from, to, dryRun, storage: kind => StorageDriver })`: (1) đặt
  `Tenant.storageDriver = to` (upload mới vào đích); (2) với mỗi Media `ready`, `driver=from`: đọc gốc + biến thể, put đích
  (Cache-Control `public, max-age=31536000, immutable` cho `tenants/`, `private, no-store` cho `private/`), đọc lại so sha256;
  (3) `update … where {id, driver: from, key, status: ready}` → `driver=to`, count 0 → `skipped` (đổi giữa chừng); (4) enqueue
  `tenant:<id>`. Không xóa nguồn. In `{copied, bytes, skipped, remaining}`; `remaining > 0` → chạy lại. Lỗi checksum → dừng,
  không cập nhật row đó. Script `packages/db/scripts/storage-migrate.ts` + root `storage:migrate`, `media:orphans`.
- **Crawler** `scripts/media-crawl.mjs <url>…` (fetch thuần, không dependency).

## Case biên & bất biến
| Case | Test |
|---|---|
| Tenant B: quét/migrate tenant A không đụng row/khóa của B | `mediaOrphans.int` › "tenant isolation", `storageMigrate.int` › "only target tenant" |
| Race: section gắn media giữa quét và xóa → Serializable abort, không xóa | › "concurrent reference aborts delete" |
| Media `quarantine/failed`, private (draft) không bị migrate sai/xóa sớm | › "skips non-ready" |
| Tệp nguồn thiếu khi migrate → lỗi rõ, row giữ `from` | `storageMigrate.int` › "missing source" |
| Checksum lệch (driver đích giả trả bytes khác) → không cập nhật | `storageMigrate.test` › "checksum mismatch" |
| Chạy migrate 2 lần → lần 2 `copied=0` (idempotent) | › "idempotent" |
| `--from` = `--to`, tenant không tồn tại, driver đích thiếu env → thoát 1, không ghi | script test |
| `MEDIA_BACKUP_DIR` có file hỏng → không xóa gì | `mediaOrphans.int` › "corrupt backup aborts" |
| Khóa trong bundle/biến thể ngoài tenant → bỏ qua, không xóa khóa lạ | › "foreign keys ignored" |
| Env chỉ có local, row `driver=s3` → lỗi cấu hình khi đọc row đó, trang tĩnh không cần env S3 | web `media.test.ts` |
