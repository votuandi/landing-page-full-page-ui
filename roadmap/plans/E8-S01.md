## Mục tiêu
Package `@solar/storage`: một interface `StorageDriver`, hai driver `local` (thư mục SSD) và `s3` (AWS S3 / R2 / MinIO),
chọn bằng `STORAGE_DRIVER`; cùng một bộ contract test chạy qua cả hai (s3 trên MinIO, local và CI).

## Bối cảnh đã khảo sát
- Chưa có `packages/storage`. Prisma đã có `enum StorageDriver { local s3 }` và `Media.key @unique`, `Media.driver`
  (`packages/db/prisma/schema.prisma:97,735`) — story này **không** đụng DB. `Tenant.id` là uuid v7.
- Mẫu package Node thuần: `packages/cache` (`node --import tsx --test`, tsconfig `allowImportingTsExtensions`, eslint
  dùng `@solar/config/eslint`). Chép khung này.
- CI: `.github/workflows/workspace.yml` (job `changes` đọc `scripts/ci/checks-map.mjs --github-output`, job `verify` chạy
  `pnpm turbo run … test`), `scripts/local-ci.sh` (container Postgres/Redis qua `start()`).
- Truy vấn: `grep fs imports apps packages`, `grep STORAGE_|MEDIA_PUBLIC|S3_|minio` (không có gì), `codegraph sync`.

## Thiết kế
```
packages/storage/src/
  types.ts        StorageDriver, Meta, PutOptions
  key.ts          mediaKey(tenantId, ext, now?) + assertKey(key)
  config.ts       storageFromEnv(env = process.env) — zod parse env → driver
  drivers/local.ts  createLocalDriver({ root, publicBase })      ← file DUY NHẤT import node:fs
  drivers/s3.ts     createS3Driver({ bucket, region, endpoint?, forcePathStyle?, credentials?, publicBase })
  index.ts
  __tests__/contract.ts      runContract(name, makeDriver) — bộ test dùng chung
  __tests__/storage.test.ts  key + config + contract(local) + contract(s3, khi có env)
```
- `interface StorageDriver { put(key, body: Uint8Array, { contentType, cacheControl? }): Promise<void>; delete(key);
  list(prefix): AsyncIterable<string>; head(key): Promise<Meta | null>; publicUrl(key): string;
  signedUploadUrl?(key, opts): Promise<{ url; fields? }> }`, `Meta = { size: number; contentType?: string }`.
  `signedUploadUrl` chỉ khai báo trong interface — implement ở E8-S02 (cần thêm `@aws-sdk/s3-presigned-post`, quyết ở đó).
  Body stream: ngoài phạm vi (E8-S02).
- `mediaKey`: `tenants/<tenantId>/<yyyy>/<mm>/<randomUUID()>.<ext>` theo **UTC**; `tenantId` phải là uuid, `ext` chuẩn hóa
  chữ thường, chỉ `[a-z0-9]{1,8}` — sai → throw. Không nhận tên file người dùng.
- `assertKey(key)` gọi ở mọi method của cả hai driver: rỗng, bắt đầu `/`, có `\`, segment rỗng/`.`/`..`, ký tự ngoài
  `[A-Za-z0-9._/-]` → throw `InvalidKeyError`. Local thêm kiểm `path.resolve(root, key)` nằm trong `root`.
  `list(prefix)`: prefix `""` hợp lệ; còn lại cùng quy tắc ký tự (cho phép kết thúc `/`).
- Local: ghi nguyên tử = ghi `<root>/.tmp/<uuid>` → `rename` sang đích (cùng filesystem); `list` duyệt đệ quy, bỏ thư mục
  bắt đầu bằng `.`, so khớp tiền tố **chuỗi** như S3 (`tenants/a` khớp cả `tenants/ab/…`), trả khóa dùng `/` cả trên Windows;
  `head` = `stat` (contentType không lưu — server tĩnh suy theo đuôi; `cacheControl` do Caddy cấu hình, ghi trong README).
  `delete` khóa không tồn tại → không lỗi.
- S3: `@aws-sdk/client-s3` (đã duyệt trong AGENTS.md §4). `PutObject` (ContentType, CacheControl), `DeleteObject`,
  `ListObjectsV2` phân trang bằng `ContinuationToken`, `HeadObject` (404/NotFound → `null`, lỗi khác ném tiếp).
- `publicUrl(key)` = `MEDIA_PUBLIC_BASE` (bỏ `/` cuối) + `/` + key — cả hai driver (CDN/R2 public domain đứng trước).
- Env (`config.ts`, zod): `STORAGE_DRIVER=local|s3` (mặc định `local`), `MEDIA_PUBLIC_BASE` (URL, bắt buộc),
  local: `STORAGE_LOCAL_ROOT` (bắt buộc); s3: `S3_BUCKET` (bắt buộc), `S3_REGION` (mặc định `auto`), `S3_ENDPOINT?`,
  `S3_FORCE_PATH_STYLE?` (`true` cho MinIO), `S3_ACCESS_KEY_ID?` + `S3_SECRET_ACCESS_KEY?` (đi cặp; thiếu cả hai → chain
  mặc định của SDK/IAM role). Lỗi liệt kê **tên** biến thiếu/sai, không in giá trị.
- Luật "không import fs ngoài driver local": `no-restricted-imports` (`fs`, `node:fs`, `fs/promises`, `node:fs/promises`)
  trong `packages/storage/eslint.config.mjs`, bỏ qua cho `src/drivers/local.ts` và `src/__tests__/**`.
- MinIO: image ghim tag `minio/minio:RELEASE.2025-04-22T22-12-26Z` (kiểm tag tồn tại khi chạy `docker pull`; không có →
  chọn tag RELEASE gần nhất có trên Docker Hub, ghi vào report).
  - `scripts/local-ci.sh`: thêm container `solar-local-minio` (cổng `LOCAL_MINIO_PORT`, mặc định 59000) vào `up`, lệnh
    `storage` = tạo bucket (chạy `mc` trong container hoặc `CreateBucket` ở test) rồi
    `pnpm --filter @solar/storage test` với env `STORAGE_S3_TEST_ENDPOINT`…; `down` xóa cả minio.
  - Test s3: bucket test tạo trong `before` (bỏ qua `BucketAlreadyOwnedByYou`), mỗi lần chạy dùng tiền tố ngẫu nhiên.
    Không có `STORAGE_S3_TEST_ENDPOINT` → `describe` s3 **skip** kèm lý do; có `STORAGE_REQUIRE_S3=1` mà thiếu env → **fail**.
  - `checks-map.mjs`: bộ `storage` (`cmd: bash scripts/local-ci.sh storage`, paths `[...shared, "packages/storage/"]`)
    + test trong `checks-map.test.mjs`; `workspace.yml`: output `storage` ở job `changes` + job `storage` (chạy
    `docker run` MinIO, chờ health `/minio/health/live`, `STORAGE_REQUIRE_S3=1`, `pnpm --filter @solar/storage test`).

## Dữ liệu có sẵn chịu ảnh hưởng
Không có — không đổi schema DB, preset, seed; `Media` chưa có bản ghi do code ghi. Không cần dòng conformance.

## Case biên & bất biến
- Bất biến: mọi khóa đi qua `assertKey` trước khi chạm fs/S3 (R9); local không bao giờ ghi/đọc ngoài `root` (R9, symlink
  không cần xử lý — root do ops cấu hình).
- Đồng thời: 2 `put` cùng khóa song song → file cuối là một trong hai nội dung đủ byte, không lẫn (contract › "put đồng thời").
- Thư mục cha chưa có → local tạo (`mkdir recursive`) (R2).
- `list` trên prefix chưa tồn tại → rỗng, không throw (contract › "list rỗng").
- Body rỗng (0 byte) → head size 0 (contract › "file rỗng").
- Secret không xuất hiện trong message lỗi config (R14).

## Ngoài phạm vi
`signedUploadUrl` implement, body stream, quarantine/visibility (E8-S02); biến thể ảnh (E8-S03); route phục vụ file local
trong `apps/web` và cấu hình Caddy (E10-S02 / E8-S03); migrate driver (E8-S06).
