## Thiết kế

### 1. Package `packages/presets` (`@solar/presets`)
```
packages/presets/
  package.json        exports "." → src/index.ts; deps: @solar/sections, @solar/themes, zod
  src/schema.ts       presetSchema
  src/index.ts        presets, getPreset(id), loadPreset(id) → { preset, theme, page, widgets }
  src/__tests__/presets.test.(ts|mjs)
  t15.json
```
`presetSchema` (zod):
```ts
{
  id: string,                       // "t15", "t12", … "t01" (minwy)
  name: string, group: "signature" | "pro" | "classic",
  themeId: string,                  // phải có trong @solar/themes
  description?: string,
  source: { branch: string },       // "template-15", "minwy"… để công cụ so sánh biết branch gốc
  sections: Array<pageSection & { note?: string }>, // data optional: thiếu → defaults của type
  widgets: siteWidgetsSchema,
  subpages?: string[],              // route trang con preset bật (t15: san-pham, giai-phap, cong-trinh, tin-tuc, cam-nang, ve-chung-toi, lien-he, chinh-sach)
}
```
- `loadPreset` trả `page` đã qua `pageConfigSchema` với `data = type.schema.parse(section.data ?? type.defaults)`
  (parse theo schema chung, không có trường riêng của preset).
- `note` chỉ là chú thích cho người đọc (AC chung E4: section gốc thiếu giá trị thay bằng variant gần nhất).
- Test (bắt buộc, chạy cho **mọi** file `*.json` trong package — story sau thêm preset tự được kiểm):
  parse schema; `themeId` có trong `themes`; mọi `type/variant` có thật trong `sectionRegistry`
  (không fallback); `data` parse qua schema của type; widget variant có trong `widgetRegistry`; id/anchor không trùng.

- `apps/web/src/app/page.tsx` render `PageRenderer` với `loadPreset("t15")` (giữ JSON-LD FAQ, lấy câu hỏi từ section

- `t15.json`: 24 khối theo đúng thứ tự `HomePage.tsx`, `site-header` đầu và `site-footer` cuối; `data` lấy từ nội dung
  hiện tại của `site.config.ts`/`data/*` khi khác `defaults` (để ảnh khớp). Khối FeaturedProjects + ProjectsGallery:
  hai section `projects` (id khác nhau); ProjectsGallery dùng `projects/t15` kèm `note` "chờ projects/t12 (E4-S02)"
