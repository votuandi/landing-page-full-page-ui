## Thiết kế
- `packages/storage/src/key.ts`: `VARIANT_WIDTHS = [640, 1280, 1920]`, `VARIANT_FORMATS = ["avif", "webp"]`,
  `variantKey(key, width, format)`: `…/<uuid>.<ext>` → `…/<uuid>-w<width>.<format>` (assertKey; giữ prefix).
- Worker scan: sau khi làm sạch, nếu ảnh tĩnh (`pages` ≤ 1, không GIF động) → 6 lần
  `sharp(body, { limitInputPixels }).resize({ width, withoutEnlargement: true }).avif({ quality: 50 }) | .webp({ quality: 75 })`,
  hạn chót chung 30 s cho cả ảnh (mỗi pipeline `.timeout` = phần còn lại, tối thiểu 1 s). Ghi `private/` với
  `private, no-store`. Lỗi sharp → reject + xóa mọi biến thể đã ghi. Promote lỗi/false → xóa cả biến thể.
- `Promotion.variants?: MediaVariant[]` (`{ key, format, width, height, size }`); `promoteMedia` từ chối biến thể có khóa
  ngoài `private/<tenantId>/` (MediaError). Quota tính theo file gốc (biến thể ≤ 1920px, bị chặn số lượng) — ghi trong
  README packages/storage.
- Publish: parse `variants` bằng zod; hợp lệ → chép từng biến thể sang `tenants/` (immutable), CAS cập nhật
  `{ key, visibility, variants: <khóa tenants/> }`, rồi xóa private gốc + biến thể. Nhánh recovery xóa cả biến thể private.
- Admin `/media`: Server Component, `media.view`, 50 bản ghi mới nhất (`mime, size, status, variants, createdAt`), bảng có
  `<caption>`, nhãn trạng thái bằng chữ (không chỉ màu), class token. E8-S05 thay bằng thư viện đầy đủ.
