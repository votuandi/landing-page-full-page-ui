## Mục tiêu
Preset Tailwind nằm trong `@solar/tokens`, sinh class **chỉ** từ token của `ThemeTokens` (màu, bo góc, bóng, kính,
motion, khoảng cách section, font). Màu mặc định của Tailwind không sinh CSS; `bg-primary/20` vẫn chạy. Có test
chạy Tailwind thật để chứng minh.

## Bối cảnh đã khảo sát
- Preset hiện tại: `packages/config/tailwind.preset.mjs` (export `@solar/config/tailwind`), đã thay `theme.colors`
  bằng `rgb(var(--c-<key>) / <alpha-value>)` nhưng liệt kê tay; `borderRadius.card` cứng `28px`; `boxShadow` dùng
  `--c-shadow` với alpha cứng; chưa có `pill/media/input/button`, `backdropBlur.glass`, `transitionDuration.motion*`,
  `spacing.section`, `fontFamily.display`. README `packages/config` ghi "Preset sẽ chuyển sang `packages/tokens` ở E2".
- Người dùng duy nhất: `apps/web/tailwind.config.ts` (`presets: [preset]`, content gồm `packages/ui/src`).
- `packages/tokens/src/schema.ts`: `COLOR_KEYS` (35 khóa kênh "R G B"), `GLASS_COLOR_KEYS` (4 khóa `rgba(...)`),
  `radius.{card,pill,media,input,button}`, `shadow.{strength,tint}`, `glass.blur`, `motion.duration*`, `density.sectionY`
  (`sm|md|lg`), `font.{sans,display}`.
- `packages/tokens/src/css.ts` (`themeToCss`, E2-S02) đã phát `--c-*`, `--glass*`, `--radius-*`, `--shadow-strength`,
  `--glass-blur`, `--motion-fast|base|slow`, `--motion-ease`, `--container`. **Chưa** phát biến cho `density.sectionY`.
- t15 (`packages/themes/t15/theme.ts`): radius card 28px (khớp giá trị cứng hiện tại), `shadow.strength: 1`,
  `sectionY: "md"`. Section t15 dùng chủ yếu `py-16 md:py-20`.
- Class đang dùng trong `apps/web/src` + `packages/ui/src`: `rounded-full` 116, `rounded-2xl` 44, `rounded-3xl` 16,
  `rounded-xl` 11, `rounded-card` 5; `shadow-sm|lg|xl|2xl`; `backdrop-blur*` 28; `duration-300|500|700`.
- Test của tokens: `node:test`, biên dịch `tsconfig.test.json` (commonjs, rootDir `src`) rồi chạy file `.test-dist`.

## Thiết kế
- File: `packages/tokens/src/tailwind-preset.ts` (đặt trong `src/` thay vì gốc package để khớp `tsconfig` include và
  `rootDir` của test hiện có). Export default preset kiểu `Omit<Config, "content">` (`import type` từ `tailwindcss` —
  không có import runtime của tailwind). Subpath mới trong `package.json`: `"./tailwind": "./src/tailwind-preset.ts"`.
- `theme.colors` (thay hẳn, không `extend`): sinh từ `COLOR_KEYS` → `rgb(var(--c-<key>) / <alpha-value>)`, từ
  `GLASS_COLOR_KEYS` → `var(--<key>)`, cộng `transparent`, `current`, `inherit`. Khóa phẳng (`"bg-elevated"`) cho ra
  đúng tên class như bản liệt kê tay (`bg-bg-elevated`, `text-fg-muted`, `bg-primary`), và tự đồng bộ khi schema thêm màu.
- `theme.extend`:
  - `borderRadius`: `card|pill|media|input|button` → `var(--radius-<key>)`.
  - `boxShadow`: giữ 4 bậc `sm|lg|xl|2xl` hiện có (cùng hình dạng), alpha = `calc(<alpha cũ> * var(--shadow-strength))`
    trên `rgb(var(--c-shadow) / …)`. t15 có `strength: 1` nên giữ nguyên hình ảnh.
  - `backdropBlur.glass` → `var(--glass-blur)`.
  - `transitionDuration`: `motion-fast|motion-base|motion-slow` → `var(--motion-fast|base|slow)` (class
    `duration-motion-base`…).
  - `spacing.section` → `var(--section-y)` (class `py-section`, `pt-section`…).
  - `fontFamily`: `sans` → `var(--font-sans), system-ui, sans-serif`; `display` → `var(--font-display, var(--font-sans)),
    system-ui, sans-serif` (biến `--font-display` do E2-S06 gắn; fallback về sans tới khi có).
  - Giữ nguyên phần còn lại của preset cũ: `fontSize.2xs`, `fontWeight.black: 800`, `opacity` 6/8/12/15,
    `backgroundImage.media-glow`.
- `themeToCss` thêm `--section-y` từ `density.sectionY`: `sm` → `64px`, `md` → `80px`, `lg` → `112px` (md = `py-20`
  mà t15 đang dùng ở desktop). Cập nhật test css tương ứng.
- **Không cấm** thang `borderRadius`/`boxShadow` mặc định của Tailwind (`rounded-3xl`, `rounded-2xl`… vẫn sinh CSS):
  AC ghi "(nếu bị cấm)"; cấm lúc này sẽ vỡ ~70 chỗ trong `apps/web` và lệch baseline t15 của E2-S02. Việc chuyển sang
  `rounded-card|media|…` thuộc lúc port section (E3) / E2-S07. Test ghi rõ hành vi này.
- Xóa `packages/config/tailwind.preset.mjs` và subpath `./tailwind` của `@solar/config` (gỡ `tailwindcss` khỏi
  devDependencies của config nếu không còn dùng). `apps/web/tailwind.config.ts` import `@solar/tokens/tailwind`,
  content thêm `../../packages/sections/src/**/*.{ts,tsx}` (package chưa có, glob rỗng không lỗi).
- devDependencies mới của `@solar/tokens`: `tailwindcss` (cùng bản `3.4.19` đã có trong lockfile), `postcss` (cùng bản
  resolved của `apps/web`) — chỉ cho type và test, không phải dependency runtime.

## Các bước
1. Tạo `packages/tokens/src/tailwind-preset.ts` theo Thiết kế; thêm subpath `./tailwind` và devDependencies
   — file: `packages/tokens/package.json` — kiểm bằng: `pnpm --filter @solar/tokens typecheck`.
2. `themeToCss` phát `--section-y` — file: `packages/tokens/src/css.ts`, `src/__tests__/css.test.ts` — kiểm bằng test css.
3. Test `packages/tokens/src/__tests__/tailwind-preset.test.ts` (thêm vào script `test`): chạy
   `postcss([tailwindcss({ presets: [preset], content: [{ raw }], corePlugins: { preflight: false } })])` trên
   `@tailwind utilities`, khẳng định:
   - `bg-white`, `text-slate-500`, `bg-red-500`, `border-gray-200` **không** có trong CSS ra.
   - `bg-primary/20` sinh `rgb(var(--c-primary) / 0.2)`; `text-fg-muted`, `bg-bg-elevated`, `bg-glass` sinh đúng biến.
   - mọi khóa trong `COLOR_KEYS` sinh được `bg-<key>`.
   - `rounded-card|pill|media|input|button` → `var(--radius-*)`; `shadow-lg` chứa `--shadow-strength`;
     `backdrop-blur-glass` → `var(--glass-blur)`; `duration-motion-base` → `var(--motion-base)`;
     `py-section` → `var(--section-y)`; `font-display` → `--font-display`.
   - `rounded-3xl` vẫn sinh CSS (khẳng định quyết định "không cấm", để story sau đổi có chủ đích).
4. Chuyển `apps/web/tailwind.config.ts` sang `@solar/tokens/tailwind`, thêm content glob `packages/sections`; xóa
   `packages/config/tailwind.preset.mjs` + subpath; cập nhật README `packages/config` và `packages/tokens`
   — kiểm bằng: `pnpm --filter web typecheck lint` và `pnpm --filter web build` cục bộ (đảm bảo Tailwind nạp được preset
   `.ts` qua jiti; không bắt buộc theo buildPolicy nhưng cần để chứng minh preset chạy trong app).
5. Tick AC trong `roadmap/epics/E02-tokens-themes.md`.
