## Mục tiêu
Video tự host (gói Cao cấp) đi cùng pipeline media E8-S02/S03: worker kiểm video bằng `ffprobe`, cắt một khung bằng
`ffmpeg` làm **poster tự sinh** (biến thể ảnh AVIF/WebP như S03), lưu nguyên file. Story có `source.provider = "file"` trỏ
tới Media UUID được apps/web đổi thành URL công khai của driver (local hoặc S3/R2) khi render, nên Shorts phát được.

## Thiết kế
- **Worker** `apps/worker/src/video.ts`: `probeVideo(path)` (ffprobe `-v error -print_format json -show_format -show_streams`)
  → `{ duration, width, height }` hoặc lỗi `InvalidVideoError`; `posterFrame(path, at)` (ffmpeg `-ss at -i path -frames:v 1
  -f image2pipe -vcodec png -`) → Buffer. `spawn` không shell, đường dẫn `FFMPEG_PATH`/`FFPROBE_PATH` (mặc định PATH), timeout
  60 s → `SIGKILL`, giới hạn stdout 50 MB. Ghi bytes vào `mkdtemp(os.tmpdir())`, `finally` xóa. Inject vào `createMediaScan`
  (`video?: { probe, frame }`) để test fake.
- `mediaScan`: `format.kind === "video"` → probe (duration > 600 hoặc không stream video → reject) → frame → nguồn của
  vòng biến thể = PNG khung (cùng sharp, cùng `variantKey(videoKey, …)`), `width/height` từ probe. File gốc lưu nguyên.
- `mediaPublish`: sau `media.publish` thành công, enqueue `invalidationJob([`tenant:${tenantId}`])` qua outbox của tenant
  (đường ghi outbox Codex chọn theo `mediaRuntime.ts`).
- **Schema**: refine `file` = `localPath || z.uuid()`. Không đổi hình dạng → không tăng `schemaVersion`, không migration
  (dữ liệu cũ vẫn hợp lệ; ghi lý do trong PR).
- **Render**: `PageRendererProps.resolveData?: (input: { section, data, site }) => unknown | Promise<unknown>` chạy **sau**
  lần parse cuối (dữ liệu server tin cậy, không parse lại). apps/web `apps/web/src/lib/tenant/media.ts`
  `createMediaResolver(tenantId, storage)`: duyệt data tìm object `{ provider: "file", idOrSrc: <uuid> }`, một truy vấn
  `media.list({ id in, status: "ready", visibility: "public", mime startsWith "video/" })`, khóa phải `tenants/<tenantId>/`
  → `storage.publicUrl(key)`. Không phân giải → bỏ item trong mảng / bỏ thuộc tính video tùy chọn (R11). Poster fallback
  R12. Gắn vào `cached.tsx`, `SystemPages.tsx` (cả chrome). E8-S07 mở rộng resolver này cho ảnh.
- `mediaSrc` nhận thêm `http:` **chỉ** cho host `localhost`/`127.0.0.1` (dev/e2e; prod dùng https CDN). Test.
- **Gói**: feature `videoUpload` ("Video tự host") trong premium; reserve kiểm `assertCan(site, "videoUpload")` khi `kindOf(mime) === "video"`.
- **E2E local**: `tooling/visual/media-server.mjs` (node:http, chỉ GET/HEAD `/media/tenants/*` từ `STORAGE_LOCAL_ROOT`,
  hỗ trợ `Range` → 206, `nosniff`, prefix khác 403 — giống Caddy) làm webServer thứ 2 của tenant config, `MEDIA_PUBLIC_BASE=http://localhost:3212/media`.
  Fixture ghi mp4 + 1 biến thể webp vào `tenants/<t>/…` và Media ready/public, item shorts `{file, <uuid>}`.
- **CI**: job chạy worker int test cài `ffmpeg` (apt); test ffmpeg thật skip có lý do khi thiếu, fail khi `MEDIA_REQUIRE_FFMPEG=1` (CI đặt).
