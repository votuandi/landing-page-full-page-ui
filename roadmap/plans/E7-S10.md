## Mục tiêu
Owner tải về bản sao lưu JSON của site (nội dung + danh sách media); super admin khôi phục bản đó thành một **tenant mới**
(nhân bản site, chuyển máy chủ) cho site render giống hệt. Bản xuất không chứa tài khoản, phiên, bí mật.

## Bối cảnh đã khảo sát
- Model tenant: `packages/db/prisma/schema.prisma` (Site, Page, PageVersion, SectionContent, 12 collection, Media, Lead…);
  danh sách `tenantModels` ở `packages/db/src/tenantScope.ts`. Mọi id là uuid toàn cục (`@id`) → khôi phục phải **đổi id**.
- RLS: `tenantTransaction(db, tenantId, tx => …)` (`packages/db/src/tenantTransaction.ts`) đặt `app.tenant_id`.
  Ref chéo tenant: `assertRefsBelongToTenant` + `collectRefs` (`packages/db/src/refs.ts`, `@solar/sections`).
- Mẫu tạo tenant + site + page + section: `seedDemoTenant` (`packages/db/prisma/seed-demo.ts:31`). Mẫu script platform:
  `packages/db/scripts/import-site-config.ts` + `forPlatform`. Mẫu route admin có quyền: `apps/admin/src/app/api/san-pham/csv/route.ts`
  (`route(permission, handler)` trong `apps/admin/src/lib/action.ts`, đã đặt `private, no-store`).
- Quyền: `packages/auth/src/permissions.ts` — `admin` = owner trừ `users.transferOwner`; phiên ghost (super admin hỗ trợ,
  E15) nhận quyền owner.
- Storage: `StorageDriver` (`packages/storage/src/types.ts`) chưa có hàm đọc → không sao chép file được.
- `apps/console` chưa có (E15-S02/S03) → đường "super admin" hiện là script platform; nút trong console thuộc E15-S03.
- Branch `develop`: `src/lib/backup.ts` dump JSON toàn DB + zip `public/` — chỉ học ý tưởng, không port (toàn DB thuộc E10-S06).
- Truy vấn: `codegraph sync`; grep `storageFromEnv`, `seedDemoTenant`, `tenantModels`, `route(`; `git show origin/develop:src/lib/backup.ts`.

## Thiết kế
- `packages/db/src/tenantBackup.ts`:
  - `BACKUP_FORMAT = "solar-tenant-backup"`, `version: 1`; `tenantBackupSchema` (zod) — `{ format, version, exportedAt,
    source: { tenantId, slug }, site, pages, pageVersions, sectionContents, collections: { product: [], productCategory: [], … },
    media: [] }`. Mỗi bản ghi giữ `id` cũ (để đổi id), bỏ `tenantId`.
  - `exportTenant(db, tenantId)` đọc qua `forTenant`/`tenantTransaction` (một transaction `RepeatableRead` để nhất quán).
    **Loại trừ**: SiteUser, SiteSession, SiteToken, PreviewToken, GhostGrant, Domain (hostname unique), Lead (PII —
    xuất lead đã có ở trang Lead), LeadIntegration (bí mật mã hóa), Outbox, AuditLog. `PageVersion.publishedBy*` → null.
  - `remapBackup(bundle, newTenantId)` thuần: map id cũ → `randomUUID()` mới cho mọi bản ghi; duyệt sâu JSON thay chuỗi
    **bằng đúng** id cũ và thay tiền tố `tenants/<oldTenantId>/` trong mọi chuỗi; key media mới giữ phần đuôi.
  - `restoreTenant(db: PlatformDb, storage, bundle, { slug, name?, planId })`: parse schema (sai format/version → lỗi
    tiếng Việt 400); slug trùng → 409 trước mọi thao tác; sinh `tenantId` trước; sao chép file media (`storage.get` →
    `put`) trước transaction; một transaction tạo Tenant (`status: "trial"`) + mọi bản ghi theo thứ tự FK (media →
    productCategory theo cây cha trước con → brand → collection khác → site → page → sectionContent → pageVersion), cuối
    transaction gom `collectRefs` của mọi section/collection và `assertRefsBelongToTenant` (id ngoài bundle → rollback).
    Transaction lỗi → xóa file đã sao (best-effort). Ghi AuditLog `tenant.backup.restore` (`actorType: "system"`/platform,
    `data: { sourceSlug, counts }`).
- `packages/storage`: thêm `get(key): Promise<Uint8Array | null>` vào `StorageDriver`, local (fs) + S3 (`GetObject`), cùng `assertKey`.
- `packages/auth`: thêm permission `site.backup` ("Sao lưu website"), owner có, `admin` không (như `users.transferOwner`).
- `apps/admin`: `GET /api/sao-luu` = `route("site.backup", …)` → `Content-Disposition: attachment; filename="<slug>-backup-<ngày>.json"`,
  ghi AuditLog `tenant.backup.export`. Trang `cai-dat`: khối "Sao lưu" với link tải, chỉ hiện khi có quyền.
- Scripts `packages/db/scripts/tenant-export.ts` (`--tenant <slug> --out <file>`) và `tenant-restore.ts`
  (`<file> --slug --plan [--name]`), lệnh `tenant:export`, `tenant:restore` trong `package.json`.
- Không thêm dependency (không zip: media nằm ở storage, bundle chỉ liệt kê; chuyển máy chủ đồng bộ storage ở E10-S06).
