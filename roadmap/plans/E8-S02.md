## Thiết kế
**Ba prefix** (sửa câu khóa media trong `AGENTS.md` §4 cho khớp): public `tenants/<tid>/yyyy/mm/<uuid>.<ext>` (đã có),
private `private/<tid>/yyyy/mm/<uuid>.<ext>`, cách ly `quarantine/<tid>/<uuid>`. Chỉ `tenants/` được phục vụ public:
`publicUrl()` ném lỗi với key khác; README `packages/storage` có bucket policy (`public-read-policy.json`, chỉ `tenants/*`)
và đoạn Caddy/route local tương ứng; test MinIO dùng đúng file policy đó.

`packages/storage`: `sniff(bytes) → {mime, ext, kind: image|video|pdf} | null` (JPEG, PNG, WebP, GIF, AVIF, MP4/MOV `ftyp`,
WebM EBML, PDF `%PDF-`; SVG/HTML/khác → null), `UPLOAD_LIMITS = {image: 15 MB, video: 200 MB, pdf: 20 MB}`,
`kindOf(mime)`, `quarantineKey/privateKey`; s3 `signedUploadUrl(key, {contentType, contentLength, expiresIn 900})` ký
`Content-Type` + `Content-Length`; local không có presign.

`packages/db/src/media.ts`:
- `reserveUpload(db, tenantId, {mime, size})`: `tenantTransaction` → `SELECT … FROM "Tenant" WHERE id=… FOR UPDATE` →
  `used = SUM(size) WHERE status IN (quarantine, ready)` (SQL `::bigint`) → `used + size > mediaGb·1024³` → `MediaQuotaError`
  (413); tạo `Media{key: quarantine…, status: quarantine, visibility: private, mime: declared, size: declared}`. Hàng
  quarantine **là** phần đặt chỗ (`reservedBytes` = tổng size quarantine; không có bộ đếm riêng để khỏi lệch).
- `mediaUsage(repo)` dùng chung cho quota và dashboard. `completeUpload` → outbox `media.scan` (idempotency `media.scan:<id>`).
  `cancelUpload` → xóa hàng quarantine (trả chỗ). Hàm worker: `promote`, `reject` (status failed, AuditLog `media.rejected`),
  `expireStale(now)` (quarantine > 24 h → failed, trả về key để xóa), `publishMedia(ids)`.
- Publish: `publishPage` và `saveCollectionItem(published)` gom `collectRefs(...).media` → enqueue `media.publish` cho id
  `private`+`ready` trong cùng transaction.

Admin routes (`media.manage`, trừ GET = `media.view`):
`POST /api/media {mime, size}` → 201 `{id, upload: {method: "PUT", url, headers}}` (s3: presigned; local:
`/api/media/<id>/upload`) · `PUT /api/media/<id>/upload` (chỉ driver local, đọc stream có trần = size đặt chỗ, vượt → 413;
driver s3 → 409) · `POST /api/media/<id>/complete` (head quarantine phải có, size ≤ đặt chỗ) · `DELETE /api/media/<id>`
(chỉ quarantine) · `GET /api/media/<id>` (ready, tenant hiện tại, stream với `nosniff`, `private, no-store`).

Worker: topic `media.scan` (get → size ≤ đặt chỗ → sniff → kind khớp kind của mime khai báo → size ≤ `UPLOAD_LIMITS` → ảnh:
`sharp(…, {animated: true}).rotate()` xuất lại cùng định dạng, không metadata, lấy width/height → put key private, content-type
= mime **đã sniff** → `promote` có điều kiện `status=quarantine` → xóa object quarantine; lỗi nội dung → `reject` + xóa
object, job vẫn complete); topic `media.publish` (private → `tenants/…`, cập nhật key + visibility, xóa private); cron 1 h
`expireStale` + xóa object. Worker dùng `storageFromEnv()`.

## Case biên & bất biến
- Không tin tên file/mime/size client: content-type lưu = mime sniff; key luôn do server sinh (UUID), không dùng tên file.
- Đặt chỗ nguyên tử dưới khóa hàng Tenant; size ≤ 0, không phải số nguyên, > giới hạn loại → 400 trước transaction.
- `mediaGb` = 0 / gói lạ → mọi đặt chỗ bị từ chối; override `limitOverrides.mediaGb` được tính.
- Scan idempotent: job chạy lại khi hàng đã ready/failed → no-op; object quarantine mất → reject.
- Crash giữa put và promote → retry tạo key mới; object cũ để E8-S06 dọn (ghi chú README).
- Route upload local: body vượt trần dừng đọc ngay (không buffer hết), không ghi object dở.
- Id không phải UUID / của tenant khác / còn quarantine → 404 như nhau (không lộ tồn tại).
- Không có cookie/phiên trong code cache; GET private trả `private, no-store`.
- Mọi media mới `visibility=private`; chỉ `media.publish` đổi thành public.
