## Thiết kế

### Workspace và giai đoạn chuyển tiếp

- `pnpm-workspace.yaml` khai báo đúng apps/* và packages/*. Package thực tế đầu tiên là @solar/config; chưa tạo app web/admin giả hoặc package nghiệp vụ rỗng.
- Root package giữ tên, dependencies app và script trực tiếp hiện tại. Thêm engines.node=">=20.9" (không chặn máy dev đang Node 20; `.nvmrc`/CI mới là chuẩn Node 22), packageManager cố định bản pnpm 10.x ổn định mới nhất lúc thực thi (ghi số cụ thể, vd. pnpm@10.x.y) và devDependency turbo pin chính xác bản 2.x ổn định mới nhất; không dùng range/latest trôi nổi. `.nvmrc` chứa 22. Cài bằng đúng phiên bản đã pin trên dev và CI.
- Root khai báo devDependency @solar/config=workspace:*. Mọi dependency trực tiếp được khai báo tại package sử dụng; không bật shamefully-hoist để che lỗi phân giải.
- Dùng pnpm import khi yarn.lock còn tồn tại để giữ các phiên bản resolved, sau đó cài workspace và sinh pnpm-lock.yaml hoàn chỉnh. Chỉ xóa yarn.lock sau khi frozen install thành công; không giữ hai lockfile quản lý song song. [Tài liệu pnpm import](https://pnpm.io/cli/import).
- Chỉ thêm dependency phục vụ build/lint: turbo, @solar/config, @eslint/js và @eslint/eslintrc. Ghi lý do trong PR; không thêm dependency runtime. Giữ ESLint 8.57.1; dùng @eslint/js cùng 8.57.1 và @eslint/eslintrc 2.1.4 đã có trong Yarn lock.

### Package cấu hình

- `packages/config/package.json`: private, name=@solar/config, type=module; export ./tsconfig.base.json, ./eslint và ./tailwind tới các file cấu hình. Cấu hình là JSON/ESM trực tiếp, không cần build hoặc dist.
- `packages/config/tsconfig.base.json`: đưa các compilerOptions dùng chung từ root vào đây, giữ strict, moduleResolution=bundler, target và module hiện có. Không đưa alias, baseUrl, include/exclude, plugin Next hoặc đường dẫn output của consumer vào base.
- Root tsconfig extends @solar/config/tsconfig.base.json, giữ phần Next/alias/include cục bộ, exclude packages và apps trong giai đoạn S01 để typecheck root không vô tình kiểm mọi workspace. Cấu hình test giữ độc lập.
- `packages/config/eslint.config.mjs`: export cấu hình base cho JS/ESM từ @eslint/js và factory cấu hình Next dùng FlatCompat với next/core-web-vitals. BaseDirectory của compat trỏ nơi có eslint-config-next được khai báo trong config package; settings.next.rootDir nhận đường dẫn app của consumer. [Next.js 15: FlatCompat và rootDir](https://nextjs.org/docs/15/app/api-reference/config/eslint#specifying-a-root-directory-within-a-monorepo).
- Root `eslint.config.mjs` dùng factory Next; config package dùng base cho chính các file ESM. Khai báo dependency/peer tương thích rõ ràng cho eslint, eslint-config-next và các module import trực tiếp. Xóa .eslintrc.json sau khi kiểm tương đương.
- Flat config bổ sung ignore rõ ràng cho node_modules, .next, .test-dist, .turbo, coverage, build/dist/out và thư mục công cụ ẩn của repo. Root lint bỏ apps/packages vì package tự lint; vẫn kiểm src và script/config gốc như trước. Không nới rule hoặc tắt kiểm lint trong Next build.
- `packages/config/tailwind.preset.mjs`: chuyển nguyên theme/plugins hiện tại sang ESM với JSDoc import type Config từ tailwindcss; không chứa content glob. Root tailwind.config.ts chỉ import preset và giữ content glob. Giữ theme.colors thay hẳn bảng màu, không chuyển thành extend.colors; không thay tên token hay CSS.
- `packages/config/tsconfig.json`: extends base, allowJs/checkJs, chỉ include file ESM của config, noEmit. Scripts typecheck=tsc -p tsconfig.json và lint=eslint . phải kiểm file thực; khai báo typescript/tailwindcss cùng phiên bản app. README package mô tả export và việc preset sẽ chuyển sang packages/tokens ở E2.

### Task graph và cache

- `turbo.json` dùng tasks của Turbo 2; khai báo build, dev, lint, typecheck, test, lint:tokens. Build dependsOn=["^build"], outputs gồm .next/** trừ .next/cache/** và dist/**. Dev persistent=true, cache=false.
- Lint/typecheck lần lượt dependsOn=["^lint"]/["^typecheck"] để thay đổi dependency không để lại cache cũ; chưa cần ^build cho config dạng source. Test dependsOn=["^build"], outputs .test-dist/**. Typecheck khai báo output *.tsbuildinfo tương ứng; lint không có output file.
- Đăng ký root task //#build, //#dev, //#lint, //#typecheck, //#test để pnpm turbo run typecheck lint test build bao phủ app còn nằm ở gốc. Root lint/typecheck có phụ thuộc rõ vào @solar/config#lint/@solar/config#typecheck; build/test dùng cấu hình và dependency graph thích hợp. Root scripts tiếp tục gọi công cụ trực tiếp, tuyệt đối không gọi Turbo từ root task cùng tên gây đệ quy. Đây là cơ chế chuyển tiếp được [Turborepo hỗ trợ](https://turborepo.com/docs/crafting-your-repository/configuring-tasks#registering-root-tasks).
- globalDependencies khai báo cụ thể package manifest, tsconfig.base.json, eslint.config.mjs, tailwind.preset.mjs của config; không glob output/cache. Khi sửa cấu hình dùng chung, task consumer phải cache miss. Khai báo env ảnh hưởng build theo biến thực tế của app, không lưu secret trong file hoặc log.
- Chỉ đăng ký lint:tokens với outputs rỗng; chưa thêm script giả trả thành công. AC S01 không yêu cầu triển khai checker; E1-S06/E2 sẽ cung cấp checker và script thật. README phải nói rõ task này chưa có checker.
- E1-S02 sẽ chuyển dependencies/scripts app sang package web, bỏ root task chuyển tiếp tương ứng và dùng wrapper Turbo ở root. S01 chưa quảng cáo pnpm --filter web là lệnh chạy được.
