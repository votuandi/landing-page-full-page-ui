# Plan E12-S04 — Sửa nội dung trực tiếp (inline) cho văn bản

- Story: roadmap/epics/E12-builder.md · Cỡ: M · Loại: ui · Mode: split (Codex dựng, Claude design pass + spec e2e) · Reviewer: claude

## Mục tiêu
Trong `/trang/<id>/builder`, nhấp đúp vào chữ ngắn (tiêu đề, nhãn nút) của section đang chọn trên canvas → sửa ngay tại chỗ,
chỉ text. Enter/bấm ra ngoài → chốt, giá trị vào form của section, qua zod rồi mới lưu nháp. Trường dài/phức tạp vẫn sửa ở
bảng thuộc tính (SchemaForm). Không sửa code của 30 type section.

## Bối cảnh đã khảo sát
- Canvas: `apps/web/src/components/preview/BuilderCanvas.tsx` (overlay `fixed`, click capture chọn section, `handle`),
  `PreviewBridge.tsx` (nhận lệnh, `refresh` → `router.refresh`), `builderMode.ts` (hàm thuần + test).
- Protocol: `packages/cms-ui/src/preview/protocol.ts` (parser nghiêm), `PreviewFrame.tsx` (`handle.post`, chỉ chuyển sự kiện trong danh sách).
- Admin: `builder/Builder.tsx` (`forms`, `selectedId`, `onEvent`), `BuilderPanel.tsx` (`useAutosave` `valid: validate(def.schema)` → chỉ lưu khi zod qua; `saveSectionContent` server validate lại).
- Trường: `localized()` đăng ký widget `localized` / `localizedTextarea`; nút = widget `link` có `label` localized.
  `describe`, `unionIndex` (`schema/describe.ts`), `getAt`/`setAt` (`schema/path.ts`), `pickLocale` (client-safe).
- Variant hiển thị chữ bằng `t(value)` = `pickLocale(value, site.locale)` → mỗi trường thành một Text node riêng (vd. hero t15
  `<span className="t15-gradient-text">{t(data.title.highlight)}</span>`).
- Truy vấn: `codegraph_explore "BuilderCanvas PreviewBridge builderMode protocol PreviewFrame"`, `"Builder BuilderPanel saveSectionContent SchemaForm"`, `"describe FieldNode setAt getAt localized widget"`.

## Thiết kế
**cms-ui `packages/cms-ui/src/sections/inline.ts`** (export ở `index.ts`):
- `type InlineField = { path: Path; text: { vi: string; en?: string } }`.
- `inlineFields(schema, data): InlineField[]` — duyệt `describe(schema)` song song với `data`: widget `localized` → `{ path, text: value }`;
  widget `link` có `label` → `{ path: [...path, "label"], text: label }`; object/array/record theo giá trị; union theo `unionIndex`;
  bỏ `localizedTextarea`, `richText`, `media`, `collectionQuery`, giá trị vắng (optional). Một hàm duy nhất quyết định "trường ngắn".
- `applyInlineEdit(schema, data, { path, locale, text }) → { data, valid, error? } | null` — `null` khi path không nằm trong
  `inlineFields(schema, data)` (iframe không ghi được path tùy ý). Chuẩn hóa `text.replace(/\s+/g, " ").trim()`; `en` rỗng → bỏ khóa
  `en` (như `LocalizedField`). `valid`/`error` từ `validate(schema, next)` để test AC2; lưu vẫn do autosave quyết định.

**Protocol** (`protocol.ts`): lệnh `fields { sectionId, fields: InlineField[] }` — ≤ 300 mục, path 1…8 đoạn (chuỗi `^[A-Za-z0-9_]{1,40}$`
hoặc số nguyên 0…999), `vi`/`en` chuỗi ≤ 2000; sai một mục → cả lệnh null. Sự kiện `inline { sectionId, path, locale: "vi"|"en", text ≤ 2000 }`.
`PreviewFrame`: thêm `inline` vào danh sách sự kiện chuyển cho `onEvent`.

**Admin `Builder.tsx`**: `editable = canEditContent && !conflict && form && !form.readOnly`. Effect theo `[selectedId, data của form đang chọn,
editable]` → `preview.post(fields)` (không editable → `fields: []`); sự kiện `ready` gửi lại (post trước `ready` bị bỏ). Sự kiện `inline`:
bỏ qua khi `sectionId !== selectedId` hoặc không editable; `applyInlineEdit` null → bỏ qua; có kết quả → cùng `setForms` như `onChange`
của `BuilderPanel` → autosave (zod) → `saveSectionContent` → `refresh`. Cập nhật câu hướng dẫn: "Nhấp đúp vào chữ trên canvas để sửa trực tiếp".

**Iframe** (`builderMode.ts` thuần + `BuilderCanvas`):
- `matchInline(texts, fields, locale) → Map<textIndex, InlineField>`: hiển thị = `pickLocale(field.text, locale).trim()`, rỗng bỏ; chỉ giữ
  cặp mà chuỗi xuất hiện **đúng một lần** trong các Text node của section và **đúng một lần** trong `fields` → không bao giờ ghi nhầm trường.
- `insertPlain(value, start, end, pasted) → { value, caret }` (gộp `\s+` thành một khoảng trắng).
- `handle` thêm `fields(sectionId, list)` và `commit()`. Locale = `document.documentElement.lang === "en" ? "en" : "vi"`.
- Hover trong section đang chọn: chữ khớp → hộp `data-builder-editable` (overlay, theo `Range.getBoundingClientRect`). Nhấp đúp
  (capture, `preventDefault`) → bật sửa: nút chữ T, cha P. Lưu `original = T.nodeValue`, `snapshot = [...P.childNodes]`, thuộc tính
  `contenteditable` cũ; đặt `P.contentEditable = "plaintext-only"` (trình duyệt không hỗ trợ → `"true"`), focus, caret tại điểm nhấp
  (`caretPositionFromPoint`/`caretRangeFromPoint`, không có → cuối T). Hộp `data-builder-inline` + `data-path="title.highlight"`.
- **Bất biến**: suốt phiên sửa, `P.childNodes` là đúng các node của `snapshot`; chỉ `T.nodeValue` đổi. Lý do: React cập nhật chữ bằng
  `nodeValue`/`textContent` → sau `router.refresh` reconcile đúng; nếu thêm/xóa node (`<br>`, `<b>`, xóa icon) React sẽ lỗi `removeChild`.
  `input` (không composing) và `compositionend`: lệch snapshot → `P.replaceChildren(...snapshot)` + `T.nodeValue = lastGood`; không lệch → `lastGood = T.nodeValue`.
- `beforeinput`: `insertParagraph`/`insertLineBreak` → chặn + chốt; `format*`, `history*`, `insertFromDrop` → chặn; target range ra ngoài T → chặn.
  `paste` → chặn mặc định, chỉ đọc `text/plain`, `insertPlain` tại vùng chọn trong T. Ctrl/Cmd+A → chọn trong T.
- Chốt: Enter, `focusout`, `commit()`; text đã chuẩn hóa khác `original.trim()` → `onEvent(inline)`. Escape → `T.nodeValue = original`, không gửi.
  Kết thúc luôn khôi phục `contenteditable` cũ và bỏ hộp.
- `PreviewBridge`: `fields` → `canvas.fields`; nhận `refresh`, `select` khác section, hoặc `fields` của section khác → `canvas.commit()` trước
  (không mất chữ đang gõ). Không bật sửa khi đang kéo hoặc khi `refresh` đang chạy (`pending`).
- Không đổi render ở trang công khai: chỉ chạy trong `BuilderCanvas` (`dynamic`, `ssr:false`, chỉ khi `?builder=1` trong iframe).

## Design pass (Claude)
Hộp hover/đang sửa (viền token `primary`, đứt nét khi hover, liền khi sửa, `cursor-text`), chip gợi ý "Nhấp đúp để sửa" (chỉ hover, không che chữ),
focus ring đủ tương phản trên nền tối/gradient, câu hướng dẫn admin, reduced motion. Codex dựng cấu trúc, logic, test unit.

## Rủi ro / câu hỏi mở
