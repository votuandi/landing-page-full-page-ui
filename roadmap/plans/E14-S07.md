## Thiết kế (đã chốt)
1. **`README.md` gốc viết lại** (≤ ~8 KB), thay hẳn nội dung template-15: dự án là gì (2–3 câu, link `AGENTS.md` §1–2),
   **Quickstart** đánh số từ máy trắng (Node 22 + Corepack pnpm 10.34.6 → `pnpm install --frozen-lockfile` →
   `bash scripts/local-ci.sh up` → `source <(bash scripts/local-ci.sh env)` → chép `.env.example` → `pnpm --filter web dev`
   / admin / worker, kèm URL + tài khoản seed), bảng app/package → README, "Làm một story" (`story.mjs next`,
   `/run-story`, `TESTING.md`), "Tài liệu khác" (runbook, docs-public, roadmap). Lý do: README gốc là trang đầu tiên dev
   mới đọc; nội dung cũ chỉ dẫn sai đường (AC fail ngay bước 1). Không chép lại chi tiết đã có trong README package —
   chỉ link (tránh hai nguồn lệch nhau).
2. **`docs-public/cms/`** — hướng dẫn khách, tiếng Việt, không thuật ngữ dev: `README.md` (mục lục) + một file mỗi nhóm:
   `dang-nhap.md` (đăng nhập, quên mật khẩu, 2FA, mời nhân viên), `trang-va-noi-dung.md` (trang, section, bản nháp/xem
   trước/xuất bản, collection), `media.md`, `lead.md` (xem, xuất CSV, kênh nhận lead), `giao-dien-ten-mien.md` (giao diện,
   tên miền, email gửi, gói). Viết theo đúng nhãn UI đang có (Codex đọc page/component để lấy nhãn thật), mỗi bước là
   hành động trên màn hình. Tính năng chưa có → không viết.
3. **`docs-public/runbook.md`** — vận hành, mỗi mục: triệu chứng → kiểm → xử lý → xác nhận. Mục: deploy (image tag SHA,
   migrate owner trước, health), rollback (chạy lại image SHA trước; migration chỉ tiến — nêu rõ cách làm khi migration
   không tương thích ngược), khôi phục (bundle `tenant:export` + phần DB vật lý thuộc hạ tầng), tên miền lỗi (kiểm bản ghi
   Domain/host → tenant, cache tag `tenant:<id>`, health), cache/ISR (revalidate), cron/worker. Phần phụ thuộc story chưa
   làm ghi dòng `> Chưa có — <story ID>` thay vì bịa lệnh. Lý do: runbook sai còn nguy hiểm hơn không có.
4. **`AGENTS.md`**: chỉ sửa §2 (cấu trúc đích hiện còn `apps/console` chưa tồn tại → ghi "(E15-S02)"; thêm `apps/worker`,
   `packages/{cache,cms-ui,config,env}`, `docs-public/`) và §3 thêm 1 dòng trỏ Quickstart. Không đổi quy ước khác.
5. **Kiểm tự động `scripts/ci/docs-check.mjs` + `docs-check.test.mjs`** (ít code nhất, không dependency):
   - Quét file `*.md` được git theo dõi trong: gốc, `apps/*`, `packages/*`, `tooling/*`, `infra/*`, `docs-public/**`
     (bỏ `roadmap/`, `.agents/`, `node_modules`).
   - Link markdown tương đối `[x](path)` / `path#anchor` → file/thư mục phải tồn tại (bỏ `http(s):`, `mailto:`, `#…`).
   - Trong `README.md` gốc và `docs-public/runbook.md`: mọi `pnpm <script>` / `pnpm --filter <pkg> <script>` phải là
     script có trong `package.json` tương ứng (pkg theo `name` hoặc thư mục; bỏ lệnh pnpm gốc `install|exec|dlx|add`).
   - Xuất danh sách lỗi `file:dòng: …`, exit 1 khi có lỗi. Chạy được bằng `node scripts/ci/docs-check.mjs`.
   - Thêm file test vào danh sách `node --test` ở `.github/workflows/workspace.yml:396`.
   Lý do: AC "chỉ dựa vào tài liệu" hỏng âm thầm khi link/lệnh mục; kiểm này giữ AC đúng về sau.
   Lỗi link có sẵn trong README package được phát hiện → sửa link (không xóa nội dung).
