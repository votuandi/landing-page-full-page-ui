## Mục tiêu
7 type section của luồng chuyển đổi (`hero`, `calculator`, `lead-form`, `packages`, `segments`, `site-header`,
`site-footer`) có schema zod chung, fixture `[DỮ LIỆU MẪU]` và variant `t15` trong `packages/sections`, đăng ký vào
registry sản phẩm. Số liệu dự toán (giá điện, VAT, đơn giá/kWp, giờ nắng, tỷ lệ ban ngày) đi từ dữ liệu section,
không từ `apps/web/src/config/solar.ts`.

## Bối cảnh đã khảo sát
- Khung: `packages/sections/src/define.ts` (`defineSectionType`, `defineVariants`), `registry.ts`
  (`sectionRegistry = createRegistry({})` — đang rỗng), `render/PageRenderer.tsx` (nhận `registry`, parse data bằng
  schema), trường chuẩn `fields/*` (`localized`, `pickLocale`, `mediaRef`, `link`, `resolveLink`). Mẫu variant
  server + island: `apps/web/src/app/lab/sections/_demo/demo-a/*` (README sections mục "Thêm variant").
- Nguồn t15 (apps/web, giữ nguyên tới E4-S01): `components/Hero.tsx` + `HeroStats.tsx`, `SegmentGrid.tsx` +
  `SegmentIcon.tsx`, `PackagesSection.tsx` + `data/packages.ts`, `SolarEstimator.tsx` + `config/solar.ts` +
  `config/segments.ts`, `ContactSection.tsx` + `LeadForm.tsx`, `layout/TopBar.tsx` + `layout/SiteHeader.tsx`,
  `SiteFooter.tsx`; dữ liệu công ty ở `config/site.config.ts`.
- Core: `calculateSolar(input, params)`, `estimateSavingForKwp`, `CalculatorParams`, `Region`, `Tariff`,
  `calculatorBus` (`openCalculator`, `onOpenCalculator`, `prefillFromUrl`), `SEGMENT_ORDER`, `SEGMENT_SLUGS`, `priceView`.
- ADR: D4 (token), D5 (zod), D12 (giữ stack UI), D15 (node:test). Phụ thuộc E3-S01..S03 đã xong.
- `registry.test.ts` đã có test "defaults của mọi type thật parse được" — tự phủ type mới.
- `tailwind.config.ts` của web đã quét `packages/sections/src`; class `t15-*` định nghĩa trong `apps/web/src/app/globals.css`.

## Thiết kế

**Cấu trúc mỗi type** (`packages/sections/src/<type>/`):
`schema.ts` (definition, `defaults = schema.parse(fixture)`), `fixtures.ts` (`<type>Fixture`, dữ liệu t15 gắn
`[DỮ LIỆU MẪU]`, kiểu `z.input`, chỉ `import type` từ schema), `index.ts` (`defineVariants(def, "t15", { t15 })`),
`t15.tsx` (Server Component). Type có tương tác thêm `t15.client.tsx` (stub `next/dynamic`) + `t15.island.tsx`.
Server variant làm `pickLocale`/`resolveLink`, truyền chuỗi + href đã resolve xuống island → island không import
zod/schema. `registry.ts` đăng ký 7 type.

**Dùng chung** `packages/sections/src/shared/`: `media.ts` (`mediaSrc(ref)`: tạm thời `id` bắt đầu bằng `/` là đường
dẫn tĩnh, còn lại `undefined` → placeholder `MediaImage`; E5 thay bằng resolver media tenant), `SegmentIcon.tsx`,
`LeadForm.island.tsx` (form lead client: kiểm SĐT VN, honeypot, POST `/api/lead`; chuỗi giao diện VI/EN trong file;
nội dung tenant qua props). Thêm dependency workspace `@solar/ui`, peer `@heroicons/react` (đã có trong web/ui, không
phải dependency runtime mới của app — ghi lý do trong PR).

**Core**: thêm `packages/core/src/provinces.ts` (`PROVINCES` 34 tỉnh, `REGION_LABELS`) — dữ liệu địa lý, không phải giá;
`apps/web/src/config/solar.ts` re-export từ core để không trùng. Không đổi API tính toán.

**Schema (rút gọn, trường nội dung là `localized()`)**:
- `hero`: `badge`, `title {lead, highlight, sub, subHighlight}`, `description`, `primaryCta: link()`,
  `secondaryCta?: link()`, `rating? {score 0..5, count, url, label}`, `stats[≤3] {value, decimals 0..2, suffix?, unit, label}`,
  `image: mediaRef()`, `chips[≤4] {label, icon: sun|cpu|battery|light, tone: accent|secondary|primary|leaf}`,
  `outputCard?`, `savingCard?`, `co2Card?` (thẻ nổi; thiếu → ẩn). Island: đếm số `stats` (giữ hành vi `HeroStats`).
- `segments`: `eyebrow`, `title`, `description`, `targetAnchor` (mặc định `video-cong-trinh`),
  `items[1..4] {segment, label, pitch, image, saving, savingLabel}`. Server-only: thẻ là
  `<a href="?phan-khuc=<slug>#<targetAnchor>">` (chạy khi tắt JS). State phân khúc chung là E3-S08.
- `calculator` (theo story): `tariffs: Record<Segment, Tariff>`, `vatRate`, `pricePerKwp: Record<Segment, number>`,
  `peakSunHours: Record<Region, number>`, `segmentRatios: Record<Segment, 0..100>`, `steps` (thứ tự ô nhập hiển thị:
  `segment|bill|roof|province|ratio`, duy nhất, ≥1), `ctaLabel`; thêm `system {performanceRatio, m2PerKwp, panelWatt,
  kwpStep, minKwp, minRoofArea}`, `inputs: Record<Segment, {bill {min,max,step,default}, roof {default,max}}>`,
  `defaultProvince` (refine: có trong `PROVINCES`), `segments[1..4] {segment, label, short}`, nội dung (`eyebrow`, `title`,
  `description`, `tips[≤3]`, `formTitle`, `formDescription`, `disclaimer`), `leadSource` (mặc định `calculator`).
  `calculator/params.ts` (không zod): `toCalculatorParams(data): CalculatorParams`. Island port `SolarEstimator`:
  nhận params + chuỗi đã resolve, giữ prefill từ URL/`calculatorBus`, ghi `t15-last-estimate` (localStorage, try/catch).
- `lead-form`: `title`, `points[≤5]`, `image`, `formTitle`, `fields {zalo, address, message}`, `messageLabel?`,
  `submitLabel`, `successText`, `privacyNote`, `fallbackPhone?`, `source` (`[\w-]+`, mặc định `home-bottom`).
- `packages`: `eyebrow`, `title`, `segments[1..4] {segment, label, short, pitch, cover}`, `defaultSegment`,
  `items[] {id, segment, name, kwp, price?, salePrice?, suitableFor, highlights[], popular, monthlySaving?}`,
  `maxPerSegment` (1..8, mặc định 4), nhãn (`ctaLabel`, `savingLabel`, `popularLabel`, `footnote`). `monthlySaving`
  là số do tenant nhập (fixture tính sẵn bằng `estimateSavingForKwp` với params của fixture calculator); thiếu → ẩn khối
  tiết kiệm. Island: tab phân khúc (khởi tạo từ `?phan-khuc=`), nút gọi `openCalculator({segment, topic})`.
- `site-header`: `brand {name, logo?}`, `topBar[]` (rỗng = ẩn), `pricingMenu? {label, hint, categories[] {id, label,
  hint, segment, groups[] {title?, chips[] {label, bill?, popular}}}}`, `menus[] {label, columns[] {title, description?,
  link?, links[]}}` (Thiết bị, Cẩm nang), `links[]`, `mobileLinks[]`, `hotlines[] {name, main, lines[] {label, phone},
  mapLink?}`, `cta: link()`, `drawerActions[]: link()`. Island: mega menu, hotline, drawer mobile; id DOM có tiền tố
  `sectionId`. Công tắc theme, giỏ báo giá, đổi ngôn ngữ thuộc widget/i18n (E3-S07, E8) — không làm ở đây.
- `site-footer`: `brand {name, tagline, logo?}`, `socials[] {kind: facebook|youtube|tiktok|zalo, url, label}`,
  `legal {legalName, lines[], badges[], moitBadge {enabled, url?}}`, `complaintHotline? {label, phone}`,
  `branches[] {name, stores[] {name, address?, phone}}`, `columns[] {title, links[]}`, `contactNote`, `disclaimer[]`.
  Server-only.
