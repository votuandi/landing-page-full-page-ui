## Mục tiêu
CMS site (`apps/admin`) có khung quản trị thật: sidebar (desktop) / menu gập (mobile) với đủ mục của story, theme admin
riêng (không theo theme tenant), chỗ chừa sẵn cho banner ghost (E15-S07) và bảo trì (E15-S06). Menu chỉ hiện mục mà
người dùng có quyền **và** gói/kill switch/override cho phép; mỗi trang vẫn tự kiểm lại ở server.

## Bối cảnh đã khảo sát
- `apps/admin/src/app/layout.tsx`: root layout dùng `t15` + bọc mọi trang trong card `max-w-3xl` (hợp cho trang đăng nhập,
  không hợp cho khung admin). `apps/admin/src/app/(admin)/layout.tsx`: menu ngang 6 link, lọc theo `session.permissions`.
- `apps/admin/src/lib/auth.ts`: `getTenant()` (trả `SlugRecord {tenantId, siteId, tenantStatus}`), `getAdminSession()`,
  `requirePagePermission()` (redirect/forbidden/notFound). `lib/gate.ts`: `authorize()` thuần, có test.
- Quyền: `packages/auth/src/permissions.ts` (`PERMISSIONS`, `ROLE_PERMISSIONS`, phiên ghost bỏ nhóm `account.security`).
- Gói: `packages/plans/entitlements.ts` `can(site, feature, { disabled })` = kill switch → override tenant → gói/addon/trial (D19).
  Web nạp subject qua `forTenant(db, tenantId).site.first({ where: { id: siteId }, include: { tenant: true } })`
  (`apps/web/src/lib/tenant/siteData.ts:22-40`) + `loadDisabledFeatures(db)` (`packages/db/src/client.ts:114`). Admin làm y hệt —
  không cần migration.
- `packages/ui` chỉ có primitive cho site công khai; chưa có `apps/console` (E15). Theme: `packages/themes/t15/theme.ts`, `themes[]`
  trong `packages/themes/src/index.ts:19` là danh sách theme tenant chọn được.
- Đã có `@axe-core/playwright`, `@playwright/test` trong store; E1-S03 từng chạy Lighthouse (`.agent-runs/E1-S03`).

## Thiết kế
1. **Theme admin** `packages/themes/admin/theme.ts` → export `adminTheme` từ `@solar/themes` nhưng **không** thêm vào `themes[]`
   (tenant không chọn được). Dựa trên cấu trúc t15, bảng màu trung tính (nền xám rất nhạt, primary xanh lá đậm), font Be Vietnam Pro
   như hiện tại; mọi cặp chữ/nền đạt WCAG AA (≥ 4.5:1). Có light + dark. Root layout admin đổi `t15` → `adminTheme`.
2. **`packages/ui/src/admin/AdminShell.tsx`** (server component, dùng chung cho console sau này), export từ `@solar/ui`:
   ```ts
   type AdminNavItem = { href: string; label: string; current?: boolean };
   type AdminNavGroup = { label?: string; items: AdminNavItem[] };
   AdminShell({ brand: ReactNode; nav: AdminNavGroup[]; banners?: ReactNode; account?: ReactNode; children })
   ```
   - Desktop (≥ lg): sidebar cố định trái, nội dung phải. Mobile: thanh trên cùng + `<details>`/`<summary>` "Menu" mở danh sách
     (chạy được khi tắt JS, không cần client component).
   - `<nav aria-label>`, mục hiện tại `aria-current="page"`; vùng `banners` nằm trên cùng nội dung (`role="region"` khi có);
     `<main id="noi-dung">` cho skip link. Chỉ class token (luật §4), không icon bắt buộc.
   - `current` tính ở client cần pathname → dùng header `x-admin-path` mà `proxy.ts` đã đặt (đã dùng ở root layout), so khớp
     prefix trong `adminNav`.
3. **Mô hình menu thuần** `apps/admin/src/lib/nav.ts` (có test):
   ```ts
   type NavEntry = { href; label; permission: Permission; feature?: Feature };
   export const ADMIN_NAV: { label?: string; items: NavEntry[] }[];
   export function adminNav(input: { permissions: ReadonlySet<Permission>; can: (f: string) => boolean; pathname?: string | null }): AdminNavGroup[]
   ```
   Lọc bỏ mục thiếu quyền hoặc `feature && !can(feature)`; bỏ nhóm rỗng; đặt `current` theo prefix (`/` chỉ khớp chính nó).
   Mục (thứ tự story):
   | Nhãn | href | permission | feature |
   |---|---|---|---|
   | Tổng quan | `/` | dashboard.view | — |
   | Trang & Section | `/trang` | pages.view | — |
   | Nội dung | `/noi-dung` | content.edit | — |
   | Media | `/media` | media.view | — |
   | Lead | `/lead` | leads.view | leadInbox |
   | Giao diện | `/giao-dien` | theme.manage | — |
   | Tên miền | `/ten-mien` | domains.manage | customDomain |
   | Email theo tên miền | `/email` | email.manage | customDomain |
   | Tài khoản & nhân viên | `/nhan-vien` | users.view | — |
   | Gói | `/goi` | billing.view | — |
   Nhóm "Tài khoản của tôi": Đổi mật khẩu `/doi-mat-khau` (account.password), Bảo mật `/tai-khoan/bao-mat` (account.totp).
4. **Entitlement phía admin** `apps/admin/src/lib/entitlements.ts`:
   `getSiteEntitlements = cache(async () => …)` dùng `getTenant()` + `forTenant(db, tenantId).site.first({ where: { id: siteId }, include: { tenant: true } })`
   + `loadDisabledFeatures(db)` (lọc bằng `disabledFeaturesSchema`) → `canUse(subject, { disabled })`. Thêm vào `lib/auth.ts`:
   `requirePageFeature(feature)` → `notFound()` khi `!can` (giống web: tính năng ngoài gói = không tồn tại). Thêm `@solar/plans` vào deps admin.
5. **Bố cục route**:
   - Chuyển các trang auth (`dang-nhap`, `quen-mat-khau`, `dat-lai-mat-khau`, `link-dang-nhap`, `moi`, `auth/magic`, `loi/*`) vào
     route group `src/app/(auth)/` với `layout.tsx` giữ card căn giữa hiện tại (URL không đổi, `git mv`). `doi-mat-khau` cũng vào
     `(auth)` (bắt buộc đổi mật khẩu lần đầu không hiện menu). Root layout chỉ còn `<html>/<body>`, theme, skip link.
     `forbidden.tsx`/`not-found.tsx` tự bọc card.
   - `(admin)/layout.tsx`: `requirePagePermission("session")` + `getSiteEntitlements()` → `AdminShell` với `adminNav(...)`;
     `banners`: phiên `session.kind === "ghost"` → banner "Bạn đang ở phiên hỗ trợ của quản trị nền tảng" (chỉ hiển thị, nội dung
     đầy đủ ở E15-S07); chỗ trống có comment cho banner bảo trì (E15-S06). `account`: tên người dùng + nút Đăng xuất (`ActionForm` cũ).
   - Trang chỗ chờ mới (mỗi trang gọi `requirePagePermission(<permission>)` và, nếu có, `requirePageFeature(<feature>)` — đúng bảng
     trên): `(admin)/trang`, `noi-dung`, `media`, `lead`, `giao-dien`, `email`. Nội dung: `<h1>` + một câu "Màn hình này sẽ có ở story
     E7-Sxx" (trang → S04/S05, nội dung → S06, media → E8, lead → E11, giao diện → S08, email → E13). Trang `ten-mien` thêm
     `requirePageFeature("customDomain")`.
6. Không thêm dependency runtime mới (chỉ nối workspace `@solar/plans`).
