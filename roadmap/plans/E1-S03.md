(giữ Next 16). Chưa bật `cacheComponents` (E5-S06), chưa có `proxy.ts` (chưa có middleware để đổi tên).

## Thiết kế
- Nâng thủ công trong pnpm workspace (codemod `upgrade` không xử lý tốt monorepo pnpm); chạy codemod chuyển đổi nếu có
  pattern liên quan (không có `middleware`, `unstable_*`, `next lint` → chỉ đổi phiên bản).
- Ghim phiên bản chính xác: `next` 16.x mới nhất ổn định, `eslint-config-next` cùng phiên bản, `react`/`react-dom` 19.2.x,
  `@types/react(-dom)` 19.2.x. `packages/ui` peer/dev theo cùng phiên bản.
- ESLint: `nextConfig()` dùng `eslint-config-next/core-web-vitals` (flat) thay cho `FlatCompat`; gỡ `@eslint/eslintrc`
  nếu không còn dùng.
- `next.config.ts`: thêm `images.qualities: [70, 75]` để giữ ảnh hero như cũ.
- `layout.tsx`: thêm `data-scroll-behavior="smooth"` để giữ hành vi cuộn khi điều hướng như Next 15.
- `priority` → giữ nguyên nếu build/dev không in cảnh báo (chỉ deprecated trong docs; đổi sang `preload` thay đổi
  ngữ nghĩa `fetchPriority`/`loading` có thể ảnh hưởng LCP). Nếu Next in cảnh báo thì đổi.
- Turbopack thành mặc định cho `next dev`/`next build` — giữ mặc định; nếu lỗi với Tailwind 3/PostCSS thì `--webpack`
  và ghi lý do.

## Các bước
1. Đo trước khi nâng (trên base): `pnpm visual:test` xanh; Lighthouse trang chủ (mobile, `next start`) → lưu
   `.agent-runs/E1-S03/lighthouse-before.json`.
2. Nâng phiên bản — file: `apps/web/package.json`, `packages/ui/package.json`, `packages/config/package.json`,
   `pnpm-lock.yaml` — kiểm bằng: `pnpm install`.
3. Sửa ESLint flat config — file: `packages/config/eslint.config.mjs` — kiểm bằng: `pnpm turbo run lint lint:root`.
4. `next.config.ts` (`qualities`), `layout.tsx` (`data-scroll-behavior`); `next-env.d.ts` do Next sinh lại.
5. `pnpm turbo run typecheck lint test` + `pnpm --filter web build` → đọc log, xử lý mọi cảnh báo deprecation.
6. Dev server + MCP `next-devtools` `get_errors` qua các route → không lỗi.
7. `pnpm visual:test` → 48/48 khớp baseline; Lighthouse sau → so sánh (≤ 3 điểm giảm).
8. Ghi D2 trong `roadmap/02-decisions.md` (giữ Next 16 + số liệu), tick AC trong epic, `claude-report.md`.
