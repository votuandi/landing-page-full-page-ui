## Thiết kế
- `packages/db/src/csv.ts`: `parseCsv(text) → string[][]` (bỏ BOM, CRLF/LF, ô có `"`/dấu phẩy/xuống dòng) và
  `toCsv(rows) → string` (BOM `﻿`, CRLF, quote khi cần).
- `packages/db/src/productCsv.ts`:
  - `PRODUCT_CSV_COLUMNS` cố định: `slug,title_vi,title_en,status,category,brand,price,salePrice,featured,segments,
    powerKw,images,warranty,tech,segment,specs,compatible,unit,datasheet`. `category`/`brand` = **slug** trong tenant.
  - Mã hóa ô: số → chữ số; boolean `true/false` (nhập không phân biệt hoa thường); mảng chuỗi → nối `|`; text
    localizable/record (`specs`) → JSON. Quy tắc chung: ô bắt đầu bằng `[`, `{`, `"` được đọc là JSON; bộ mã hóa
    dùng JSON khi dạng thường mơ hồ (phần tử chứa `|`, chuỗi bắt đầu bằng `[{"`).
  - Chống CSV injection: ô bắt đầu `= + - @` (hoặc tab/CR) khi xuất thêm `'` phía trước; khi nhập bỏ `'` đứng trước
    các ký tự đó → round-trip vẫn giữ nguyên.
  - `productToCsvRow(row, refs)`, `exportProductsCsv(rows, categories, brands)`.
  - `previewProductCsv(text, existing, refs, { bilingual })` → `{ rows: { line, slug, kind: "create"|"update"|"unchanged"|"error", errors: { column, message }[] }[], inputs }`.
    Dòng cũ (theo slug) có ô **trùng hệt** `productToCsvRow(existing)` → `unchanged`, không validate, không ghi (round-trip
    đúng cả với bản ghi cũ không còn đạt schema). Còn lại: dựng `CollectionInput` → `collectionInputSchema("product")`
    (locale vi), map `issue.path` → tên cột (`["columns","salePrice"]` → `salePrice`, `["data","specs"]` → `specs`,
    `["title"]` → `title_vi`). Slug trống → `slugify(title_vi)`. `line` = số bản ghi CSV (header = dòng 1).
- `packages/db/src/collectionWrite.ts`: tách thân ghi của `saveCollectionItem` thành hàm nội bộ dùng chung;
  thêm `importCollectionItems(db, tenantId, "product", inputs)` — **một** `transaction`, upsert theo slug (update giữ
  `id`, `order`, `publishedAt`; tạo mới nối cuối), `enqueueInvalidate` **một lần** nếu có dòng published trước/sau.
- Admin: `apps/admin/src/lib/productCsv.ts` (handlers `preview`/`import` theo mẫu `createCollectionHandlers.run`: kiểm
  `content.edit`, `catalog`; tính lại preview khi xác nhận, còn lỗi → từ chối, không ghi); actions trong
  `noi-dung/actions.ts`; route `app/api/san-pham/csv/route.ts` (`route("content.edit")` + kiểm `catalog` → 404,
  `Content-Type: text/csv; charset=utf-8`, `Content-Disposition: attachment; filename="san-pham.csv"`);
  component `components/ProductCsv.tsx` trên trang `noi-dung/san-pham`: nút "Xuất CSV", chọn file → "Xem trước" →
  bảng dòng (trạng thái + lỗi "Dòng N, cột X: …") → "Xác nhận nhập" (tắt khi có lỗi).
- Giới hạn: file ≤ 500 kB (byteLength), ≤ 1000 dòng dữ liệu; xuất > 1000 sản phẩm → báo lỗi tiếng Việt.
