## Mục tiêu
`@solar/tokens` có hàm thuần kiểm tra tương phản WCAG các cặp màu bắt buộc của một theme (light + dark, có/không
override CMS) và hàm `suggestAccessible(color, against)` gợi ý màu gần nhất đạt chuẩn. Test của `@solar/themes`
chạy kiểm tra này cho mọi theme đã export, nên CI chặn theme gốc dưới AA.

## Bối cảnh đã khảo sát
- `packages/tokens/src/schema.ts`: `RgbChannels` (chuỗi `"R G B"`), `ColorSet`, `ThemeTokens`; `colors.dark` là
  tập ghi đè partial, token thiếu kế thừa light.
- `packages/tokens/src/css.ts`: `ThemeOverrides` (`colors.light?/dark?` partial) và thứ tự cascade khi render:
  light = `{...light, ...ov.light}`; dark = `{...light, ...ov.light, ...dark, ...ov.dark}` (khối `[data-theme=dark]`
  chỉ khai báo khóa dark + override dark, còn lại rơi về `:root`).
- `packages/tokens/src/color.ts` + `__tests__/color.test.ts`: kiểu test `node:test`, liệt kê file trong script `test`
  của `packages/tokens/package.json`.
- `packages/themes/src/index.ts` export `t15`; `packages/themes/src/__tests__/theme.test.mjs` nạp TS qua
  `ts.transpileModule` — thêm test ở đây để chạy cho **mọi** export.
- CI `.github/workflows/workspace.yml` chạy `pnpm turbo run test` với filter `...[origin/base]` → đổi tokens hoặc
  themes đều chạy test của themes.
- Đo t15 hiện tại: mọi cặp dưới đây ≥ 4.5 ở light và dark (thấp nhất: `accent-ink`/`bg` light 4.66,
  `on-media` trên scrim/60 nền trắng light 4.74, `fg-subtle`/`bg-sky` light 4.72). `accent-ink` trên
  `bg-tint`/`bg-sky` (4.46/4.37) **không** thuộc danh sách bắt buộc của story → không kiểm, không sửa theme.

## Thiết kế
File mới `packages/tokens/src/contrast.ts`, export qua `src/index.ts`. Không thêm dependency.

```ts
export const AA_NORMAL = 4.5;
export function contrastRatio(a: string, b: string): number;          // a, b: RgbChannels; công thức WCAG 2.x
export function suggestAccessible(color: string, against: string, min = AA_NORMAL): string;
export const CONTRAST_PAIRS: readonly ContrastPair[];
export type ContrastPair = { fg: ColorKey; bg: ColorKey; scrimAlpha?: number };
export type ContrastIssue = {
  mode: "light" | "dark"; fg: ColorKey; bg: ColorKey; scrimAlpha?: number;
  ratio: number; min: number; suggestion: string;
};
export function checkContrast(theme: ThemeTokens, overrides?: ThemeOverrides): ContrastIssue[];
```

- `contrastRatio`: parse bằng `RgbChannels` (ném lỗi nếu sai dạng), luminance sRGB WCAG (ngưỡng 0.04045 hoặc
  0.03928 đều được, chọn 0.04045), trả `(L1+0.05)/(L2+0.05)` chưa làm tròn. So sánh `ratio >= min` trên số chưa làm tròn.
- `suggestAccessible(color, against, min)`: đã đạt → trả nguyên `color`. Chưa đạt → thử hai hướng: trộn `color` về
  đen và về trắng (`c + t*(target-c)`, làm tròn kênh về số nguyên), tìm nhị phân `t` nhỏ nhất mà màu **sau làm tròn**
  đạt `min`; trong các hướng đạt, chọn kết quả có `t` nhỏ nhất (gần màu gốc nhất, giữ sắc độ). Không hướng nào đạt
  (chỉ xảy ra khi `min` > ~4.58) → trả đen hoặc trắng, cái nào tương phản cao hơn. Kết quả luôn dạng `"R G B"`.
  Dùng lại ở E7-S08 (CMS override).
- `CONTRAST_PAIRS` (đúng phạm vi story, cùng áp cho light và dark):
  - `fg`, `fg-muted`, `fg-subtle` × `bg`, `bg-elevated`, `bg-tint`, `bg-sky`, `bg-sun`
    (không gồm `bg-deep`: nền tối dùng `on-media`).
  - `on-primary`/`primary`, `on-secondary`/`secondary`, `on-accent`/`accent`.
  - `accent-ink`/`bg`, `accent-ink`/`bg-elevated`.
  - `on-media`/`scrim` với `scrimAlpha: 0.6`.
- Cặp có `scrimAlpha`: nền = `scrim` phủ alpha lên ảnh bất kỳ → tính màu ghép trên nền **trắng** và **đen**, lấy
  ratio thấp hơn; `suggestion` tính trên nền ghép tệ nhất đó.
- `checkContrast(theme, overrides?)`: parse `overrides` bằng `ThemeOverridesSchema` (export sẵn ở `css.ts`), dựng bộ
  màu hiệu lực theo đúng cascade ở trên; dark chỉ kiểm khi `theme.meta.supportsDark`. Trả mảng issue rỗng khi đạt;
  mỗi issue có `suggestion = suggestAccessible(fgColor, bgColor)` (đổi màu chữ, giữ nền).

Kiểm trong CI = test `@solar/themes`: lặp `Object.values(require("../index.ts"))`, mỗi theme
`assert.deepEqual(checkContrast(theme), [])` với message liệt kê cặp lỗi. Không thêm script/CLI riêng (test đã chạy
trong CI cho mọi theme; theme mới export từ `src/index.ts` tự được kiểm).

## Các bước
1. `packages/tokens/src/contrast.ts` + export trong `src/index.ts` — kiểm bằng typecheck.
2. `packages/tokens/src/__tests__/contrast.test.ts`, thêm `.test-dist/__tests__/contrast.test.js` vào script `test`
   của `packages/tokens/package.json`. Ca test:
   - `contrastRatio("0 0 0","255 255 255")` ≈ 21; cùng màu = 1; đối xứng; giá trị đã biết
     (`"118 118 118"` trên trắng ≈ 4.54 ± 0.01); chuỗi sai dạng ném lỗi.
   - `suggestAccessible`: màu đã đạt trả nguyên; màu xám nhạt trên trắng → kết quả đạt ≥ 4.5 và tối hơn; màu trên
     nền tối → sáng hơn; kết quả là `RgbChannels` hợp lệ; `min = 7` cũng đạt; `min` không thể đạt (vd. 22) trả đen/trắng.
   - `checkContrast(parseTheme(t15 fixture))` → `[]`.
   - Override `fg-subtle` light = `"200 200 200"` → có issue `{ mode: "light", fg: "fg-subtle", … }` với
     `suggestion` đạt chuẩn; cũng xuất hiện ở `mode: "dark"` **chỉ khi** dark không ghi đè `fg-subtle`
     (fixture t15 có ghi đè → không xuất hiện ở dark).
   - Override dark `on-media` thấp trên scrim → issue có `scrimAlpha: 0.6`.
   - Theme `supportsDark: false` (bỏ `colors.dark`) → không có issue `mode: "dark"`.
   - Override sai dạng → ném lỗi (ThemeOverridesSchema).
3. `packages/themes/src/__tests__/theme.test.mjs`: thêm test "mọi theme đạt WCAG AA cho cặp bắt buộc".
4. `packages/tokens/README.md`: mục "Kiểm tra tương phản" (danh sách cặp, cách dùng `checkContrast`,
   `suggestAccessible`, quy tắc scrim, ghi chú E7-S08 dùng cho override CMS).
5. Tick 2 AC của E2-S05 trong `roadmap/epics/E02-tokens-themes.md` khi có bằng chứng.
