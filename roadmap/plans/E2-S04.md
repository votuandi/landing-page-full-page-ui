## Thiết kế

### Package `@solar/eslint-plugin` — `tooling/eslint-plugin/` (JS thuần `.mjs`, không build)
```
tooling/eslint-plugin/
  package.json        name @solar/eslint-plugin, type module, exports "." → ./src/index.mjs,
                      bin { "solar-lint-tokens": "./src/cli.mjs" }, scripts lint/test,
                      devDeps/peer: eslint 9.39.5, @typescript-eslint/parser (đúng bản 8.x đang có trong lockfile)
  src/matchers.mjs    findHardcoded(text) → [{ index, found, kind }]  — logic khớp chuỗi dùng chung
  src/no-hardcoded-style.mjs   rule ESLint
  src/index.mjs       plugin { meta, rules: { "no-hardcoded-style" } } + tokensConfig (flat config dùng cho CLI)
  src/cli.mjs         solar-lint-tokens [dir…]
  src/*.test.mjs      node:test (RuleTester + matchers + CLI)
  README.md
```
- **Matchers** (`kind` quyết định gợi ý), không phân biệt hoa/thường:
  - `hex`: `#` + 3/4/6/8 ký tự hex, không đứng sau chữ/số/`&`/`/`, không theo sau bởi `[\w-]` (để `#CarouselNav`,
    `#lien-he` không bị bắt).
  - `color-fn`: `rgb(` `rgba(` `hsl(` `hsla(` **trừ** khi tham số đầu là `var(--…)` (`rgb(var(--c-accent) / .2)`,
    `rgb( var(--c-x))` hợp lệ).
  - `arbitrary`: class arbitrary `(bg|text|from|to|via|border|rounded|shadow|font|fill|stroke)-[` kể cả có variant
    (`hover:`, `md:`, `!`) — cấm mọi giá trị trong ngoặc (kể cả `border-[6px]`, `text-[11px]`). Không cấm
    `bg-primary/[.08]`, `z-[90]`, `aspect-[9/16]`, `tracking-[…]`, `leading-[…]`, `max-w-[…]`, `[mask-image:…]`
    (nhưng màu cứng bên trong vẫn bị `hex`/`color-fn` bắt).
  - `palette`: màu mặc định của Tailwind như scanner cũ (`bg-white`, `text-slate-500`…).
- **Rule `no-hardcoded-style`** (type `problem`):
  - Duyệt mọi `Literal` chuỗi và `TemplateElement` (`value.cooked`) trong file → phủ `className`, `cn()/clsx()`,
    map class, style object, thuộc tính SVG `fill`/`stroke`. Bỏ qua nguồn `import`/`export`, chỉ thị `"use client"`,
    và giá trị JSX attribute `href`/`id`.
  - Mỗi chuỗi vi phạm báo **một** lỗi cho mỗi đoạn khớp, đoạn `arbitrary` chứa hex/rgb chỉ báo một lần (không trùng).
  - Message tiếng Việt, có gợi ý theo `kind`/tiền tố, vd. với `bg-[#0E7C3A]`:
    `"bg-[#0E7C3A]" viết cứng — dùng class màu từ token: bg-primary, bg-accent, bg-bg-elevated, bg-bg-tint…`.
    Gợi ý: màu → `bg-*/text-*/border-*` + tên token màu; `rounded-[` → `rounded-card|media|pill|input|button`;
    `shadow-[` → các shadow của preset; `text-[` cỡ chữ → thang `fontSize` của preset; `font-[` → `font-sans|display`;
    hex/rgb trong style/CSS → `rgb(var(--c-<key>) / α)`.
  - Allowlist: file thuộc `packages/themes/**` hoặc `**/brand-icons/**` → không báo; comment `token-exempt: <lý do>`
    (bắt buộc có lý do không rỗng) trên **cùng dòng** hoặc **dòng ngay trên** node (`//`, `/* */`, JSX `{/* */}`).
- **CLI `solar-lint-tokens [dir…]`** (mặc định `src`): dùng Node API `new ESLint({ overrideConfigFile: true,
  overrideConfig: tokensConfig })` — chỉ bật rule này, parser `@typescript-eslint/parser` (JSX bật), file
  `**/*.{js,jsx,mjs,cjs,ts,tsx}`, ignore `node_modules/.next/dist/.test-dist` + allowlist ở trên. Thêm: quét `*.css`
  bằng `findHardcoded` theo dòng (exempt `/* token-exempt: … */` cùng dòng/dòng trên). In `file:line:col  message`,
  dòng tổng `lint:tokens: N vi phạm`, exit 1 nếu N > 0. Không dùng `-c` với đường dẫn tương đối giữa package.
- Không đưa rule vào `nextConfig()` (một cổng duy nhất là `lint:tokens`; tích hợp editor để sau).

### Dọn vi phạm `packages/ui` + `apps/web` — nguyên tắc
1. **Giữ nguyên pixel ở t15**: token thay thế phải cho đúng giá trị cũ khi theme là t15. Kiểm bằng visual regression
   local (bước 1 tạo baseline trước khi sửa, bước cuối `pnpm visual:test` phải qua).
2. Ưu tiên token có sẵn: `rounded-[28px]` → `rounded-card`, `rounded-[32px]` → `rounded-media` (đúng vai trò thẻ/ảnh;
   nếu chỗ nào sai vai trò thì vẫn chọn theo giá trị t15), `text-[11px]` → `text-2xs`.
3. Giá trị còn lại → thêm vào `packages/tokens/src/tailwind-preset.ts` (không đổi `ThemeTokensSchema`):
   - Radius lớn hơn (36/44px…): suy từ biến theme bằng `calc(var(--radius-media) + Npx)`, đặt tên theo vai trò.
   - Cỡ chữ: mỗi giá trị px lặp lại (8, 9, 10, 10.5, 13, 15px) một mục trong thang (`3xs`, `4xs`… hoặc tên tương tự,
     ghi trong README tokens); cỡ tiêu đề rem (`2rem`, `2.55rem`, `2.6rem`, `3.9rem`, `1.75rem`) → `display-*`;
     `text-[0.62em]` → mục tương đối (em).
   - Shadow: mục theo vai trò (`card`, `card-hover`, `glass`, `float`…) dạng
     `… rgb(var(--c-<key>) / calc(α * var(--shadow-strength)))` — t15 strength 1 nên không đổi; giữ đúng màu gốc
     (`shadow`, `primary`, `accent`).
   - Glow `bg-[radial-gradient(circle,rgb(var(--c-X)/.Y),transparent_65%)]` → `backgroundImage` theo màu
     (vd. `glow-accent`) + cách biểu diễn alpha tương đương (hoặc mục riêng cho từng alpha) — bắt buộc giữ pixel.
   - `border-[5px]`/`border-[6px]` → `borderWidth` `5`/`6`.
4. CSS thô trong `globals.css`: `rgba(…)`/`rgb(255 255 255 / .08)` → `rgb(var(--c-<key>) / α)` với key có cùng giá
   trị ở t15 (không có key bằng → chọn gần nhất, ghi vào report); `mask-image` dùng keyword `black` thay `rgb(0 0 0)`
   (mask chỉ dùng alpha). `@apply` các class arbitrary → class token mới.
5. Dữ liệu màu theo theme: swatch `rgb(${c})` ở `SiteShell.tsx:70` (hiển thị bảng màu theme) → giữ, thêm
   `// token-exempt: swatch hiển thị màu lấy từ dữ liệu theme`. `themeColor: "#F5FAF6"` → bỏ trường cứng, `viewport.themeColor`
   trong `layout.tsx` lấy từ token `bg` của theme đang dùng (helper nhỏ trong `@solar/tokens` đổi kênh RGB → chuỗi màu,
   có unit test). Ngoài 2 chỗ này **không** dùng `token-exempt`.
6. Không sửa logic/nội dung component; chỉ thay class/giá trị style.
