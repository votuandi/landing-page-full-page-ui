## Mục tiêu
CI của PR vào `mono-repo-multi-tenent` chỉ chạy task của package bị ảnh hưởng (và package phụ thuộc vào nó), có cache
Turborepo giữa các lần chạy (remote cache tùy chọn), bỏ workflow Yarn cũ trigger theo branch template.

## Bối cảnh đã khảo sát
- `.github/workflows/workspace.yml`: matrix Windows/Ubuntu (AC của E1-S01), chạy toàn repo `typecheck lint` hai lượt
  (lượt 2 phải `FULL TURBO`), `lint:tokens`, `test build`, coverage `@solar/core`. Không cache `.turbo` giữa các run.
- `.github/workflows/ci.yml`: workflow Yarn của template cũ (trigger `template-*`, PR vào `develop`) — không còn chạy
  được trên branch này (không có `yarn.lock`).
- `.github/workflows/visual.yml` (E1-S04) đã có path filter; `pr-meta.yml` (E0-S05) đã chạy mọi PR → giữ nguyên.
- Đồ thị package: `@solar/config` ← `@solar/core` ← `@solar/ui` ← `web`; `@solar/visual` chỉ phụ thuộc `@solar/config`.
  `apps/admin` chưa có (E7). Dry run với file đổi trong `packages/core`:
  `turbo run build typecheck lint test --filter=...[HEAD] --dry=json` → packages `@solar/core, @solar/ui, web`;
  `@solar/visual` không có task nào (chỉ `@solar/config#*` chạy do `^build`).
- Không filter nào khớp → turbo in `No tasks were executed`, không có `FULL TURBO`.
- `.turbo/` đã trong `.gitignore`; cache local turbo 2 nằm ở `.turbo/cache`.

## Thiết kế
- Sửa `workspace.yml` (giữ tên, matrix, các bước):
  - `actions/checkout` `fetch-depth: 0` để có `origin/<base>` cho filter.
  - Job env: `TURBO_FILTER` = `--filter=...[origin/${{ github.base_ref }}]` khi `pull_request`, rỗng khi push/dispatch
    (chạy toàn repo trên base). `TURBO_TOKEN: secrets.TURBO_TOKEN`, `TURBO_TEAM: vars.TURBO_TEAM` → remote cache khi
    được cấu hình, rỗng thì turbo dùng cache local.
  - `actions/cache@v4` cho `.turbo/cache`, key `turbo-<os>-<sha>`, restore-keys `turbo-<os>-` (cache giữa các run).
  - `defaults.run.shell: bash` cho cả Windows để `${TURBO_FILTER:+"$TURBO_FILTER"}` chạy giống nhau (quote tránh glob `[...]`).
  - Bước kiểm `FULL TURBO` chấp nhận thêm `No tasks were executed` (PR không đụng package nào).
  - Coverage `@solar/core` giữ nguyên (vài giây).
- Xóa `ci.yml` (trigger branch template cũ, Yarn). Template branch giữ bản `ci.yml` của chính nó nên không bị ảnh hưởng.
- Test `scripts/ci/affected.test.mjs` (`node:test`), chạy trong `workspace.yml` sau `pnpm install`:
  1. `turbo run build --filter=...@solar/core --dry=json` (cùng tập mà `...[ref]` cho ra khi chỉ `packages/core` đổi):
     có `@solar/core`, `web`; mọi package không phụ thuộc `@solar/core` (hiện là `@solar/visual`, sau này `apps/admin`)
     không có task `build`. Tính "không phụ thuộc core" từ `package.json` của workspace, để `apps/admin` tự được kiểm khi
     xuất hiện.
  2. `workspace.yml` có filter `...[origin/${{ github.base_ref }}]`, cache `.turbo/cache`, `TURBO_TOKEN`; không còn
     `ci.yml`/trigger `template-`.

## AC → bằng chứng
| AC | Bước | Bằng chứng sẽ có |
|---|---|---|
| PR chỉ sửa `packages/core` không chạy build `apps/admin` | 1–3 | test (1) + dry run log; `apps/admin` chưa tồn tại → test kiểm tổng quát mọi package không phụ thuộc core |
| Cache Turborepo (remote cache tùy chọn) hoạt động | 2 | bước `FULL TURBO` trong CI; log CI lượt 2 của PR có `Cache restored` + `cache hit` `[ngoài agent]` |
