## Thiết kế

### 1. Schema hồ sơ site dùng chung — `packages/db/src/siteProfile.ts` (export `@solar/db/site-profile`)
- Chuyển `profileSchema` sang đây (apps/web `contentSchemas.ts` re-export, không đổi nơi gọi). Thêm trường **tùy chọn hoặc có
  default** để mọi `profile` hiện có vẫn parse (không migration dữ liệu; JSON cột `profile`):
  - `brand`: `legalName?`, `tagline?` (textValue), `logo?`, `logoDark?` (`asset`), `logoText?` (≤ 4 ký tự), `foundedYear?`
    (1900…năm hiện tại), `url?` (https).
  - `legal`: giữ `policies`; thêm `businessRegistration?` `{ number, issuedBy, issuedDate }`, `licenses: string[]`, `iso: string[]`,
    `moitBadge?` `{ enabled, url }`.
  - `zalo`: record `household|factory|project` → `{ label: textValue, phone }` (đúng hình t15); `messenger?` (url), `complaintHotline?`,
    `workingHours?` (textValue), `callbackHours?` (int 1–72).
  - `socials`: mảng ≤ 10 `{ id: facebook|youtube|tiktok|zalo|instagram, url (https), handle, followers? ≥ 0 }`.
  - `stats`: `{ enabled, mwp?, projects?, dealers?, provinces?, engineers?, customers? }` số ≥ 0.
  - `reviews`: `{ google?, trustpilot? }` mỗi cái `{ url, rating 0–5, count ≥ 0 }`.
  - `commitments`: ≤ 8 `{ title, desc }` textValue. `popup`: `{ enabled, delayMs 0–600000, scrollRatio 0–1 }`.
  - `topBar`: `{ enabled, items: textValue[] ≤ 10 }`. `megaMenu`: `{ pricing: …, equipment: … }` đúng hình `pricing`/`equipment`
    của site.config t15 (PriceCategory / nhóm thiết bị), mặc định rỗng.
  - Hằng `COMPANY_KEYS` = các khóa form công ty sửa; `guide`, `team`, `timeline`, `legal.policies`, `theme` **giữ nguyên** khi lưu.
- Chi nhánh không vào profile (collection `branches`). Ngôn ngữ = cột `locales`/`defaultLocale` (sửa khi có `bilingual`; `vi` bắt buộc).
- Ngoài phạm vi: nối dữ liệu này vào section header/footer/widget (section vẫn dùng data riêng) → E13-S02. Web chỉ tiếp tục dùng các
  trường đang dùng (name, email, hotline, …) + `brand.logo` cho Organization JSON-LD nếu có.

### 2. Ghi cài đặt site — `packages/db/src/siteSettings.ts`
`saveSiteSettings(db, tenantId, siteId, patch: { profile?, locales?, defaultLocale?, themeId?, themeOverrides? }, expectedUpdatedAt?: Date)`:
`withTenantTransaction` → đọc site (đúng tenant), `expectedUpdatedAt` khác → lỗi 409 "Dữ liệu vừa thay đổi…"; update; `enqueueInvalidate(repo, [tenantTag(tenantId)])`
(theme/hồ sơ ảnh hưởng mọi trang). Lỗi validate → `SiteSettingsError(message tiếng Việt, status)`.

### 3. Import `site.config.ts` — `pnpm import:site-config <file> --tenant <slug> [--dry-run]`
- Mapper thuần `mapSiteConfig(config: unknown): { profile, locales, defaultLocale, branches: CollectionInput[], unmapped: string[] }`
  ở `packages/db/src/siteConfigImport.ts`; validate bằng `siteProfileSchema` (lỗi → liệt kê đường dẫn trường). `unmapped` liệt kê
  khóa section/runtime (`hero`, `calculator`, `pricing` nếu không map, `certificates`, `press`, `siteMode`, `catalog`, `legacy`, `demo`…)
  kèm ghi "thuộc section/collection — E13-S02".
- Script `packages/db/scripts/import-site-config.ts` (tsx, dynamic import file → `siteConfig`/default export) → `forPlatform(platformDb).tenants.bySlug`
  → `saveSiteSettings` (gộp `COMPANY_KEYS`, giữ phần còn lại của profile) + `saveCollectionItem("branch")` upsert theo slug = `branch.id`
  (chạy 2 lần không nhân bản) + `AuditLog` `site.import-config` (actor `system`). `--dry-run` chỉ in JSON + unmapped. Root
  `package.json`: `"import:site-config": "pnpm --filter @solar/db import:site-config"`.
- Seed dùng `mapSiteConfig(siteConfig).profile` để demo có dữ liệu công ty (giữ nguyên các trường seed đang đặt).

### 4. Admin `/cai-dat` — "Thông tin công ty" (`settings.manage`)
- Nav thêm mục (sau "Giao diện"). Page server: `requirePagePermission("settings.manage")` trước khi đọc DB → `SiteProfileForm` (client,
  `SchemaForm` trên schema pick `COMPANY_KEYS`, labels tiếng Việt, `bilingual` theo `can("bilingual")`) + khối Ngôn ngữ (checkbox vi/en khi `bilingual`).
- Action `saveSiteProfile = action("settings.manage", { payload: JSON, updatedAt }, handler)`; handler parse lại bằng schema (server là nguồn
  sự thật), `en` trong locales khi không có `bilingual` → 403. Handler + deps tiêm được (`lib/siteSettings.ts` + `siteSettingsRuntime.ts`).

### 5. Admin `/giao-dien` (`theme.manage`)
- **Lưới theme**: mọi theme trong registry; `themeAllowed(planId, group)` (thêm vào `packages/plans`, đọc `plans[planId].themes`). Card: tên, nhóm
  (`themeLabels`), mẫu màu primary/secondary/accent/bg lấy từ token của theme (style từ dữ liệu theme, không mã màu viết tay), radio chọn;
  theme ngoài gói: khóa + "Cần gói …"; theme hiện tại ngoài gói (đã hạ gói) vẫn hiện "Đang dùng".
- **Lưu theme** `saveTheme`: theme tồn tại + được phép (server) → nếu có override màu: `validateBrandOverrides(newTheme, overrides)` không đạt → 400 kèm
  gợi ý (không tự xóa màu khách) → `saveSiteSettings({ themeId })`. Không đụng `Page`/`SectionContent`.
- **Xem thử** `previewTheme(themeId)`: kiểm như trên → `createPreviewToken` → `previewUrl(..., path "/")` + `&theme=<id>` → mở tab mới.
  Web: `createPreviewHandler` nhận `theme` (`^[a-z0-9-]{1,40}$`, sai → 400) → cookie httpOnly `solar-preview-theme` (lax, cùng maxAge); không có
  `theme` → xóa cookie. `applyPreviewTheme(site, themeId)` (apps/web, thuần): theme tồn tại **và** `themeAllowed` → thay `theme` + `context.themeId`,
  ngược lại giữ nguyên. Chỉ `tenantRoute` khi `preview` đọc cookie; `tenantRenderKey` thêm `themeId` (preview, còn lại `undefined`) và
  `cachedSite` áp cùng helper. Render công khai không bao giờ đọc cookie.
- **Màu thương hiệu** (feature `themeOverride`; thiếu → khối ẩn + action 403): input `type=color` cho primary/secondary/accent × chế độ sáng (+ tối khi
  `supportsDark`); trống = màu theme; nút "Dùng màu theme" từng ô. Thêm `hexToChannels` vào `packages/tokens/src/color.ts`.
  `validateBrandOverrides(theme, overrides)` trong `packages/tokens/src/contrast.ts`: với mỗi khóa đã override k ∈ {primary, secondary, accent} và mỗi chế độ,
  ratio = `contrastRatio(k, on-k)` (màu đã gộp theme+override); < 4.5 → issue `{ mode, key, ratio, suggestion: suggestAccessible(k, on-k) }`; cộng thêm
  `checkContrast` cho cặp còn lại. Client dùng cùng hàm để báo ngay + nút "Dùng màu gợi ý"; server `saveColors` chặn (400, thông điệp
  "Màu chính (sáng) chỉ đạt 3,1:1 với chữ trên nền, cần ≥ 4,5:1. Gợi ý: #…").
- **Logo sáng/tối**: hai ô đường dẫn ảnh (`asset`) lưu vào `profile.brand.logo/logoDark` (action `saveLogos`, `theme.manage`).
- **Web thực thi gói**: `loadTenantSite` (wrapper export) trả `overrides = siteCanUse(site)("themeOverride") ? overrides : {}` — hạ gói thì màu theme gốc.
