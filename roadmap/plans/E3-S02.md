## Mục tiêu
Thêm vào `@solar/sections` năm hàm tạo trường zod dùng chung (`localized`, `mediaRef`, `link`, `richText`,
`collectionQuery`), mỗi trường khai báo `widget` cho form tự sinh (E7-S03). Thêm renderer an toàn cho `richText`

### Metadata widget (D5)
```ts
// widget.ts
export type FieldWidget = "localized" | "localizedTextarea" | "media" | "link" | "richText" | "collectionQuery";
export type FieldMeta = { widget: FieldWidget; collection?: string };
export const fieldRegistry = z.registry<FieldMeta>();
/** Đọc meta, tự bóc ZodOptional/ZodDefault/ZodNullable để CMS gọi trên trường đã .optional()/.default(). */
export function fieldMeta(schema: z.ZodType): FieldMeta | undefined;
```
Mỗi hàm tạo trường trả schema đã `.register(fieldRegistry, { widget, … })`. Dùng registry riêng (có kiểu) thay vì
`z.globalRegistry` để không đụng metadata JSON Schema của thư viện khác.

### Chữ ký trường
```ts
localized(opts?: { multiline?: boolean; max?: number })
  // z.object({ vi: z.string().max(max), en: z.string().max(max).optional() }); widget localized | localizedTextarea
  // vi được rỗng (alt ảnh trang trí); bắt buộc khác rỗng là việc của schema từng section (.refine) nếu cần.
export type Localized = { vi: string; en?: string };
pickLocale(value: Localized, locale: Locale): string   // en rỗng/thiếu → vi

mediaRef()
  // { id: string(min 1), alt: localized(), focal?: { x: number 0..1, y: number 0..1 } }; widget media
  // id là id bản ghi Media (E5), không phải URL/đường dẫn — S02 không resolve URL.

link()
  // { kind: "page"|"url"|"anchor"|"phone"|"zalo"|"calculator", value: string, label: localized() }; widget link
  // superRefine theo kind:
  //   page       value = slug: /^[a-z0-9-]+(\/[a-z0-9-]+)*$/ hoặc "" (trang chủ)
  //   url        new URL(value) với protocol http: | https: (chặn javascript:, data:, //host…)
  //   anchor     /^[a-z0-9-]+$/ (không kèm #)
  //   phone|zalo normalizeVnPhone(value) có 9–11 chữ số
  //   calculator query điền sẵn dạng "phan-khuc=ho-gia-dinh&hoa-don=2000000" hoặc ""; parse bằng prefillFromSearch
export type Link = z.output<ReturnType<typeof link>>;
resolveLink(link: Link): { href: string; external: boolean; calculator?: CalculatorPrefill }
  // page → "/" + value; url → value (chạy lại kiểm protocol, sai → "#"); anchor → "#" + value;
  // phone → "tel:" + normalizeVnPhone; zalo → "https://zalo.me/" + normalizeVnPhone (external);
  // calculator → prefill = prefillFromSearch(value), href = `/?${prefillToSearch(prefill)}#${CALCULATOR_ID}`
  //   (bỏ "?" khi query rỗng) — chạy được khi tắt JS.

richText()
  // localized ở cấp tài liệu: { vi: Block[], en?: Block[] }; widget richText. Không đệ quy, không chuỗi HTML.
type Inline =
  | { type: "text"; text: string; bold?: boolean; italic?: boolean }
  | { type: "link"; link: Link; children: { type: "text"; text: string; bold?: boolean; italic?: boolean }[] };
type Block =
  | { type: "paragraph"; children: Inline[] }
  | { type: "heading"; level: 2 | 3 | 4; children: Inline[] }
  | { type: "list"; ordered: boolean; items: Inline[][] };
  // z.discriminatedUnion; giới hạn: tối đa 200 block, text ≤ 5000 ký tự/node. Inline link dùng lại link().
  // node.link.label không hiển thị trong richText (dùng children) — chấp nhận label trùng nội dung, không thêm schema riêng.

collectionQuery(collection: string)
  // { filter: z.record(z.string(), z.union([string, number, boolean])).default({}),
  //   sort: { field: string(min 1), dir: "asc"|"desc" }.optional(),
  //   limit: int 1..48 default 6, ids: string[] (max 48).optional() }
  // widget collectionQuery, meta.collection = tên collection. Field/filter hợp lệ theo collection là việc của E5.
```

### Renderer
- `RichText({ value, locale })` (Server Component, không `"use client"`): `pickLocale` ở cấp doc (`en` thiếu/rỗng →
  `vi`), duyệt block bằng `switch (node.type)`; chỉ tạo `<p>`, `<h2|h3|h4>`, `<ul>/<ol><li>`, `<strong>`, `<em>`,
  và `SectionLink` cho inline link. Node lạ (dữ liệu chưa parse, hoặc type mới) → bỏ qua, không throw. Text đi qua
  React text node (tự escape). **Cấm** `dangerouslySetInnerHTML` trong `packages/sections/src` — thêm rule ESLint
  `no-restricted-syntax`/`react/no-danger` vào `packages/sections/eslint.config.mjs` + test quét source.
  Chỉ class token (`text-fg`, `text-fg-muted`, `font-heading`…); khoảng cách tối giản, variant tự bọc style.
- `SectionLink({ link, locale, className?, children? })` (Server Component): `resolveLink`; nội dung = `children` hoặc
  `pickLocale(link.label)`. `external` → `target="_blank" rel="noopener noreferrer"`. `calculator` → render
  `<CalculatorLink href prefill className>` thay `<a>`.
- `CalculatorLink` (`"use client"`, nhỏ, import tĩnh — không cần cặp `.client/.island` vì là primitive vài dòng, không
  phải variant; ghi lý do trong README): `<a href={href} onClick={(e) => handleCalculatorClick(e, prefill)}>`.
  Tách hàm thuần `handleCalculatorClick(event, prefill, open = openCalculator)` trong `link.ts` (hoặc file riêng không
  `"use client"`): bỏ qua khi có phím bổ trợ (ctrl/meta/shift/alt) hoặc nút chuột ≠ 0 để mở tab mới vẫn chạy;
  ngược lại `event.preventDefault()` rồi `open(prefill)`.
- `@solar/sections` thêm dependency `@solar/core: workspace:*`; devDependency `react-dom` 19.2.8 (chỉ cho test
  `renderToStaticMarkup`, không phải runtime mới — app đã có react-dom).

  `{ kind, value, label }` của story; parse/serialize bằng hàm sẵn có `prefillFromSearch`/`prefillToSearch`.
- [không chặn] `CalculatorLink` là client component import tĩnh (không theo cặp `.client/.island` của S01) → chọn vì là
  primitive vài dòng dùng chung, tách chunk riêng không đáng; ghi vào README.
- [không chặn] Nếu `jsx: "react-jsx"` trong `tsconfig.test.json` xung đột với build test hiện có → tách test `.tsx` sang
