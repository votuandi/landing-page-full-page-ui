## Thiết kế
**Font** — lưu `site.themeOverrides.font = { sans?, display? }` (thiếu khóa = font theme).
- `packages/tokens`: `ThemeOverridesSchema` thêm `font: strictObject({ sans: string.max(60).optional(), display: … }).optional()`.
  `themeToCss` không đổi (bỏ qua `font`).
- `packages/themes/src/fonts.ts`: `export const FONT_FAMILIES = Object.keys(FONTS)`; `withFontOverride(theme, font?) → ThemeTokens | null`
  (không override → trả `theme`; family ngoài allowlist hoặc thiếu weight → `null`, không ném).
- Admin `appearance.ts`: handler `fonts` (action `saveFonts`, `theme.manage`): `!can("themeOverride")` → 403 "Gói hiện tại không hỗ
  trợ font thương hiệu"; family ∉ `FONT_FAMILIES` → 400; `withFontOverride(theme hiện tại)` null → 400 nêu font + weight thiếu; lưu
  `{ ...overrides, font }` (giữ `colors`; font rỗng → xóa khóa `font`). `assertBrandContrast` mở rộng thành `assertOverrides(theme,
  overrides)`: thêm kiểm font tương thích → `theme`/`preview` đổi sang theme có weight font không có bị từ chối kèm gợi ý.
- Web: `loadTenantSite` trả thêm `font` = override chỉ khi `siteCanUse(site)("themeOverride")` (hạ gói → `undefined`). `TenantLayout`:
  `const theme = withFontOverride(site.theme, site.font) ?? site.theme` (sau `applyPreviewTheme`) cho `themeFontCss` + preload. Override
  hỏng/không tương thích → font theme gốc, `console.error` một dòng.
- UI: panel "Font chữ" (chỉ khi `canOverride`, như panel màu): hai `<select>` "Chữ nội dung" / "Tiêu đề", lựa chọn đầu "Theo theme (<font>)".

**Favicon** — lưu `profile.brand.favicon = <media uuid>`.
- `siteProfileSchema.brand.favicon: z.uuid().optional()`; `siteProfileMediaIds` thêm favicon → `saveSiteSettings` tự `publishMedia`.
- Admin handler `favicon` (action `saveFavicon`, `theme.manage`, mọi gói): payload `{ favicon: uuid | null }`; dep mới
  `media(tenantId, id)` qua `forTenant` → không có (tenant khác/không tồn tại) → 404 "Không tìm thấy ảnh"; `status !== "ready"` hoặc
  mime ∉ {png, jpeg, webp, gif, avif} → 400; lưu profile giữ mọi khóa brand khác. Dep `images(tenantId)` (ready + `image/*`, mới nhất,
  `take: 60`) cho trang; UI radio có thumbnail `/api/media/<id>` + "Biểu tượng mặc định".
- Web `apps/web/src/lib/tenant/icon.ts`: `createIconHandler({ loadSite, media, storage, resize })(tenantId, siteId, size)`:
  site → `profile.brand.favicon` → `media(tenantId, id)` (forTenant) phải `ready`, `visibility: public`, key bắt đầu `tenants/<tenantId>/`
  → `storage.get(key)` → `sharp(...).resize(size, size, { fit: "cover" }).png()` → 200 `image/png`, `Cache-Control: public, max-age=86400`.
  Mọi nhánh khác → 307 `/favicon.svg` với `no-store`. Route `sites/[tenantId]/[siteId]/icon.png/route.ts` (64) và
  `apple-icon.png/route.ts` (180). Proxy rewrite thêm hai path này như robots.
- `tenantMetadata`: site có favicon → `icons: { icon: [{ url: "/icon.png?v=<id>", type: "image/png", sizes: "64x64" }], apple:
  [{ url: "/apple-icon.png?v=<id>", sizes: "180x180" }] }`; không → giữ `/favicon.svg`. Invalidation: lưu settings đã enqueue
  `tenantTag`; metadata render theo request; `?v=<mediaId>` đổi URL khi đổi ảnh.

## Case biên & bất biến
- Không tin client: entitlement, allowlist, weight, media tenant kiểm ở server (unit trên handler, không qua UI).
- Media: `null`/uuid sai định dạng → 400; media `quarantine`/`failed` → 400; `private` lúc lưu được nhận (publish sau), web chỉ phục vụ `public`.
- Storage trả `null` hoặc sharp lỗi (ảnh hỏng) → 307 fallback, không 500.
- Chuỗi font chỉ vào CSS sau `withFontOverride` (allowlist) — không chèn được `"` / `}`: test `fonts.test › rejects css injection name`.
- Preview theme cookie + font override → font override áp lên theme preview, không tương thích → font theme.
- Hai request lưu song song → 409 (khóa `updatedAt` có sẵn).
- Tắt JS: font/favicon từ SSR, không phụ thuộc client.
