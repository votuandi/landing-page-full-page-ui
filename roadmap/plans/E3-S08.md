## Mục tiêu
Chọn phân khúc một lần (lưới `segments`, chip lọc, tab gói, ô phân khúc của dự toán) thì video, gói, công trình, dự toán
cùng đổi theo, không tải lại trang. State nằm trong provider client đặt ở layout site; section chỉ dùng `useSegment()` và
`useOpenCalculator()`. Trang không có `segments` vẫn chạy với phân khúc mặc định; trang không có `calculator` thì
`openCalculator` điều hướng tới trang có calculator hoặc mở dialog tư vấn. Giỏ báo giá đính kèm được kết quả dự toán
đã lưu (phần E3-S07 để lại).

## Thiết kế

**Module mới** `packages/sections/src/state/`:
```
state/logic.ts        thuần, test bằng node:test
state/SiteState.tsx   "use client": SiteStateProvider, useSegment, useOpenCalculator
```

`logic.ts`:
```ts
/** Thay/xóa ?phan-khuc= trong search, giữ tham số khác. */
export function withSegmentParam(search: string, segment: Segment | null): string   // trả "?…" hoặc ""
export type CalculatorAction = { kind: "bus" } | { kind: "navigate"; href: string } | { kind: "consult" };
/** onPage: trang có #du-toan. calculatorHref: undefined → "/" (giữ hành vi cũ), null → site không có trang dự toán. */
export function resolveCalculatorAction(onPage: boolean, calculatorHref: string | null | undefined, prefill: CalculatorPrefill): CalculatorAction
// navigate: `${href}${q ? `?${q}` : ""}#${CALCULATOR_ID}` với q = prefillToSearch(prefill); href chỉ nhận đường dẫn
// bắt đầu bằng "/" (không phải "//"), sai → coi như null.
```

`SiteState.tsx`:
```ts
type SegmentState = {
  segment: Segment | null;  // null = "Tất cả"
  version: number;          // tăng mỗi lần chọn chủ động, kể cả chọn lại cùng phân khúc
  source?: string;
  setSegment(segment: Segment | null, source?: string): void;
  focusSegment(segment: Segment, anchor: string, source?: string): void;
};
export function SiteStateProvider(props: { children: ReactNode; calculatorHref?: string | null }): JSX.Element
export function useSegment(): SegmentState
export function useOpenCalculator(): (input?: Segment | CalculatorPrefill) => void
```
- Một hook nội bộ `useSegmentStore()` chứa toàn bộ logic: state `{segment, version, source}`; mount → đọc
  `segmentFromParam(?phan-khuc)`, có thì set (không đổi URL); `setSegment` → cập nhật state + `history.replaceState`
  với `withSegmentParam` (giữ hash, để reload/chia sẻ link giữ phân khúc); `focusSegment` → `setSegment` rồi
  `requestAnimationFrame` → `getElementById(anchor)?.scrollIntoView` (tôn trọng `prefers-reduced-motion`); **không có
  phần tử thì không điều hướng** (khác `scrollToSection` của core — state đã đổi tại chỗ).
- `SiteStateProvider` gọi `useSegmentStore()` và đặt context (kèm `calculatorHref`).
- `useSegment()`: luôn gọi `useSegmentStore()` (luật hooks) nhưng trả context nếu có. Không có provider → mỗi island
  dùng store cục bộ = đúng hành vi hiện tại (đọc URL riêng). Nhờ vậy section chạy ở mọi trang/lab/test không cần provider.
- `useOpenCalculator()`: `resolveCalculatorAction(!!document.getElementById(CALCULATOR_ID), ctx?.calculatorHref, prefill)`
  → `bus`: `openCalculator` của core (dispatch + cuộn); `navigate`: `window.location.href = href`; `consult`:
  `openConsult()` (widget `consult-popup` mở dialog có form). Không có provider → `calculatorHref` undefined → "/".
- Không thêm trường site vào `SiteContext`; E5-S04 truyền `calculatorHref` khi dựng layout site từ DB (trang nào có
  section `calculator`). Core `openCalculator` giữ nguyên chữ ký (apps/web cũ còn dùng).

**Section dùng state chung** (chỉ đổi state/handler, không đổi giao diện):
- `segments`: thêm `segments/t15.island.tsx` — `SegmentLink` client bọc `<a>` hiện có: click trái thường →
  `preventDefault` + `focusSegment(item.segment, data.targetAnchor)`; Ctrl/Meta/Shift/Alt/chuột giữa → để trình duyệt
  xử lý (dùng lại điều kiện của `handleCalculatorClick`; tách hàm `isPlainClick(event)` trong `fields/calculatorClick.ts`
  và dùng ở cả hai). `aria-current="true"` khi thẻ trùng phân khúc đang chọn. Nội dung thẻ (ảnh, chữ) vẫn render ở
  server, truyền làm `children`. `href` giữ nguyên → chạy khi tắt JS.
- `packages`: bỏ state + đọc URL; `current = segment && tabs.some(tab => tab.segment === segment) ? segment : defaultSegment`;
  bấm tab → `setSegment(t.segment)`; "Nhận tư vấn" → `useOpenCalculator()`.
- `shorts`, `projects`: bỏ state + đọc URL; dùng `segment`/`setSegment` chung (chip "Tất cả" → `setSegment(null)`).
  `shorts` vẫn cuộn băng về đầu khi đổi phân khúc (effect theo `segment`).
- `calculator`:
  - `chooseSegment(next)` → như cũ + `shared.setSegment(next)`.
  - Bus/URL prefill có `segment` hợp lệ → như cũ + `shared.setSegment(s, source)`.
  - Effect theo `[shared.version]`: `version > 0`, `shared.segment` thuộc `allowed` và **khác** phân khúc local →
    `applySegment` + `setTouched(true)`. So sánh "khác" để không ghi đè `hoa-don` từ URL (effect của provider chạy sau
    effect con khi mount) và để không lặp vòng khi calculator tự set.
  - Lưu dự toán: thay ghi localStorage inline bằng `saveLastEstimate(...)` (core, dưới).
- `CalculatorLink`, `Anchor`: truyền `useOpenCalculator()` vào `handleCalculatorClick(event, prefill, open)`.
- `mobile-bottom-nav`: `openCalculator(link.calculator)` → `useOpenCalculator()`.
