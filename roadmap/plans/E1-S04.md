# Plan E1-S04 — Ảnh chụp hồi quy trực quan (baseline)

- Story: roadmap/epics/E01-monorepo.md · Cỡ: M

## Mục tiêu
Có bộ ảnh chụp tự động của site t15 trong `apps/web` (mọi route × 390/1440 × light/dark) để mọi story refactor sau
(E1-S05, E1-S06, E2…) phát hiện thay đổi giao diện ngoài ý muốn: `pnpm visual:test` so sánh và xuất report HTML,
`pnpm visual:update` cập nhật baseline, CI tự chạy trên PR chạm giao diện.

## Bối cảnh đã khảo sát
- Route (`apps/web/src/app/**/page.tsx`): tĩnh `/`, `/cam-nang`, `/giai-phap`, `/lien-he`, `/san-pham`, `/tin-tuc`,
  `/ve-chung-toi`; động `/chinh-sach/[slug]`, `/cong-trinh/[slug]`, `/giai-phap/[slug]`, `/san-pham/[slug]`,
  `/tin-tuc/[slug]` — đều có `generateStaticParams` (`policies`, `PROJECTS`, `SERVICES`, `PRODUCTS`, `POSTS`).
  `/san-pham/[slug]` chỉ có trang khi `catalogEnabled` (`NEXT_PUBLIC_CATALOG_ENABLED`) → đây là lý do epic ghi "11 route".
- Theme: `apps/web/src/app/layout.tsx` đặt `<html data-theme>` từ `localStorage["t15-theme"]` (script chạy trước khi vẽ);
  `globals.css` định nghĩa `[data-theme="light"|"dark"]`.
- Chuyển động: `globals.css` đã có `@media (prefers-reduced-motion: reduce)`; `lib/useCountUp.ts` nhảy thẳng giá trị cuối
  khi reduce. Vùng động còn lại: marquee `components/layout/TopBar.tsx` (`.t15-marquee`), iframe YouTube/TikTok
  (`components/StoryPlayer.tsx`, `components/ui/VideoModal.tsx` — chỉ nạp khi bấm), các thành phần có `setInterval`/
  `Date.now()` (`HeroStats`, `StatsSection`, `SolarEstimator`, `sections/{Dealer,FeaturedProjects,Social}Section`).
- Ảnh trong `apps/web/public` (105 MB, local); không phụ thuộc ảnh ngoài khi render.
- `pnpm-lock.yaml` đã có `@playwright/test` (gián tiếp); chưa có thư mục `tooling/`; `pnpm-workspace.yaml` chỉ có
  `apps/*`, `packages/*`.
- CI monorepo: `.github/workflows/workspace.yml` (windows + ubuntu, pnpm cache, turbo). `ci.yml` là workflow cũ của
  template — không đụng (E1-S07 xử lý).
- Quyết định của chủ dự án (2026-10-09): **baseline lưu bằng artifact CI**, không git LFS, không commit ảnh.

## Thiết kế
- **Package `tooling/visual`** (`@solar/visual`, private), thêm `tooling/*` vào `pnpm-workspace.yaml`.
  devDependency `@playwright/test` (ghim đúng phiên bản, chỉ dev — không phải dependency runtime).
  - `tooling/visual/routes.ts`: danh sách route cố định + slug đầu tiên của mỗi route động lấy từ dữ liệu của
    `apps/web` (đọc slug thật, ghi cứng trong file kèm chú thích nguồn; không import chéo package). Route nào
    trả 404 với env mặc định (vd. `/san-pham/[slug]` khi catalog tắt) thì bỏ, ghi chú lý do → số route thực tế
    ghi vào report và README.
  - `tooling/visual/playwright.config.ts`:
    - projects = 4 tổ hợp `{mobile-390, desktop-1440} × {light, dark}`; chỉ Chromium.
      Viewport 390×844 và 1440×900; `reducedMotion: "reduce"`; `colorScheme` khớp theme.
    - Theme đặt bằng `page.addInitScript` ghi `localStorage["t15-theme"]` trước khi nạp trang.
    - `webServer`: `pnpm --filter web start --port 3210` (cổng riêng, không đụng dev 3000),
      `reuseExistingServer: !process.env.CI`; build làm trước ở script (xem dưới).
    - `expect.toHaveScreenshot`: `fullPage: true`, `animations: "disabled"`, `caret: "hide"`,
      `maxDiffPixelRatio: 0.005` (Target epic ≤ 0,5%), `scale: "css"`.
    - `snapshotPathTemplate`: `__screenshots__/{platform}/{projectName}/{arg}{ext}` — baseline tách theo nền tảng vì
      font Windows/Linux khác nhau; CI dùng `linux`.
    - reporter: `[["html", { outputFolder: "playwright-report", open: "never" }], ["list"]]`.
    - `workers`: mặc định của Playwright (song song) để đạt Target ≤ 3 phút.
  - `tooling/visual/visual.spec.ts`: mỗi route một test; chờ `networkidle` + `document.fonts.ready`; cuộn hết trang
    rồi về đầu để kích hoạt lazy image/reveal; `mask` các vùng động bằng selector ổn định (marquee `.t15-marquee`,
    iframe, phần tử số liệu chạy). Chỉ khi không có selector ổn định mới thêm thuộc tính `data-visual-mask` vào
    component trong `apps/web` (không đổi giao diện; ghi rõ trong báo cáo từng chỗ).
  - `tooling/visual/.gitignore`: `__screenshots__/`, `playwright-report/`, `test-results/`.
  - `tooling/visual/README.md`: cách chạy local, vì sao baseline local khác CI, cách cập nhật baseline có chủ đích.
  - Scripts package: `test` **không** có (để `turbo run test` không cần trình duyệt); `typecheck` (`tsc --noEmit`),
    `lint` (eslint dùng `@solar/config`), `visual:test` = `playwright test`, `visual:update` =
    `playwright test --update-snapshots`.
- **Root `package.json`**: `visual:test` = `turbo run build --filter=web && pnpm --filter @solar/visual visual:test`;
  `visual:update` tương tự với `visual:update`. (Build qua turbo để dùng cache.)
- **CI `.github/workflows/visual.yml`** (ubuntu, Chromium, cache pnpm + `~/.cache/ms-playwright`,
  `permissions: contents: read, actions: read`):
  - Trigger `push` vào `mono-repo-multi-tenent` + `workflow_dispatch` → job `baseline`: `pnpm visual:update`, upload
    artifact `visual-baseline` (thư mục `tooling/visual/__screenshots__/linux`, `retention-days: 90`).
  - Trigger `pull_request` vào `mono-repo-multi-tenent`, `paths`: `apps/web/**`, `packages/ui/**`,
    `packages/sections/**`, `packages/themes/**`, `packages/tokens/**`, `tooling/visual/**`, `pnpm-lock.yaml`,
    `.github/workflows/visual.yml` → job `compare`:
    1. Tải baseline: `gh run list --workflow visual.yml --branch mono-repo-multi-tenent --event push --status success
       --limit 1 --json databaseId` rồi `gh run download <id> -n visual-baseline` (dùng `GITHUB_TOKEN`, không action
       bên thứ ba).
    2. Không có artifact (lần đầu / hết hạn) → fallback: `git worktree add` ở merge-base với base, `pnpm install
       --frozen-lockfile`, `pnpm visual:update` trong worktree đó, copy `__screenshots__/linux` sang cây PR. Ghi
       `::notice::` cho biết baseline sinh tại chỗ.
    3. `pnpm visual:test`. Fail → upload artifact `visual-report` (`playwright-report` + `test-results`, 14 ngày).
  - Trigger `push` cũng dùng `paths` như trên để không sinh baseline vô ích.
  - Không đặt làm required check (chủ dự án quyết định riêng).

## Các bước
1. Thêm `tooling/*` vào `pnpm-workspace.yaml`; tạo `tooling/visual/package.json`, `tooling/visual/tsconfig.json`
   (extends `@solar/config` base), `tooling/visual/eslint.config.mjs`; `pnpm install` cập nhật `pnpm-lock.yaml`
   — kiểm bằng: `pnpm turbo run typecheck lint` gồm `@solar/visual`.
2. Viết `tooling/visual/routes.ts`, `tooling/visual/playwright.config.ts`, `tooling/visual/visual.spec.ts`,
   `tooling/visual/.gitignore`, `tooling/visual/README.md` — kiểm bằng: `pnpm visual:update` tạo đủ ảnh (số route × 4).
3. Root scripts `visual:test`, `visual:update` trong `package.json`.
4. Ổn định: chạy `pnpm visual:test` 3 lần liên tiếp ngay sau `visual:update` → 0 lệch. Lệch → thêm mask/chờ cho
   vùng đó (không nới `maxDiffPixelRatio`). Ghi thời gian chạy (Target ≤ 3 phút, không tính build).
5. Chứng minh phát hiện lệch: tạm đổi một giá trị trong `apps/web/src/app/globals.css` (vd. màu `--c-primary`),
   chạy `pnpm visual:test` → fail và có `tooling/visual/playwright-report/index.html`; hoàn tác thay đổi
   (không commit). Ghi log + số test lệch vào báo cáo.
6. `.github/workflows/visual.yml` như Thiết kế — kiểm bằng: `actionlint` nếu có, không thì đọc lại kỹ cú pháp;
   CI thật chạy trên PR này (chạm `tooling/visual/**` → job `compare`, lần đầu đi nhánh fallback).
7. Tick AC1, AC2 trong `roadmap/epics/E01-monorepo.md`; AC3 để Claude tick khi job `compare` xanh trên PR.

- Đổi giao diện `apps/web` (ngoại trừ thuộc tính `data-visual-mask` nếu bắt buộc).
