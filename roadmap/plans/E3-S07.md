## Mục tiêu
7 widget toàn site (`contact-dock`, `consult-popup`, `mobile-bottom-nav`, `commitments-strip`, `quote-cart`,
`theme-switch`, `scroll-progress`) nằm trong `packages/sections/src/widgets/*`, mỗi widget có schema zod + fixture
`[DỮ LIỆU MẪU]` + variant `t15`. Cấu hình site có `widgets: { [key]: { enabled, variant, data } }`; renderer
`SiteWidgets` chỉ render widget đã bật và đủ entitlement (`quote-cart` cần `catalog`).

## Thiết kế

**Cấu trúc** `packages/sections/src/widgets/`:
```
widgets/config.ts          widgetEntrySchema, siteWidgetsSchema, SiteWidgetsConfig
widgets/registry.ts        widgetRegistry = createRegistry({...7 widget}), WIDGET_SLOTS
widgets/events.ts          bus window CustomEvent: openConsult/onOpenConsult ("t15:open-consult"),
                           toggleSiteMenu/onToggleSiteMenu ("t15:toggle-site-menu")
widgets/SiteWidgets.tsx    renderer
widgets/<key>/schema.ts · fixtures.ts · index.ts · t15.tsx (+ t15.client.tsx/t15.island.tsx khi tương tác)
```
Mỗi widget dùng `defineSectionType` (type = key widget, `schemaVersion: 1`, `defaults = schema.parse(fixture)`) và
`defineVariants(def, "t15", { t15 })` — cùng khuôn với section, không thêm abstraction mới.

**Cấu hình site** (`config.ts`):
```ts
widgetEntrySchema = z.object({ enabled: z.boolean().default(false), variant: z.string().min(1).default("t15"), data: z.unknown() })
siteWidgetsSchema = z.object({ "contact-dock": widgetEntrySchema.optional(), …7 key }) // key lạ bị bỏ qua
```
Export `siteWidgetsSchema`, `SiteWidgetsConfig`, `widgetRegistry`, `SiteWidgets`, `openConsult` từ `index.ts`.
Refine: `contact-dock.data.mobileBar === true` và `mobile-bottom-nav.enabled` cùng lúc → lỗi (hai thanh cố định đè nhau).

**Renderer** `SiteWidgets({ widgets, site, slot, canUse = () => true, loadData?, registry = widgetRegistry })`
(Server Component, async): `slot: "inline" | "overlay"`; `WIDGET_SLOTS` = `commitments-strip` → `inline`, còn lại
`overlay`. Lọc `enabled` + `meta.entitlement` qua `canUse`, parse `data` bằng schema (data thiếu → `defaults`), variant lạ
→ default (`getVariant`), lỗi chuẩn bị → log `[sections]` có `tenantId` và bỏ widget (không làm vỡ trang), bọc
`SectionBoundary`. `loadData` cùng chữ ký `LoadSectionData` (truyền `{ section: { id: key, type: key, … } }`) để
`quote-cart` dùng `createCollectionLoader`. Layout site đặt `<SiteWidgets slot="inline">` trước footer và
`<SiteWidgets slot="overlay">` cuối `<body>`.

**Schema** (chuỗi hiển thị là `localized()`; link là `link()` + `resolveLink` ở server; island chỉ nhận chuỗi/href đã resolve):
- `contact-dock`: `items[1..4] {kind: consult|call|zalo|messenger, label, link?}` (refine: `kind ≠ consult` phải có
  `link`), `mobileBar: boolean` (mặc định `false`), `ariaLabel`. `consult` → `openConsult()`. Desktop: cột nút tròn góc
  phải mở rộng nhãn khi hover/focus; mobile (khi `mobileBar`): thanh tròn đáy, `env(safe-area-inset-bottom)`.
- `consult-popup`: `delayMs` (int 0..600000, mặc định 30000), `scrollRatio` (0.1..1, mặc định 0.6), `autoOpen` (mặc định
  `true`), `title`, `description`, `openFormLabel`, `submitLabel`, `channels[≤2] {kind: zalo|messenger, link}`, chuỗi
  `LeadForm` (`success`, `privacy`). Hành vi giữ nguyên t15: tự mở sau `delayMs` HOẶC khi cuộn ≥ `scrollRatio`, tối đa
  **1 lần/phiên** (sessionStorage `t15-consult-shown`, fallback bộ nhớ), hoãn 5 s khi đang có `[aria-modal="true"]`;
  `onOpenConsult` mở ngay kèm form. Dialog tải lười (`next/dynamic` khi mở). LeadForm `source: "popup"`.
- `mobile-bottom-nav`: `items[3..5] {icon: home|menu|call|zalo|calculator|cart, label, link?, emphasis?: boolean}`
  (refine: `menu`/`cart` không cần link, còn lại bắt buộc; tối đa 1 `emphasis`). `menu` → `toggleSiteMenu()`
  (site-header island đăng ký `onToggleSiteMenu` để mở/đóng drawer — sửa nhỏ duy nhất ở header); `cart` →
  `openQuoteCart()`; `emphasis` = nút tròn nổi giữa như ô "Gọi" t15. Chỉ hiện `< lg`.
- `commitments-strip`: `ariaLabel`, `items[1..4] {icon: survey|warranty|paperwork|maintenance, title, description}`.
  Server-only.
- `quote-cart`: `meta.entitlement: "catalog"`, `meta.collections: ["products"]`, `query: collectionQuery("products")`
  (mặc định limit 48), `items: z.array(productItem).default([])`, nhãn (`title`, `note`, `emptyText`, `browseLabel`,
  `browseLink: link()`, `formTitle`, `formDescription`, `messagePlaceholder`, `submitLabel`, `successTitle`,
  `successMessage`, `continueLabel`, `buttonLabel`). Island: nút nổi có badge số lượng (ẩn khi giỏ rỗng trừ khi drawer
  đang mở) + drawer phải (`useDialog`, Esc đóng, focus trả về), dòng giỏ lọc theo `items` (`sanitizeCart` với slug
  đã biết), tăng/giảm/xóa (`setQty`/`removeItem` + `writeQuoteCart`), `LeadForm source="quote-cart"`, `getExtra` gửi
  `items: [{sku, name, qty}]` (nới kiểu `Extra` của LeadForm thêm `items?`), thành công → `clearCart`. Nghe
  `onQuoteCartChange`, `onOpenQuoteCart`. Đính kèm dự toán đã lưu: không làm (E3-S08).
- `theme-switch`: `lightLabel`, `darkLabel`. Island: nút nổi tròn (desktop cạnh dock, mobile góc trên) đổi
  `document.documentElement.dataset.theme`, lưu localStorage `t15-theme` (try/catch), `aria-pressed`. Script áp theme
  trước khi vẽ vẫn ở layout app (ngoài phạm vi).
- `scroll-progress`: `z.object({})`. Server-only: `<div aria-hidden class="t15-scroll-progress" />` (CSS sẵn có).

**Lab**: SiteShell cũ bọc mọi route → thêm điều kiện nhỏ trong `apps/web/src/components/SiteShell.tsx`: pathname bắt đầu
`/lab/sections/t15-widgets` thì không render ContactDock, ConsultPopup, MobileBottomNav, CommitmentsStrip, thanh
scroll-progress và drawer của `QuoteCartProvider` cũ (cầu tạm tới E4-S01). Trang lab
`apps/web/src/app/lab/sections/t15-widgets/page.tsx`: vài section ngắn làm nền cuộn + `SiteWidgets` inline/overlay với
cả 7 widget bật; `?plan=basic` → `canUse = (f) => f !== "catalog"`; `?lang=en`.

## Design pass
- Codex dựng: schema, fixture, config/registry/renderer, bus, island và logic (popup hẹn giờ, giỏ, theme), port giao diện
  t15 sang token, test, lab, spec, sửa nhỏ SiteShell/header.
- Claude làm sau: chụp `/lab/sections/t15-widgets` ở 390px/1440px, light/dark t15 + ≥ 2 theme khác (vd. t08, t12) bằng
  MCP playwright; so với trang chủ `/` (widget cũ). Chỉnh vị trí/xếp chồng các nút nổi (dock, theme-switch, giỏ không đè
  nhau và không đè bottom-nav; safe-area), vùng chạm ≥ 44px, tương phản badge giỏ, focus/aria dialog & drawer,
  `prefers-reduced-motion` (hover mở rộng nhãn, popup). Ảnh vào `.agent-runs/E3-S07/screenshots/`, ghi `design-pass.md`.
