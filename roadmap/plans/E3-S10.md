## Mục tiêu
Designer/dev mở `/lab/sections/<type>?themes=…&variant=…` để thấy mọi variant của một type dưới nhiều theme cạnh nhau.
CI chụp ma trận (variant × theme × 2 viewport × sáng/tối), so baseline, chạy script computed-style chặn màu ngoài token
và xuất report HTML đánh dấu ô có tương phản < AA (axe-core).

## Thiết kế

### 1. Scope CSS theme (tokens, themes)
- `themeToCss(theme, overrides?, options?: { scope?: string })`: không có `scope` → output **giữ nguyên byte-for-byte**.
  Có `scope` (vd. `[data-lab-theme="t15"]`): light `${scope}{…}`; dark (nếu `supportsDark`)
  `[data-theme="dark"] ${scope}{…}` + `@media (prefers-color-scheme:dark){:root:not([data-theme]) ${scope}{…}}`.
  Kiểm `scope` khớp regex an toàn `^\[data-lab-theme="[a-z0-9-]+"\]$` (tránh chèn CSS) — chỉ chấp nhận đúng dạng này.
- `themeFontCss(theme, baseUrl?, scope?)` tương tự: thay `:root` bằng `scope` khi có. Mặc định giữ nguyên.
- Test unit cho cả hai (mặc định không đổi; scope đúng selector; scope bẩn → throw).

### 2. Liệt kê variant (sections)
- Thêm `variantsOf(type): string[] | null` vào `createRegistry` (`Object.keys(entry.variants)`), `null` khi type không có.
  Test unit.

### 3. Route lab (apps/web)
- `apps/web/src/app/lab/sections/[type]/page.tsx`:
  - `params.type` không có trong `sectionRegistry` → `notFound()`.
  - `?themes=t15,t08` (lọc theo `getTheme`, bỏ id lạ; rỗng/không có → mọi `themes`), `?variant=a,b` (lọc theo
    `variantsOf`; rỗng → mọi variant), `?lang=en` như `t15-content`.
  - Mỗi theme: `<style>` từ `themeToCss(theme, undefined, { scope })` + `themeFontCss(theme, undefined, scope)`;
    `<div data-lab-theme="<id>">` bọc các ô. Mỗi ô `<div data-lab-cell="<variant>--<theme>" data-lab-variant data-lab-theme-id>`
    chứa một `PageRenderer` một section (`variant`, `data: defaults`, `site.themeId = theme.id`, `tenantId: "lab-demo"`).
    Nhãn ô (type · variant · theme) đặt **ngoài** vùng chụp/kiểm màu của ô.
  - Nhúng `<script type="application/json" id="lab-palette">` = `{ [themeId]: { supportsDark, light: {key: "r g b"}, dark: {...} } }`
    lấy từ `theme.colors` (gồm cả glass key) — nguồn bảng token cho script màu, để `tooling/visual` không import code app.
  - Class chỉ dùng token (luật §4).
- `apps/web/src/app/lab/sections/matrix/page.tsx`: danh sách link mọi type (`Object.keys(sectionRegistry.types)`) kèm
  variant và theme, mỗi link `data-lab-type="<type>"`. Static segment ưu tiên hơn `[type]` nên không xung đột.
- Logic thuần (parse query, dựng palette JSON) đặt trong một file nhỏ cùng thư mục và có test unit trong
  `apps/web/src/lib/__tests__` (theo pattern hiện có, thêm file test vào script `test` của web).

### 4. Harness ma trận (tooling/visual)
- `matrix.ts`: `matrixTypes` — danh sách tĩnh 28 type (Playwright cần biết test lúc load). Spec có một test bảo vệ:
  mở `/lab/sections/matrix`, so tập `data-lab-type` với `matrixTypes` → thiếu/thừa type là fail.
- `matrix-colors.ts`: hàm thuần `findOffTokenColors(samples, palette)` + hàm chạy trong trang `collectColorSamples(cell)`.
  - Duyệt mọi phần tử hiển thị trong ô (`getClientRects().length > 0`, bỏ `visibility:hidden`), đọc computed:
    `color`, `background-color`, `background-image` (màu trong gradient), `border-{top,right,bottom,left}-color` (chỉ khi
    width > 0 và style ≠ none), `outline-color` (khi outline-style ≠ none), `text-decoration-color` (khi có decoration),
    `box-shadow` (màu trong chuỗi), `fill`/`stroke` (phần tử SVG, khác `none`).
  - Màu hợp lệ: alpha = 0 / `transparent`; hoặc kênh RGB khớp (±1) một token của theme đang render (light, hoặc dark khi
    `html[data-theme=dark]` và theme `supportsDark`), alpha bất kỳ. Dạng không parse được (oklab, color-mix…) → tính là
    ngoài token.
  - Bỏ qua phần tử trong `[data-brand-icon]`: thêm thuộc tính này vào component trong `packages/ui/src/brand-icons`
    (thay đổi 1 dòng mỗi icon, có chú thích). Nội dung pixel của `img`/`video`/`iframe` không thuộc CSS — không xét.
  - Test unit bằng `node:test` (thêm script `test` cho `@solar/visual` theo pattern tsc → `.test-dist` của repo, để
    `turbo run test` chạy, không cần browser): token khớp, alpha, gradient/box-shadow, màu lạ `rgb(255, 0, 0)` bị bắt,
    oklab bị bắt, transparent bỏ qua.
- `matrix.spec.ts`: mỗi type một test. Đặt theme sáng/tối và chuẩn bị trang **giống `visual.spec.ts`** (tái dùng helper,
  tách ra file chung nếu cần, không đổi hành vi spec cũ). Với mỗi ô `[data-lab-cell]`:
  1. `findOffTokenColors` → `expect(offToken).toEqual([])` (thông điệp liệt kê selector + thuộc tính + giá trị).
  2. `AxeBuilder({ page }).include('[data-lab-cell="…"]').withRules(["color-contrast"])` → ghi số violation/node (không fail).
  3. `expect(cell).toHaveScreenshot([type, "<variant>--<theme>.png"])`.
  Ghi kết quả từng ô vào `test-results/matrix-results/<project>--<type>.json`.
- `playwright.matrix.config.ts`: kế thừa config chính; `testMatch: ["matrix.spec.ts"]`; 4 project tên `matrix-mobile-390-*`,
  `matrix-desktop-1440-*` (không đụng baseline của project cũ); `webServer.env.LAB_ENABLED = "true"`;
  `fullyParallel: true`; `updateSnapshots: "none"`; ô chưa có baseline (vd. theme mới ở E4) spec bỏ qua so ảnh kèm annotation,
  ô cũ vẫn so; CLI `--update-snapshots` ghi ảnh (sửa ở review: chế độ `missing` vẫn làm test fail); `outputDir: "test-results/matrix"`.
- `matrix-report.mjs` (Node thuần, không dependency): gộp JSON → `matrix-report/index.html`, bảng hàng = type/variant,
  cột = theme × viewport × sáng/tối; ô đỏ + số node khi contrast < AA, ô cam khi có màu ngoài token; tổng thời gian và
  tổng số ô ở đầu trang; dòng ghi chú "ma trận hiện có N theme — mục tiêu ≥ 4 theme đạt sau E4". `.gitignore` thêm
  `matrix-report/`.
- `package.json` scripts: `matrix:test` (`playwright test -c playwright.matrix.config.ts`), `matrix:update`
  (`… --update-snapshots`), `matrix:report` (`node matrix-report.mjs`), `test` (unit). Gốc repo thêm `visual:matrix`
  = build web (turbo cache) + `matrix:test` (theo mẫu `visual:test`).
- devDependency mới (chỉ dev, không runtime): `@axe-core/playwright` — bản stable mới nhất đã phát hành ≥ 2 tuần, ghim
  version chính xác, cập nhật `pnpm-lock.yaml`. Ghi lý do trong PR (AC axe-core).
