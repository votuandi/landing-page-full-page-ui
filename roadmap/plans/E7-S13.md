## Thiết kế
- **Một bộ lọc structure**: `siteStructureOf(site, pages)` trong `packages/db` (hoặc `@solar/presets`) bỏ Page có slug của
  loại trang không nằm trong `pageTypes`; `checkStructure` và `setPageTypes` dùng chung.
- `setPageTypes(db, tenantId, { siteId, pageTypes, expected })` trong `packages/db/src/siteStructure.ts`: transaction tenant,
  compare-and-set trên `expected` (khác → lỗi xung đột "Tải lại"), tạo Page thiếu (chưa xuất bản), validate, cập nhật
  `Site.pageTypes`, `enqueueInvalidate([siteTag])`. Áp dụng ngay (Site không có nháp pageTypes) — UI ghi rõ "Áp dụng ngay".
- Admin: khối "Danh mục trang" trên `/trang`: mỗi loại trang một switch (form + server action
  `setPageType({ type, enabled, expected })`, quyền `pages.structure`); bắt buộc → khóa "Bắt buộc"; ngoài gói → "Cần nâng
  cấp gói"; không `pageStructure` → switch tắt + nút nâng cấp, server vẫn kiểm. Nhãn tiếng Việt thêm vào `PAGE_TYPES`
  (`label: { vi }`). Danh sách trang hiện "Đã tắt" cho Page của loại không bật.
- Thumbnail: `pnpm --filter @solar/visual thumbnails` (Playwright, 1440px, chụp 900px đầu mỗi `[data-lab-cell]`, sharp →
  320×200 WebP q≈60) ghi `apps/admin/public/section-thumbs/<theme>/<type>--<variant>.webp` + manifest
  `packages/cms-ui/src/sections/thumbnails.generated.ts`. `thumbnailSrc(themeId, type, variant)` trả URL hoặc undefined.
  `SectionListEditor` thêm prop tùy chọn `thumbnail?(type, variant)` (cms-ui không biết theme). Menu đổi kiểu đổi từ
  `<select>` sang `fieldset` + radio card có ảnh (legend "Kiểu hiển thị: <label>"), giữ chọn được bằng bàn phím.
  `loadPageEditor` trả `themeId` của site.
- Xóa section: cột `SectionContent.removedAt DateTime?` + index `(tenantId, removedAt)`; migration kèm backfill. Sau mỗi
  `saveDraft`/`publishPage`: hàng không còn trong `draftSections ?? sections` lẫn `sections` → đặt `removedAt` (nếu null);
  được tham chiếu lại → null. `loadPageEditor` trả `removed[]` (sectionId, type, variant từ snapshot gần nhất hoặc variant
  đầu, `expiresAt`). Worker: `every(6h)` gọi `forPlatform(db).sectionContents.purgeRemoved({ now })`, kiểm lại tham chiếu +
  snapshot `PageVersion` mới nhất ngay trước khi xóa, ghi `AuditLog` như `scanExpiredOverrides`.
