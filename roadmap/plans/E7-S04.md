## Mục tiêu
Tenant gói có `sectionReorder` mở `/trang`, chọn một trang và sửa danh sách section: kéo thả (chuột + bàn phím), bật/tắt,
đổi variant, thêm từ thư viện, xóa — mọi thao tác chỉ lưu vào **draft**; nút "Xuất bản" mới chép sang bản chính và
revalidate. Ràng buộc `maxPerPage` kiểm cả ở client (khóa nút thêm, báo lỗi) và server (`validateSiteStructure`).
Trình sửa nằm ở `packages/cms-ui` để wizard E13-S06 dùng lại.

**Đã tách story (hỏi người dùng 17/10/2026)**: phần này giữ đủ 3 AC. Danh sách trang bật/tắt theo danh mục
(`pageStructure`), pipeline thumbnail chụp sẵn theo theme, job dọn dữ liệu section đã xóa sau 30 ngày → story mới
**E7-S13** (thêm vào epic trong commit plan). Thumbnail ở phần này: **ô giữ chỗ** (nhãn variant trên khối dùng token
theme), không ảnh chụp.

## Thiết kế

1. **`packages/sections` — `sectionLimitIssues`** (thuần):
   ```ts
   /** Lỗi tiếng Việt khi một type vượt meta.maxPerPage trên một trang; rỗng = hợp lệ. */
   export function sectionLimitIssues(sections: readonly { type: string }[], registry = sectionRegistry): string[];
   // vd. `Chỉ được có tối đa 1 "Dự toán chi phí" trên một trang`
   ```
   Đếm mọi section của type (kể cả `enabled: false` — bật lại không được vượt giới hạn).
   `validateSiteStructure` gọi hàm này cho từng `page` (thêm hậu tố ` (trang /<slug>)`), áp dụng cho mọi người gọi
   (wizard, CMS, super admin — D21).

2. **`packages/cms-ui` — `SectionListEditor`** (`"use client"`, `src/sections/SectionListEditor.tsx`):
   ```ts
   type EditableSection = { id: string; type: string; variant: string; enabled: boolean; anchor?: string };
   type SectionListEditorProps = {
     value: readonly EditableSection[];
     onChange(next: EditableSection[]): void;
     can: { reorder: boolean; variantSwitch: boolean };   // từ gói + quyền pages.structure
     allowedTypes: readonly string[];                     // type được thêm (đã lọc entitlement ở server)
     lockedTypes?: readonly string[];                     // type ngoài gói: hiện trong thư viện có khóa, không thêm được
     newId?(type: string): string;                        // mặc định `${type}-${crypto.randomUUID().slice(0, 8)}`
   };
   ```
   - Hàng: tay nắm kéo, nhãn `meta.label.vi`, variant hiện tại, ô thumbnail giữ chỗ, công tắc bật/tắt
     (`role="switch"`, `aria-checked`), menu "Đổi kiểu hiển thị" (liệt kê `sectionRegistry.variantsOf(type)`, mỗi mục có
     thumbnail giữ chỗ), nút xóa (xác nhận; ghi chú "Nội dung được giữ lại").
   - Kéo thả dnd-kit (chuột + bàn phím) và nút lên/xuống; thông báo tiếng Việt.
   - "Thêm section": danh sách `allowedTypes` (+ `lockedTypes` có khóa, `aria-disabled`); type đã đạt `maxPerPage` bị
     khóa với lý do. Lỗi `sectionLimitIssues(value)` hiện ở đầu danh sách (`role="alert"`).
   - `can.reorder = false` → không tay nắm, không công tắc/thêm/xóa; `can.variantSwitch = false` → không menu variant.
   - Thuần trình bày + state; không gọi mạng, không đọc phiên.
   - Hàm thuần đi kèm (`src/sections/ops.ts`): `move`, `toggle`, `setVariant`, `add`, `remove` — test riêng.

3. **`apps/admin` — logic trang** (`src/lib/pageSections.ts`, deps tiêm vào để test không cần DB):
   - `loadPageEditor(pageId, deps)`: `requirePermission("pages.view")`; page phải thuộc `siteId` của host (khác → null →
     `notFound()`); trả `{ page: { id, slug, title, revision }, sections: draftSections ?? sections, hasDraft,
     can: { reorder: can("sectionReorder") && has("pages.structure"), variantSwitch: can("variantSwitch") && has("pages.structure") },
     allowedTypes, lockedTypes, canPublish: has("pages.publish") }`.
   - Server Action `saveSectionsDraft` — `action("pages.structure", { pageId, revision, sections: JSON string }, …)`:
     kiểm page thuộc site của host, parse `sections` bằng schema descriptor, gọi `saveDraft` với `draftSections` và
     `sections: [{ sectionId, type, draftData: defaults }]` cho section **mới** (chưa có trong `draftSections ?? sections`
     của page). `RevisionConflictError` → `{ ok: false, status: 409, error: "Trang đã thay đổi. Tải lại trước khi lưu." }`;
     lỗi cấu trúc (`validateSiteStructure`) → trả đúng message tiếng Việt, status 400. Không gọi revalidate.
   - Server Action `publishSections` — `action("pages.publish", { pageId, revision }, …)` → `publishPage`.
   - Server Action `previewLink` — `action("pages.view", …)` → `createPreviewToken` → URL
     `<slug>.preview.<platform>/api/preview?token=…&path=/<slug>`.
   - Actor: phiên `user` → `{ siteUserId: session.accountId }`; phiên `ghost` → theo cách E15 lưu người thao tác (soát
     `kind`/`accountId` của ghost trong `packages/auth/src/realm.ts`; nếu ghost không có SiteUser thì `platformAdminId`).

4. **Trang admin**:
   - `(admin)/trang/page.tsx`: danh sách `Page` của site (slug, tiêu đề, trạng thái "Có bản nháp"/"Đã xuất bản"), link
     `/trang/[pageId]`. (Bật/tắt trang theo danh mục: E7-S13.)
   - `(admin)/trang/[pageId]/page.tsx` + client `PageSectionsEditor` (admin): `SectionListEditor` + thanh hành động
     "Lưu nháp" (bật khi có thay đổi và không có lỗi client), "Xem trước" (mở tab mới), "Xuất bản" (khi đã lưu, có
     `pages.publish`). Gói không có `sectionReorder`: thông báo "Gói hiện tại chỉ cho sửa nội dung" (đọc-only).
   - Thêm `@solar/presets` vào deps admin nếu cần (đã là workspace package).
