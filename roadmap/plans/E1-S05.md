## Mục tiêu
Logic tính toán/giá/SĐT/giỏ báo giá/định dạng/phân khúc/calculator bus nằm ở package thuần TS `@solar/core`
(không React/Next), test độc lập bằng `node:test`, hệ số dự toán truyền vào qua `CalculatorParams`.
`apps/web` chỉ import từ `@solar/core`; hành vi trang không đổi.

## Bối cảnh đã khảo sát
- Monorepo pnpm + Turbo đã có (E1-S02): `apps/web`, `packages/config`, `tooling/visual`. Turbo task `test` dependsOn `^build`.
- File cần chuyển (`apps/web/src/lib/`): `solarCalculator.ts` (import cứng `../config/solar`, `../config/segments`),
  `format.ts`, `price.ts`, `phone.ts`, `quoteCart.ts`, `calculatorBus.ts` (`"use client"`, dùng `window`/`CustomEvent`,
  `segmentFromParam`), `segment.tsx` (phần không React: `SECTION_IDS`, `scrollToSection`; còn lại là
  `SegmentProvider`/`useSegment` → ở lại web).
- `apps/web/src/config/segments.ts`: type `Segment`, `SEGMENT_ORDER`, `SEGMENTS` (nhãn hiển thị = nội dung), `isSegment`,
  `segmentFromParam` (dò theo `SEGMENTS[s].slug`). `.slug` còn được dùng ở `app/cong-trinh/[slug]/page.tsx:23`,
  `app/tin-tuc/[slug]/page.tsx:23`, `components/SiteFooter.tsx:93`.
- `apps/web/src/config/solar.ts`: type `Region`, `Tier`, `Tariff` + số liệu mẫu `TARIFFS`, `VAT_RATE`, `PRICE_PER_KWP`,
  `SYSTEM`, `PEAK_SUN_HOURS`, `PROVINCES`, `BILL_INPUT`, `ROOF_INPUT`, `REGION_LABELS`, `DEFAULT_PROVINCE`.
- Test hiện có: `apps/web/src/lib/__tests__/{solarCalculator,quoteCart}.test.ts`, chạy bằng
  `tsc -p tsconfig.test.json` (CJS → `.test-dist`) + `node --test`.
- Node local 20.20 (không có `--test-coverage-lines`), CI `workspace.yml` dùng Node 22.
- ADR: D1 (pnpm + Turbo), D12 (không thêm dependency). Chưa có ADR về test runner → thêm D15.

## Thiết kế
- **Package** `packages/core`, tên `@solar/core`, `private`, **không** có trường `"type"` (để `.test-dist` CJS chạy được).
  `exports: { ".": "./src/index.ts" }` — xuất source TS, không có bước build. `apps/web` thêm
  `"@solar/core": "workspace:*"` và `transpilePackages: ["@solar/core"]` trong `next.config.ts`.
  `dependencies` rỗng; devDeps: `typescript`, `@types/node`, `eslint`, `@solar/config` (cùng phiên bản `tooling/visual`).
- **Cấu trúc**:
  ```
  packages/core/
    package.json  tsconfig.json  tsconfig.test.json  eslint.config.mjs  README.md
    src/index.ts            barrel: export * từ các module dưới
    src/solarCalculator.ts  src/format.ts  src/price.ts  src/phone.ts  src/quoteCart.ts
    src/segment.ts          Segment, SEGMENT_ORDER, SEGMENT_SLUGS, isSegment, segmentFromParam, SECTION_IDS, scrollToSection
    src/calculatorBus.ts    CALCULATOR_ID, PACKAGES_ID, CalculatorPrefill, prefillToSearch, prefillFromSearch,
                            openCalculator, onOpenCalculator, prefillFromUrl
    src/__tests__/*.test.ts  + fixtures.ts (số liệu mẫu, ghi chú [DỮ LIỆU MẪU])
  ```
  `tsconfig.json` extends `@solar/config/tsconfig.base.json`, `lib: ["dom", "es2020"]` (bus/scroll dùng DOM API, không
  phải React), `types: ["node"]` chỉ cần cho test. `eslint.config.mjs` theo mẫu `tooling/visual/eslint.config.mjs`.
- **`CalculatorParams`** (thay `CalculatorOptions`, không có giá trị mặc định, core không import config):
  ```ts
  export type Region = "bac-bo" | "bac-trung-bo" | "nam-trung-bo" | "tay-nguyen" | "nam-bo";
  export type Tier = …; export type Tariff = …;            // chuyển nguyên từ config/solar.ts
  export type CalculatorParams = {
    tariffs: Record<Segment, Tariff>;
    vatRate: number;
    pricePerKwp: Record<Segment, number>;
    peakSunHours: Record<Region, number>;
    provinces: readonly { name: string; region: Region }[];
    system: { performanceRatio: number; m2PerKwp: number; panelWatt: number; kwpStep: number; minKwp: number };
  };
  calculateSolar(input: CalculatorInput, params: CalculatorParams): CalculatorResult
  estimateSavingForKwp(segment: Segment, kwp: number, province: string, params: CalculatorParams): number
  regionOf(province: string, provinces: CalculatorParams["provinces"]): Region
  billFromKwh / kwhFromBill            // giữ nguyên chữ ký
  ```
  Công thức giữ nguyên từng dòng (chỉ đổi nguồn hệ số). Bỏ re-export `formatMoneyShort…` khỏi `solarCalculator`
  (đã có trong barrel). `defaultDaytimeRatio` phụ thuộc `SEGMENTS` (nội dung) → chuyển sang `apps/web/src/config/segments.ts`.
- **apps/web/config/solar.ts**: import `Region`, `Tier`, `Tariff`, `CalculatorParams`, `Segment` từ `@solar/core`
  (không re-export), giữ số liệu, thêm `export const CALCULATOR_PARAMS: CalculatorParams = { tariffs: TARIFFS, … }`.
  Mọi chỗ gọi `calculateSolar`/`estimateSavingForKwp`/`regionOf` truyền `CALCULATOR_PARAMS`.
- **Segment**: slug URL (`ho-gia-dinh`…) là hợp đồng URL, không phải nội dung → `SEGMENT_SLUGS` ở core; bỏ trường `slug`
  khỏi `SEGMENTS` ở web, 3 chỗ dùng `.slug` đổi sang `SEGMENT_SLUGS[s]`. `SEGMENTS` (nhãn VI/EN, pitch,
  `defaultDaytimeRatio`) ở lại web, type `Record<Segment, …>` với `Segment` import từ core.
- **calculatorBus**: tách phần thuần để test được trong Node — `prefillToSearch(p): string` (query `phan-khuc`, `hoa-don`,
  `nhu-cau`, `nguon`, rỗng → `""`) và `prefillFromSearch(search: string): CalculatorPrefill`; `openCalculator` và
  `prefillFromUrl` gọi hai hàm này. Bỏ `"use client"` (core không phải React; component gọi vẫn là client component).
  Tên event `t15:open-calculator` giữ nguyên.
- **Không shim**: xóa các file cũ trong `apps/web/src/lib/` (trừ `segment.tsx` còn `SegmentProvider`/`useSegment`, giờ
  import `scrollToSection`, `segmentFromParam`, `Segment` từ core và **không** re-export `SECTION_IDS`/`scrollToSection`).
  Mọi importer đổi sang `from "@solar/core"`; `config/segments.ts` không re-export symbol đã chuyển.
- **Test (ADR D15)**: giữ `node:test`, không thêm dependency. `test` = `tsc -p tsconfig.test.json && node --test
  --experimental-test-coverage .test-dist/__tests__/` (in báo cáo phủ, chạy được trên Node 20).
  `test:coverage` = như trên + `--test-coverage-lines=85 --test-coverage-exclude="**/__tests__/**"` (Node ≥ 22.8),
  thêm một bước `pnpm --filter @solar/core test:coverage` vào `.github/workflows/workspace.yml` sau `turbo run test build`.
  Nếu glob thư mục của `node --test` không chạy trên Windows/Node 20 thì liệt kê file như script web hiện tại.
- `apps/web`: bỏ script `test` và `tsconfig.test.json` (không còn test ở web).

## Các bước
1. Tạo `packages/core` (package.json, tsconfig, tsconfig.test, eslint, README ngắn: mục đích, export, lệnh) —
   kiểm bằng: `pnpm install` cập nhật `pnpm-lock.yaml`, `pnpm --filter @solar/core typecheck`.
2. Chuyển `format`, `price`, `phone`, `quoteCart` nguyên văn (giữ comment) — `git mv` nếu tiện.
3. Viết `segment.ts`, `calculatorBus.ts` theo thiết kế; `solarCalculator.ts` nhận `CalculatorParams`.
4. Chuyển test sang `packages/core/src/__tests__/`: `solarCalculator.test.ts` (dùng `fixtures.ts` = bản sao số liệu mẫu
   của `config/solar.ts`, mọi assert giữ nguyên), `quoteCart.test.ts`; thêm `format.test.ts`, `segment.test.ts`
   (`isSegment`, `segmentFromParam` slug/key/null/sai), `calculatorBus.test.ts` (`prefillToSearch`↔`prefillFromSearch`,
   bill âm/NaN → undefined), `noFramework.test.ts` (đọc `package.json` + mọi file `src/**/*.ts` bằng `fs`, khẳng định không
   có dependency/import `react`, `react-dom`, `next`, `next/*`) — kiểm bằng: `pnpm --filter @solar/core test`, phủ dòng
   (trừ test) ≥ 85%.
5. Cập nhật `apps/web`: dependency + `transpilePackages`; `config/solar.ts` (`CALCULATOR_PARAMS`), `config/segments.ts`
   (bỏ slug/isSegment/segmentFromParam/Segment, thêm `defaultDaytimeRatio`), `lib/segment.tsx`, mọi importer
   (`grep -rn "lib/(solarCalculator|price|phone|quoteCart|format|calculatorBus)|config/(solar|segments)"`),
   xóa file cũ + `tsconfig.test.json` + script `test` — kiểm bằng: `pnpm --filter web typecheck lint`, `pnpm --filter web build`
   (một lần, để chắc `transpilePackages` + barrel chạy với Next).
6. ADR D15 trong `roadmap/02-decisions.md` (chèn ngay sau mục D14);
   bước CI coverage trong `workspace.yml`; tick AC trong epic.
