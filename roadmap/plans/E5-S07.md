## Mục tiêu
Có primitive DB cho lưu nháp / xuất bản nguyên tử (khóa lạc quan theo `Page.revision`, `PageVersion`, Outbox invalidate
trong cùng transaction) và đường preview `<slug>.preview.<platform>` bằng Draft Mode, vào qua token dùng một lần.
`apps/admin` (E7-S04/S05) sẽ gọi các hàm này; story này chưa có UI admin.

## Thiết kế
1. **Cấu hình**: env `PLATFORM_DOMAIN` (vd. `minwysoft.com`; dev/e2e `localhost`), `PREVIEW_SECRET` (≥ 32 byte). Đọc
   khi dùng, không ở module scope. Thêm vào `.env.example` web, `turbo.json` (`dev`/`web#test` passThroughEnv).
2. **DB** (migration `20261019010000_preview_publish`):
   - Bảng tenant `PreviewToken { id, tenantId, siteId, tokenHash @unique, expiresAt, usedAt?, createdAt }` + FK
     `(tenantId, siteId) → Site`, RLS `ENABLE` + `FORCE` + policy như các bảng tenant (theo `20261016000000_tenant_rls`),
     grant cho `app_runtime`. Thêm vào `tenantModels`, `tenantGuard`, ERD.
   - Hàm `public.resolve_tenant_slug(slug text)` SECURITY DEFINER (mẫu `resolve_tenant_host`) → `tenantId, siteId,
     tenantStatus`. `forPlatform(db).tenants.bySlug(slug)` cho cả `Db` và `PlatformDb` (E7-S01 dùng lại).
   - `tenantTransaction`/`withTenantTransaction` nhận tùy chọn `{ isolationLevel?: "RepeatableRead" | "Serializable" }`
     (truyền vào `$transaction`), mặc định như cũ.
3. **`packages/db/src/publish.ts`** (export từ index):
   - `class RevisionConflictError { currentRevision }`.
   - `saveDraft(db, tenantId, { pageId, expectedRevision, draftSections?, sections?: [{ sectionId, type, draftData }],
     actor })`: một `withTenantTransaction`; bước đầu `page.update` có điều kiện `revision = expectedRevision` (tăng
     `revision`, khóa dòng Page) → `count 0` → `RevisionConflictError`; ghi `draftSections` (parse `pageConfigSchema`
     descriptor) và `draftData` từng section (parse bằng schema của type; tạo `SectionContent` nếu chưa có, với `data`
     = defaults). Không invalidate (preview không cache). Trả revision mới.
   - `publishPage(db, tenantId, { pageId, expectedRevision, actor: { siteUserId? , platformAdminId? } })`: một
     transaction: cập nhật có điều kiện Page (`sections = draftSections ?? sections`, `draftSections = null`,
     `revision + 1`, `publishedAt = now`); mọi `SectionContent` của page có `draftData` → `data = draftData`,
     `draftData = null`, `revision + 1`; tạo `PageVersion { revision mới, snapshot: { sections, contents:
     [{ sectionId, type, schemaVersion, data }] }, publishedBy… }`; `enqueueInvalidate(repo, [pageTag(tenantId,
     slug)])` (+ `siteTag` nếu page là `home` vì header/footer lấy từ home). Trả `{ revision, versionId }`.
   - Xung đột không ghi đè ngầm: người thứ hai luôn nhận `RevisionConflictError` (kèm revision hiện tại để UI cảnh báo).
4. **Đọc nhất quán**: `loadPublishedPage` đọc `page` + `sectionContent` trong **một** `withTenantTransaction` với
   `isolationLevel: "RepeatableRead"` (một snapshot) → không bao giờ thấy bố cục của lần xuất bản này với nội dung của lần
   khác. Thêm `loadDraftPage(tenantId, siteId, slug, locale)` dùng chung code chuyển đổi, lấy `draftSections ??
   sections`, `draftData ?? data`, không yêu cầu `publishedAt`, **không** qua content cache.
5. **Token preview** (`packages/db/src/preview.ts`):
   - `createPreviewToken(db, tenantId, siteId, { ttlMs = 10 phút })` → token 32 byte base64url, lưu `sha256`.
   - `consumePreviewToken(db, tenantId, token)` → `UPDATE … SET usedAt = now() WHERE tokenHash = $1 AND usedAt IS NULL
     AND expiresAt > now() RETURNING siteId` trong tenant transaction (RLS: token của tenant khác không thấy được → sai
     host bị từ chối tự nhiên) → `{ siteId } | null`.
   - Lựa chọn: token ngẫu nhiên + hash trong DB thay vì token ký HMAC, vì "dùng 1 lần" cần trạng thái dùng chung giữa
     các instance; token vẫn gắn `tenantId` + `siteId`.
6. **Preview trên web**:
   - Proxy: host khớp `^([a-z0-9-]+)\.preview\.<PLATFORM_DOMAIN>$` → `tenants.bySlug` (qua resolver, có cache như
     host) → không có / `suspended` → 404/403 như host thường. Đặt `x-tenant-id`, `x-site-id`, `x-preview: 1` (xóa header
     giả từ client). `/api/preview` đi thẳng (không rewrite). Mọi path khác: kiểm cookie preview (bên dưới) bằng Web
     Crypto HMAC; không hợp lệ → `401` text "Phiên xem trước đã hết hạn — mở lại từ trang quản trị." `Cache-Control:
     no-store`. Hợp lệ → rewrite `/sites/<siteId>/…` như host thường. Response preview luôn có `X-Robots-Tag: noindex`,
     `Cache-Control: private, no-store`, `Content-Security-Policy: frame-ancestors <scheme>://<slug>.admin.<PLATFORM_DOMAIN>[:port]`.
   - `GET /api/preview?token=…&path=/…` (`apps/web/src/app/api/preview/route.ts`): chỉ chạy khi `x-preview` (host
     preview); thiếu/sai/hết hạn/đã dùng/khác tenant/khác site → `401` JSON `{ error }`. Thành công →
     `(await draftMode()).enable()` + cookie `__Host-preview` (`preview` khi không production) = `base64url(json {t, s,
     exp: now + 1h}).hmac(PREVIEW_SECRET)`, `HttpOnly; SameSite=Lax; Path=/; Secure` (production) → `307` tới `path`
     (chỉ path nội bộ: bắt đầu `/`, không `//`, không `\`). Cookie chỉ hợp lệ khi `t`/`s` trùng tenant/site của host
     (cookie Draft Mode `__prerender_bypass` dùng chung giữa các tenant, nên **không** tin riêng nó).
   - Trang `/sites/[siteId]/[[...path]]`: header `x-preview` → bắt buộc `draftMode().isEnabled` (không thì `notFound`),
     dùng `loadDraftPage`, `routeEnabled`/entitlement giữ như bản chính. Không đọc cookie ở trang công khai (chỉ nhánh
     preview, vốn đã động).
7. **E2E** `tooling/visual/preview.spec.ts` + `playwright.preview.config.ts` (projects `chromium`, `webkit`,
   `firefox`; cùng webServer với tenant, env `PLATFORM_DOMAIN=localhost`, `PREVIEW_SECRET`): fixture tạo token bằng
   script node (mẫu `fixture("setup")` trong `tenant.spec.ts`); `page.route` phục vụ trang giả
   `http://demo-t15.admin.localhost:<port>/__frame` chứa `<iframe src="http://demo-t15.preview.localhost:<port>/api/preview?token=…&path=/">`;
   kiểm iframe hiển thị nội dung nháp (marker `[DỮ LIỆU MẪU] nháp` trong `draftData` hero), tải lại iframe vẫn ở chế độ
   nháp, host công khai `t15.localhost` vẫn hiện bản chính. CI `workspace.yml`: thêm `/etc/hosts` cho
   `demo-t15.preview.localhost`, `demo-t15.admin.localhost`, `demo-t12.preview.localhost`; cài `webkit firefox`; chạy
   config preview.
