## Thiết kế
- Bốn file trong `scripts/agents/`: `spawn-codex.ps1`, `collect.ps1` (PowerShell 7) và `spawn-codex.sh`, `collect.sh`
  (bash). Hai bản của cùng lệnh có cùng tham số, cùng hành vi, cùng output. Mỗi file ≤ ~80 dòng, đọc `S` qua
  `node scripts/agents/story.mjs info <ID>` (pwsh: `ConvertFrom-Json`; bash: `node -p` lấy từng trường — không cần `jq`).
- Gốc repo = hai cấp trên thư mục script. Worktree root mặc định `<gốc repo>/../lp-worktrees`; worktree story ở
  `<root>/<ID>`; log Codex ở `<root>/<ID>/codex.log` (đúng "Chi tiết" của story).
- **`spawn-codex <ID…> [--root <dir>] [--base-port <n>] [--no-install]`** (pwsh nhận cả `-Root`/`-BasePort`/`-NoInstall`
  hoặc cú pháp `--` giống bash — chọn một cách và ghi trong `-?`/usage; ưu tiên cùng cú pháp `--` cho cả hai):
  1. Kiểm cả lô trước khi tạo gì (lỗi → exit 1, không làm gì): ID tồn tại, `!S.done`, `S.ready`, không trùng trong lô,
     `<root>/<ID>` chưa tồn tại, plan có sẵn (trên branch nếu branch đã có; hoặc ở base / cây làm việc chính).
  2. Mỗi story (chỉ số `i` trong lô):
     - Branch đã có → `git worktree add <wt> <branch>`; chưa có → `git worktree add -b <branch> <wt> <base>`.
       Plan chưa có trong worktree → copy từ repo chính, `git -C <wt> add <planFile>` +
       `git -C <wt> commit -m "docs(plan): <ID> plan"` (script chạy ngoài sandbox Codex nên commit được).
     - Cổng `port = base-port + i` (mặc định 3101). Lô sau cùng lúc → dùng `--base-port` khác (ghi trong tài liệu).
     - `pnpm install --frozen-lockfile` trong worktree trừ `--no-install`; lỗi → báo story đó, bỏ qua, tiếp story khác,
       exit cuối ≠ 0.
     - Ghi `<wt>/.agent-runs/<ID>/codex-exec-prompt.md` theo khung run-story Bước 3 + dòng
       `Dev server (nếu cần): PORT=<port> pnpm --filter web dev` và `Không chạy git ghi`.
     - Chạy nền, tách khỏi shell: `<CODEX_BIN:-codex> exec -C <wt> -s workspace-write
       -c model_reasoning_effort=<S.codexEffort.exec> -c sandbox_workspace_write.network_access=true
       -o <wt>/.agent-runs/<ID>/codex-exec-last.md "Dùng skill solar-story-exec. Đọc và làm theo .agent-runs/<ID>/codex-exec-prompt.md."`
       — prompt ngắn trỏ tới file để tránh quoting dài trên Windows; stdin rỗng; stdout+stderr → `<wt>/codex.log`.
       bash: `nohup … < /dev/null > log 2>&1 &`. pwsh: `Start-Process` ẩn cửa sổ (vd. qua `pwsh -NoProfile -Command`
       để gộp stream vào một log), lấy được PID. Biến môi trường `CODEX_BIN` cho phép thay codex giả khi kiểm thử.
     - Ghi PID vào `<wt>/.agent-runs/<ID>/codex.pid`, cổng vào `<wt>/.agent-runs/<ID>/port`.
     - In một dòng: `✔ <ID>  <wt>  <branch>  port <n>  pid <pid>`.
  3. Cảnh báo chồng lấn file (không chặn): đường dẫn trong `` `...` `` của mục "Các bước" ở plan, trùng giữa hai story
     → in `! <A> ↔ <B>: <file>`. Bỏ qua nếu làm script phình — tối thiểu: grep đường dẫn, so trùng. (Target "không
     xung đột file" chủ yếu đảm bảo bằng worktree riêng; cảnh báo này giúp Claude chọn lô.)
- **`collect [--root <dir>]`**: duyệt `<root>/*/.agent-runs/*/codex.pid`; mỗi story in một dòng bảng:
  `ID | branch | codex: running|done | commit: <git rev-list --count base..HEAD> | report: <dòng đầu mục "Trạng thái"
  của codex-report.md hoặc —> | checks: <PASS|FAIL từ verify.json.ok hoặc —>`. Không có worktree → in "không có".
  "Kết quả test" lấy từ `verify.json` do `node scripts/agents/run.mjs verify <ID>` (Claude chạy trong worktree) ghi ra;
  collect chỉ đọc, không chạy checks.
- `.gitignore`: thêm `codex.log` (gốc). `run.mjs` `IGNORED`: thêm `codex\.log$` để `commit`/`verify` không báo file lạc.
- Không thêm lệnh dọn dẹp: tài liệu ghi `git worktree remove <root>/<ID>` sau khi PR merge.
- Codex cloud (`codex cloud`): chỉ ghi trong tài liệu là tùy chọn cho story không cần Windows; không tự động hóa.
- `.sh` có bit thực thi trong git (Claude chạy `git update-index --chmod=+x` khi commit — ghi trong "Commit đề xuất").
