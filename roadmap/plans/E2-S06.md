Mỗi trang chỉ tải và preload font của theme đang dùng (≤ 2 họ, ≤ 4 file woff2), mọi file có glyph tiếng Việt.

## Thiết kế
**Bỏ `next/font`, tự host woff2** (người dùng chọn, xem "Rủi ro"). Khóa thiết kế:

1. **File font** — `apps/web/public/fonts/<slug>-<weight|var>.<hash8>.woff2`. Mỗi file **gộp subset latin + vietnamese**
   (một file/độ đậm, hoặc một file/họ với font variable) để đạt ≤ 4 file: Manrope (variable) 1 + Be Vietnam Pro
   (static 400/600/800) 3 = 4. `hash8` = 8 ký tự đầu sha256 nội dung → cache bất biến.
2. **Script dựng font** (công cụ dev, không phải dependency runtime): `packages/themes/scripts/build-fonts.py`
   (fonttools + brotli, `pip install fonttools brotli`). Nguồn: TTF trong repo `google/fonts` trên GitHub (giấy phép OFL,
   ghi URL nguồn trong script). Với mỗi họ trong danh sách: tải TTF (variable nếu có, không thì từng weight), `pyftsubset`
   theo unicode-range latin ∪ vietnamese của Google Fonts (ghi hằng trong script), `--flavor=woff2`, `--layout-features='*'`;
   kiểm cmap có `ạ ư đ Ă ơ ễ` (U+1EA1, U+01B0, U+0111, U+0102, U+01A1, U+1EC5), thiếu → lỗi; tính fallback metric
   (ascent/descent/lineGap/unitsPerEm và size-adjust theo `xAvgCharWidth` so với Arial, công thức giống `next/font`);
   ghi `packages/themes/src/fonts.generated.ts` (đầu file: `// Sinh bởi scripts/build-fonts.py — không sửa tay`).
   Chép giấy phép OFL của từng họ vào `apps/web/public/fonts/LICENSE-<slug>.txt`.
3. **Danh sách font được phép** — Inter, Be Vietnam Pro, Manrope (từ template) + 2 font cho override:
   Plus Jakarta Sans, Montserrat (đều có subset vietnamese, có bản variable). Tổng 5 họ (epic cho phép tới 3 + 5).
4. **API** — `packages/themes/src/fonts.ts` (thuần, không import `next`, test được bằng node:test), export qua
   `src/index.ts`:
   ```ts
   export type FontFamily = keyof typeof FONTS;          // FONTS từ fonts.generated.ts
   export function themeFontFamilies(theme: ThemeTokens): FontFamily[];        // [sans, display] bỏ trùng; tên ngoài danh sách → throw
   export function themeFontFiles(theme: ThemeTokens): string[];               // tên file woff2 cần cho theme (static: lọc theo theme.font.weights; weight không có → throw)
   export function themeFontCss(theme: ThemeTokens, baseUrl = "/fonts/"): string;
   ```
   `themeFontCss` sinh (minify, thứ tự ổn định): `@font-face` của đúng các file trên (`font-display:swap`,
   `unicode-range` = latin ∪ vietnamese, `font-weight` = weight hoặc dải variable `"100 900"`), một `@font-face`
   `"<Họ> Fallback"` (`src:local("Arial")` + `ascent-override/descent-override/line-gap-override/size-adjust`) cho mỗi họ,
   và `:root{--font-sans:"<sans>","<sans> Fallback";--font-display:"<display>","<display> Fallback"}`.
   `baseUrl` chỉ chấp nhận chuỗi khớp `^/[\w/-]*/$` (chặn chèn CSS); `theme.font.source` giữ nguyên trong schema,
   không dùng ở story này.
5. **apps/web** — `layout.tsx`: xóa import `next/font/google` và `className={sans.variable}`;
   `const themeCss = themeToCss(t15) + themeFontCss(t15)`; trong `RootLayout` gọi
   `preload(\`/fonts/${f}\`, { as: "font", type: "font/woff2", crossOrigin: "anonymous" })` (từ `react-dom`) cho mỗi
   `themeFontFiles(t15)`. `next.config.ts` thêm `headers()` cho `/fonts/:path*`:
   `Cache-Control: public, max-age=31536000, immutable`. `globals.css` không đổi.
6. Không đổi schema token, không thêm dependency runtime.
