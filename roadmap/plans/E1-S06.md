## Mục tiêu
Primitive giao diện dùng chung (tiêu đề section, nút carousel, đếm số, dialog, ảnh/wordmark, modal video, icon thương
hiệu, nhãn giá, reveal, kéo cuộn) nằm ở package `@solar/ui`, chỉ dùng class sinh từ token. `apps/web` import từ
`@solar/ui`, không còn bản sao; giao diện và hành vi trang không đổi. Trang dev-only `/lab/ui` có ví dụ cho từng primitive.

    `Wordmark` (`text-[11px]`).

## Thiết kế
- **Package** `packages/ui`, tên `@solar/ui`, `private`, `exports: { ".": "./src/index.ts" }` (không build).
  - `dependencies`: `@solar/core: workspace:*`. `peerDependencies`: `react`, `next`, `@heroicons/react` (đã có ở web —
    không phải dependency runtime mới). `devDependencies`: `@solar/config`, `typescript`, `eslint`, `@types/react`,
    `@types/node`, cùng `react`/`next`/`@heroicons/react` đúng phiên bản `apps/web` để typecheck.
  - `tsconfig.json` extends `@solar/config/tsconfig.base.json`, include `src/**/*.{ts,tsx}`. `eslint.config.mjs` chép mẫu
    `packages/core/eslint.config.mjs`.
  - Scripts: `typecheck`, `lint`, `lint:tokens`, `test` (xem dưới).
- **Cấu trúc** (mỗi file client giữ `"use client"`; barrel không có directive):
  ```
  packages/ui/src/
    index.ts              barrel, chỉ named export
    SectionHead.tsx       SectionHead
    CarouselNav.tsx       CarouselNav
    CountUp.tsx           CountUp
    useCountUp.ts         useCountUp, useInViewOnce
    useModal.ts           useModal
    useDialog.ts          useDialog
    useSnapCarousel.ts    useSnapCarousel, pad2
    Media.tsx             MediaImage, Wordmark
    VideoModal.tsx        VideoModal, type VideoSource
    PriceTag.tsx          PriceTag
    reveal.ts             delay
    SectionReveal.tsx     SectionReveal
    DragScroll.tsx        DragScroll
    brand-icons/index.tsx TikTokIcon, YouTubeIcon, FacebookIcon, MessengerIcon, ZaloIcon (đúng đường dẫn AGENTS.md)
  ```
  Chuyển nguyên code (git mv nếu được để giữ lịch sử), đổi default export → named export; không đổi logic.
- **Bỏ phụ thuộc app khỏi primitive** (props tối thiểu, mặc định tiếng Việt như nội dung mặc định):
  - `CarouselNav`: thêm `prevLabel = "Trước"`, `nextLabel = "Tiếp"`; 6 chỗ gọi truyền `tr("Trước","Previous")`,
    `tr("Tiếp","Next")` để giữ hành vi EN.
  - `VideoModal`: thêm `closeLabel = "Đóng video"`; 3 chỗ gọi truyền `tr("Đóng video","Close video")`.
    Thay khối `useEffect` tự viết bằng `useModal(dialogRef, onClose, closeRef)` (cùng hành vi; selector của `useModal`
    bỏ qua nút nền `tabIndex={-1}` — đúng hơn).
  - `VideoSource` định nghĩa ở `VideoModal.tsx`, export từ `@solar/ui`; `config/site.config.ts` import type từ `@solar/ui`
    (không re-export).
- **Token** — thay class tùy ý bằng token mới trong preset (giá trị y hệt → không đổi pixel):
  - `borderRadius: { card: "28px" }` → `VideoModal` dùng `rounded-card`.
  - `fontSize: { "2xs": ["11px", …line-height mặc định của text-[11px]] }` → `PriceTag`, `Wordmark` dùng `text-2xs`.
    (Kiểm: `text-[11px]` của Tailwind không đặt line-height → token khai báo dạng chuỗi `"11px"` để giữ nguyên.)
  - `backgroundImage: { "media-glow": "radial-gradient(circle at 75% 20%, rgb(var(--c-accent) / .22), transparent 45%)" }`
    → `MediaImage` dùng `bg-media-glow`.
  - Giữ các arbitrary không thuộc màu/font/bo góc/bóng: `z-[90]`, `aspect-[9/16]`, `max-w-[min(…)]`, `tracking-[-.02em]`.
  - CSS dùng chung (`.t15-*`, `[data-reveal]`) ở lại `globals.css` của web trong story này; README của `@solar/ui` ghi rõ
    app phải có các class đó (E2 chuyển vào token/theme).
- **apps/web**: thêm `"@solar/ui": "workspace:*"`, `transpilePackages: ["@solar/core", "@solar/ui"]`, Tailwind `content`
  thêm `"../../packages/ui/src/**/*.{ts,tsx}"` (thiếu dòng này class của primitive không được sinh). Mọi import đổi sang
  `from "@solar/ui"`; xóa `components/ui/`, `DragScroll.tsx`, `SectionReveal.tsx`, `BrandIcons.tsx`, `PriceTag.tsx`,
  `lib/useDialog.ts`, `lib/useCountUp.ts`, `utils/reveal.ts`. Không shim, không re-export.
- **`lint:tokens` tạm (regex)** — `packages/ui/scripts/lint-tokens.mjs` (sẽ bị thay bởi rule ESLint ở E2-S04):
  - Quét đệ quy thư mục truyền vào (`.ts/.tsx/.css`), báo `file:dòng: <mẫu> — gợi ý` và exit 1 khi có vi phạm.
  - Mẫu cấm (theo danh sách E2-S04): mã hex `#[0-9a-fA-F]{3,8}\b`, `rgb(`/`hsl(` không theo sau bởi `var(--c-`,
    class `(bg|text|from|to|via|border|rounded|shadow|font)-\[`.
  - Bỏ qua thư mục `brand-icons/` và dòng có comment `token-exempt: <lý do>`.
  - Export hàm thuần `findViolations(text, file)` để test; phần CLI gọi hàm này.
  - Script `"lint:tokens": "node scripts/lint-tokens.mjs src"`. CI: thêm bước `pnpm turbo run lint:tokens` vào
    `.github/workflows/workspace.yml` (cạnh bước lint).
- **Test**: `packages/ui/scripts/lint-tokens.test.mjs` (`node:test`): ca sai (`bg-[#0E7C3A]`, `rgb(1,2,3)`,
  `rounded-[28px]`, `text-[11px]`) và ca đúng (`bg-primary`, `rgb(var(--c-accent) / .2)`, `z-[90]`, dòng `token-exempt`,
  file trong `brand-icons/`). Script `"test": "node --test scripts/"`. Primitive là code chuyển nguyên, không viết test
  React mới (không thêm dependency test).
- **`/lab/ui`** — `apps/web/src/app/lab/ui/page.tsx` (server) + `LabUi.tsx` (client):
  - `page.tsx`: `if (process.env.NODE_ENV === "production" && process.env.LAB_ENABLED !== "true") notFound();`,
    `metadata.robots = { index: false, follow: false }`. Thêm `LAB_ENABLED` vào `env` của task `build` trong `turbo.json`;
    `robots.ts` thêm `"/lab/"` vào `disallow`. Không thêm vào sitemap.
  - `LabUi.tsx`: mỗi export của `@solar/ui` có một khối ví dụ có tiêu đề là tên primitive (`id` = tên, để kiểm):
    SectionHead, CarouselNav + useSnapCarousel + pad2 (dải `.t15-no-scrollbar` → DragScroll cũng áp dụng), CountUp,
    useCountUp/useInViewOnce, useModal (nút mở dialog đơn giản), useDialog, MediaImage (có/không `src`), Wordmark (3 cỡ),
    VideoModal (nút mở, video file `/videos/hero_video.mp4` đã có), PriceTag (giá thường / giảm giá / short),
    delay + SectionReveal (vài khối `data-reveal` với `style={delay(…)}`), DragScroll, 5 brand icon.
    Gắn `<SectionReveal />` trong trang (DragScroll đã gắn ở `SiteShell`). Nội dung mẫu gắn nhãn `[DỮ LIỆU MẪU]`.
  - Chỉ dùng class token, cùng quy tắc như `packages/ui`.

## Các bước
1. Tạo `packages/ui` (package.json, tsconfig, eslint config, README) — kiểm bằng: `pnpm install`, `pnpm --filter @solar/ui typecheck`.
2. Chuyển primitive sang `packages/ui/src/` theo cấu trúc trên, named export, bỏ `useLang`/`site.config`, VideoModal dùng
   `useModal` — kiểm bằng: typecheck của ui.
3. Thêm token `rounded-card`, `text-2xs`, `bg-media-glow` vào preset, thay class tùy ý — kiểm bằng: `lint:tokens` của ui.
4. Đổi import trong `apps/web`, truyền label cho `CarouselNav`/`VideoModal`, cập nhật `next.config.ts`,
   `tailwind.config.ts`, `package.json`, `site.config.ts`; xóa file cũ — kiểm bằng: `pnpm turbo run typecheck lint`
   và lệnh grep ở mục kiểm tra trả về rỗng.
5. Viết `lint-tokens.mjs` + test, script `lint:tokens`/`test`, bước CI — kiểm bằng: `pnpm --filter @solar/ui test`,
   `pnpm --filter @solar/ui lint:tokens`; thử thêm tạm `bg-[#0E7C3A]` vào một file ui → exit 1 (ghi output vào report, rồi bỏ).
6. Tạo `/lab/ui`, `robots.ts`, `turbo.json` — kiểm bằng: `pnpm dev --filter web`, mở `/lab/ui` thấy đủ khối;
   `curl` trả 200 ở dev. Nếu dựng production được trong sandbox: `next build && next start` → `/lab/ui` 404.
7. Cập nhật `packages/ui/README.md`, tick AC trong epic, viết report.
