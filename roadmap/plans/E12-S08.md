## Mục tiêu
Tenant có `abTest` bật A/B cho một landing: nhập phiên bản B cho tiêu đề hero + nhãn CTA chính; khách được gán A/B ổn định
ở client (trang vẫn ISR); lead ghi phiên bản; admin xem lượt xem/lead theo phiên bản và chọn phiên bản thắng.

## Bối cảnh đã khảo sát
- `abTest` đã có trong gói premium (`packages/plans/plans.ts:3`, nhãn "A/B CTA"); pro có `landingPages` nhưng không có `abTest`.
- Landing render trong `tenantPage` (cache, `apps/web/src/components/tenant/cached.tsx:41-63`); `loadPublishedPage` trả
  `{ id, kind, settings, config }` (`apps/web/src/lib/tenant/siteData.ts:75`). Locale theo cookie, path = slug.
- Hero: `title.{lead,highlight,sub,subHighlight}` (localized ≤ 60) + `primaryCta.label` (`packages/sections/src/hero/schema.ts`),
  mọi variant đọc hai trường này; `maxPerPage: 1`.
- Lead: `/api/lead` → `createTenantLeadHandler` (deps có `loadSite/saveLead/limiter`, `apps/web/src/lib/tenant/leadIntake.ts`),
  body có `page: location.pathname`; 4 nơi gửi form (LeadForm web, DealerForm, sections LeadForm, dealer island).
  Proxy gắn `x-tenant-id/x-site-id` cho mọi `/api/*` (`apps/web/src/lib/tenant/proxy.ts:60,74`).
- Admin landing: `/trang/[pageId]` + `PageSettingsForm`, handler có deps `apps/admin/src/lib/landingPages.ts`, action `pages.structure`.
- Đếm bằng SQL trong `tenantTransaction` có tiền lệ (`leadWeeklySources`, `packages/db/src/leads.ts`). Bảng mới cần RLS theo mẫu
  `20261030180000_e11_s06_sending_domain` + `tenantScope.ts`/`tenantGuard.ts`.
- Truy vấn: `codegraph explore "landing page lead form entitlement abTest"`, checks-map cho từng file dự kiến.

## Thiết kế (chốt)
- **Dữ liệu** — migration `20261106120000_e12_s08_ab_test`:
  - `Page.abTest Json?` (cột riêng, **không** nằm trong `settings`: `savePageSettings` ghi đè cả `settings` → gộp chung sẽ mất A/B
    hoặc phải khóa đọc-sửa-ghi). Thêm vào `tenantBackup` pages (`abTest: json.optional()`), export/import.
  - `Lead.abTestId String? @db.Uuid`, `Lead.abVariant String?` + `@@index([tenantId, abTestId])`.
  - `AbTestView { tenantId, pageId, testId @db.Uuid, variant String, views Int @default(0), @@id([tenantId,testId,variant]) }`,
    FK Page/Tenant `onDelete: Cascade`, RLS + grant như SendingDomain, đăng ký `tenantScope`/`tenantGuard`. Không đưa vào backup (số liệu).
- **Schema** `packages/db/src/abTests.ts` (export từ `@solar/db`; không đặt ở `packages/presets` để không kéo bộ ảnh matrix):
  `abTestSchema = strictObject({ id: uuid, status: enum(running, ended), title: strictObject({lead, highlight, sub, subHighlight} localized ≤60),
  ctaLabel: localized ≤80, winner?: enum(A,B) })`; `parseAbTest(value)` → `AbTest | null`.
- **db** (`abTests.ts`): `saveAbTest(db, tenantId, { pageId, action: "start"|"end", winner?, title, ctaLabel })` trong `withTenantTransaction`:
  page phải `isLandingSlug && slug !== ""`, có section `hero` bật trong `draftSections ?? sections`; site.tenant `canUse(..)("abTest")`;
  start: giữ `id` khi đang running, ngược lại `randomUUID()`; end: `status:"ended", winner`. Trang đã xuất bản → `enqueueInvalidate([pageTag])`.
  `recordAbView(db, tenantId, siteId, testId, variant)`: tìm page `siteId` có `abTest.id = testId` và `status running` (JSON path) →
  `INSERT … ON CONFLICT DO UPDATE SET views = views + 1` (SQL, một câu, không đọc-sửa-ghi) → `true`; không thấy → `false`.
  `runningAbTest(db, tenantId, siteId, slug)` → `{ id } | null`. `abTestStats(db, tenantId, testId)` → `{A:{views,leads},B:{…}}`
  (lead đếm bằng SQL group by `abVariant`, bỏ `status = spam`).
- **Web render** (`cached.tsx`, chỉ `!key.preview`, `page.kind === "landing"`, `canUse("abTest")`, có hero):
  - running: tách `config.sections` thành [trước hero] [hero] [sau hero], render hero hai lần trong `<div data-ab-variant="A|B">`
    (bản B: `id` section `<id>-b`, bỏ `anchor`, `data` = hero gộp B qua `withAbVariant(data, ab)` thuần ở `apps/web/src/lib/tenant/abTest.ts`)
    → không sửa `PageRenderer` (tránh kéo matrix). CSS inline: `[data-ab-variant]{display:contents}`
    `html:not([data-ab="B"]) [data-ab-variant="B"],html[data-ab="B"] [data-ab-variant="A"]{display:none}` → tắt JS: A
    (một trang chỉ một hero ⇒ một thử nghiệm, nên một attribute `data-ab` đủ).
  - Script inline **trước** hai wrapper (chạy trước paint, không nháy): đọc cookie `ab_<id>`; thiếu → `Math.random()<.5`, ghi cookie
    `path=/;max-age=7776000;samesite=lax`; đặt attribute trên `<html>` (đã `suppressHydrationWarning`); `navigator.sendBeacon("/api/ab", JSON.stringify({t:id,v}))`
    mỗi lượt tải. Script sinh từ `abScript(id)` (thuần, test được); id chỉ là uuid đã parse → không chèn chuỗi người dùng.
  - ended + winner B: gộp B vào hero ở server, không script. Gói thiếu `abTest` / preview: A, không script.
- **`POST /api/ab`** (`apps/web/src/app/api/ab/route.ts` → `createAbViewHandler(deps)` ở `apps/web/src/lib/tenant/abView.ts`):
  không header tenant → 404; body text JSON `{t: uuid, v: "A"|"B"}` sai → 400; rate limit `rl:ab:<tenant>:ip:<ip>` 30/phút → 429;
  site thiếu `abTest` → 403 (`entitlementResponse`); `recordAbView` false → 404; ok → 204. Không đọc/ghi cookie.
- **Lead** (`leadIntake.ts`): dep mới `abTest(tenantId, siteId, slug) → {id}|null`; sau khi parse, nếu site có `abTest`, `lead.page`
  → slug (bỏ `/` đầu/cuối, cắt `?#`), test đang chạy và cookie `ab_<id>` ∈ {A,B} → `LeadInput.abTestId/abVariant`. Mọi trường hợp khác
  → bỏ qua, **lead vẫn nhận** (không 403 làm mất lead). Đọc cookie ở API route là được (route không cache).
- **Admin** (`apps/admin/src/lib/abTest.ts` handler có deps như `landingPages.ts`; action `pages.structure` trong `trang/actions.ts`):
  panel "Thử nghiệm A/B" ở `/trang/[pageId]` khi landing + quyền: gói thiếu → lý do + `UpgradeRequest feature="abTest"`;
  có gói: form B (4 ô tiêu đề + nhãn nút, ô EN khi site có `en`; điền sẵn từ hero A khi chưa có) + nút "Bắt đầu thử nghiệm"/"Lưu phiên bản B";
  bảng thống kê (caption "Kết quả thử nghiệm", cột Phiên bản/Lượt xem/Lead/Tỉ lệ lead); "Chọn A thắng", "Chọn B thắng" (form riêng,
  chạy không cần JS). Lead inbox: nhãn "Phiên bản A|B" khi `abVariant`.
