## Mục tiêu
`<SchemaForm schema value onChange />` tự dựng form cho mọi section type từ zod schema của type đó (không viết form tay),
validate inline bằng chính schema với thông báo tiếng Việt. Thêm section type mới là có form ngay. Đặt ở package mới
`packages/cms-ui` để `apps/admin`, `apps/console` và wizard (E13-S06) dùng chung (E7-S04, E13 đã ghi chỗ này).

## Bối cảnh đã khảo sát
- `packages/sections/src/fields/widget.ts`: `fieldRegistry` (zod registry) + `fieldMeta(schema)` (tự bóc
  optional/default/nullable). Widget có sẵn: `localized`, `localizedTextarea`, `media`, `link`, `richText`,
  `collectionQuery` (kèm `collection`). Field helper: `fields/{localized,media,link,richText,collection}.ts`.
- `packages/sections/src/registry.ts`: `sectionRegistry.types` có **30** type (28 section + `site-header`, `site-footer`);
  mỗi `def.defaults` = `schema.parse(fixture)` → dùng làm fixture round-trip.
- `calculator/schema.ts`: dùng `z.record(z.enum(SEGMENTS), …)` (bảng theo phân khúc), `z.discriminatedUnion("kind")`
  (tariff bậc thang/bình quân), `nullable` (`upTo`), `.refine`, `.default`, mảng enum (`steps`). Form phải đi được các
  dạng này, không chỉ string/number/boolean.
- zod 4.6.5 có `z.locales.vi()` → `schema.safeParse(v, { error: z.locales.vi().localeError })` ra thông báo tiếng Việt
  (đã thử). Message tùy biến trong schema (vd. "Bậc tăng dần…") vẫn giữ nguyên.
- `apps/admin`: `requirePagePermission(...)` (lib/auth.ts), `getSiteEntitlements()` → `can("bilingual")`
  (lib/entitlements.ts), trang `(admin)/noi-dung/page.tsx` đang là placeholder. Chưa phụ thuộc `@solar/sections`.
- Test: không có jsdom; sections/admin test bằng `node:test` + `renderToStaticMarkup`. Thư viện media là E8-S05 (chưa có).
- Dependency đã chấp thuận (AGENTS.md §4): `@dnd-kit/*`.

## Thiết kế
Package `@solar/cms-ui` (`packages/cms-ui`, cấu hình như `packages/ui`: typecheck/lint/lint:tokens/test bằng
`node --import tsx --test` như apps/admin). Phụ thuộc: `zod`, `@solar/sections`, `@solar/ui` (nếu cần), `@dnd-kit/core`,
`@dnd-kit/sortable`, `@dnd-kit/utilities`; peer `react`.

1. **`src/schema/describe.ts` — duyệt zod thành cây trường (thuần, không React)**
   ```ts
   type FieldNode =
     | { kind: "string"; multiline?: boolean; max?: number; format?: "url" | "email" }
     | { kind: "number"; int?: boolean; min?: number; max?: number; step?: number }
     | { kind: "boolean" }
     | { kind: "enum"; options: readonly (string | number)[] }      // z.enum, union các literal, literal đơn
     | { kind: "widget"; widget: FieldWidget; collection?: string; schema: z.ZodType } // fieldMeta có giá trị
     | { kind: "object"; fields: { key: string; node: FieldNode }[] }
     | { kind: "record"; keys: readonly string[]; value: FieldNode } // record khóa enum → hiển thị như object
     | { kind: "array"; item: FieldNode; min?: number; max?: number }
     | { kind: "union"; discriminator: string; options: { value: string; node: FieldNode /*object*/ }[] }
     | { kind: "json" };                                              // fallback cho dạng chưa hỗ trợ
   // Mọi node có thêm: optional?, nullable?, hasDefault?, label (từ key), description? (z.describe/meta nếu có).
   export function describe(schema: z.ZodType): FieldNode;
   export function defaultFor(node: FieldNode): unknown; // giá trị khởi tạo khi thêm phần tử mảng / bật trường optional / đổi nhánh union
   ```
   - Kiểm `fieldMeta(schema)` **trước** mọi kiểu khác (widget thắng object).
   - Bóc `ZodOptional/ZodDefault/ZodNullable/ZodPipe (lấy in)`; `.refine/.superRefine` ở zod 4 không đổi kiểu node.
   - `json` chỉ là lưới an toàn; test bảo đảm 30/30 type không sinh node `json` (Target).
   - Nhãn: bảng `labels` tiếng Việt cho key hay gặp (`title`, `eyebrow`, `description`, `items`, `cta`…) + fallback tách
     camelCase; cho phép override qua `overrides`.

2. **`src/schema/path.ts`** — `getAt(value, path)`, `setAt(value, path, next)` bất biến (copy theo nhánh, giữ nguyên
   tham chiếu nhánh không đổi), `issuesByPath(error)` → `Map<"a.b.0", string[]>`.

3. **`src/codecs.ts` — chuyển giá trị ↔ ô nhập (thuần)**: `number` (chuỗi rỗng/không phải số → lỗi "Nhập một số",
   **không ghi chuỗi vào value**), `richText` (blocks ↔ mô hình editor), `link`, `localized`. Mỗi codec có
   `toInput(v)` / `fromInput(input) → { ok: true, value } | { ok: false, message }`.

4. **`src/SchemaForm.tsx` (`"use client"`)**
   ```ts
   type SchemaFormProps<S extends z.ZodType> = {
     schema: S; value: z.input<S>; onChange(next: z.input<S>): void;
     onSubmit?(data: z.output<S>): void;          // chỉ gọi khi safeParse thành công
     bilingual?: boolean;                          // false → ẩn tab EN, giữ nguyên giá trị en đã có
     widgets?: Partial<Record<string, WidgetComponent>>; // override theo đường dẫn ("tariffs.*") hoặc theo widget
     pickers?: { media?: MediaPicker; pages?: { slug: string; label: string }[]; collectionItems?: (c: string) => Promise<{ id: string; label: string }[]> };
     submitLabel?: string;
   };
   ```
   - Validate: mỗi lần đổi → `schema.safeParse(value, { error: z.locales.vi().localeError })`, lỗi hiện ngay dưới trường
     theo path (`aria-invalid`, `aria-describedby`); lỗi của ô nhập (codec) giữ ở state cục bộ của ô, không đẩy giá trị sai
     kiểu lên `onChange`. Nút lưu bị khóa khi còn lỗi; `onSubmit` nhận `parse` output.
   - Widget: string (input/textarea theo `multiline`/`max`, có đếm ký tự khi có `max`), number (`inputMode="decimal"`,
     min/max/step), boolean (switch), enum (select; mảng enum unique như `steps` → checkbox list có sắp xếp),
     `localized`/`localizedTextarea` (tab VI/EN, EN chỉ khi `bilingual`), `media` (nút "Chọn từ thư viện" gọi
     `pickers.media`; chưa có picker → ô mã media + alt; ảnh xem trước bằng `mediaSrc`), `link` (chọn loại: trang/URL/neo/
     điện thoại/Zalo/dự toán; loại `page` là select từ `pickers.pages` hoặc ô nhập), `richText` (editor tối giản
     contentEditable: đậm, nghiêng, link, danh sách có/không thứ tự, đoạn; chuyển DOM ↔ `RichTextBlock[]` bằng hàm thuần
     trong `src/richText/convert.ts`, chỉ nhận đúng whitelist của schema), `collectionQuery` (limit, sắp xếp, chọn id từ
     `pickers.collectionItems`), object (fieldset lồng, thu gọn được ở cấp ≥ 2), record khóa enum (bảng: hàng = khóa có
     nhãn, vd. phân khúc), array (thêm/xóa/nhân bản, kéo sắp xếp bằng dnd-kit có hỗ trợ bàn phím + nút lên/xuống;
     tôn trọng min/max), union theo discriminator (select nhánh; đổi nhánh → `defaultFor` nhánh mới, hỏi xác nhận nếu đang
     có dữ liệu), optional (công tắc "Bật" → `defaultFor`; tắt → bỏ khóa).
   - Chỉ dùng class token (AGENTS.md §4). Không đọc cookie/phiên.

5. **`apps/admin` — trang dùng form (bằng chứng AC1, nền cho E7-S05)**
